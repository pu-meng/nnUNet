# 论文路线与贡献边界

本文合并 2026-07-16 方向会议和后续贡献补强计划，只保存仍然有效的决策与历史教训。实验完成状态不在这里重复维护；以 [`../实验与分析/当前实验总览与决策门.md`](../实验与分析/当前实验总览与决策门.md) 和 [`../待补图表统计与对比清单.md`](../待补图表统计与对比清单.md) 为准。

## 1. 论文主线

目标不是把 MLA、MoE、attention 和多尺度模块堆在一起，而是研究：

> 在有限医学数据和三维计算预算下，能否保留 MedNeXt 的局部卷积表征，只在最低空间分辨率补充受控的全局 token 交互，从而改善肝肿瘤分割的外部可靠性，并控制额外成本？

对应逻辑：

```text
局部卷积长程交互有限
→ 全局上下文可能有帮助
→ 高分辨率 3D attention 成本高
→ 在 bottleneck 使用低秩 KV 表示
→ 用无 attention、标准 MHA 和相同 MoE 对照检验机制
```

MoE 目前属于组合中的独立变量。除非 `MHA+MoE vs MLA+MoE` 等严格对照支持，否则不能把组合收益单独归因于 MLA 或 MoE。

## 2. 2026-07-16 会议中保留的决策

- 论文需要同时报告 effectiveness 与 efficiency，不能只报 Dice。
- 当前模型参数量高于原 MedNeXt，不能称为 lightweight；准确说法是“以有限结构增量引入全局交互”，且仍需实测支持。
- bottleneck 的动机是 token 数最少、语义层级最高，但“最佳位置”仍是待验证命题。
- 应报告 Params、FLOPs、峰值显存、推理时间和训练成本，并区分理论复杂度与真实运行成本。
- 有限数据比例实验只有在主机制证据成立且训练预算允许时再做，不是当前 Tier 1。

会议曾提出 dynamic skip MoE。当前没有实现和证据，且会引入新的机制变量；在 MLA/MHA/MoE 主效应尚未隔离前暂停，不进入当前论文故事。

## 3. 当前可以主张到哪里

### 可以陈述

- 代码中实现了 MedNeXt bottleneck 后的 MLA 与 MoE 组合。
- 已有三数据域和病例级配对结果可以描述“在哪些域、哪些指标上观察到差异”。
- IRCADb 上 MLA+MoE 相比原 MedNeXt 的肿瘤阳性病例 Tumor Dice 配对差异通过当前统计判据。
- HCC 上 MLA+MoE 相比 MLA 反而显著更低，说明收益并不跨域普遍成立。

### 不能陈述

- “MLA 普遍改善三维肝肿瘤分割的跨域泛化”。
- “整个网络是轻量模型”或“显著降低 attention 的计算复杂度”，因为当前实现仍显式形成完整 token 交互，整体效率必须实测。
- “MoE 专家学会了不同肿瘤亚型”，除非提供路由分布、专家使用和病例属性对应证据。
- “每个新增模块都独立有效”，除非完成单变量及组合消融。

## 4. 贡献成立所需的最小证据链

| 证据 | 回答的问题 | 优先级 |
|---|---|---|
| MedNeXt | 无 attention 的骨干基线 | 必须，已有 |
| MedNeXt_MHA | 标准 attention + 标准 MLP | 必须，已有 |
| MedNeXt_MLA | 低秩 attention + 标准 MLP | 必须，已有 |
| MedNeXt_MHA_MoE | 标准 attention + 相同 MoE | 必须，已有结果需按当前总览核验 |
| MedNeXt_MLA_MoE | proposed combination | 必须，已有 |
| 参数/FLOPs/峰值显存/延迟 | 收益是否只是成本增加 | 必须，已有部分统计，需统一口径 |
| 多 seed 或重复训练 | 结果是否依赖单次随机性 | 必须补强 |
| 病灶大小、FP/FN、失败病例 | 机制在哪些病例上成立 | 很值得做，已有部分病例证据 |
| 插入位置、ratio、block 数 | 当前结构选择是否随意 | 根据主效应结果选择最少量消融 |

不机械要求所有位置和超参数网格。如果 `MLA vs MHA` 在相同 FFN 下没有稳定收益，优先重新定义或收缩贡献，而不是继续扩大搜索空间。

## 5. 当前投稿叙事的决策门

### 路径 A：低秩 attention 主效应成立

若相同 FFN、相近训练预算下，MLA 在至少一个外部域稳定优于 MHA，并有合理成本优势：

1. 补一组最小位置或压缩比消融；
2. 用病例大小和 FP/FN 分析解释受益群体；
3. 主线写成“bottleneck low-rank global context 的效果—成本权衡”。

### 路径 B：只有 MLA+MoE 组合有效

若 MLA 单独不优于 MHA，但组合有稳定收益：

1. 不再声称 MLA 单独有效；
2. 检查交互是否可重复，并分析路由与专家使用；
3. 主线改为“受控的 latent attention–expert interaction”，否则只作为经验组合报告。

### 路径 C：跨域结果不稳定

若多 seed 或补充外部验证仍出现方向反转：

1. 停止追加新模块；
2. 将工作收缩为跨域失效与可靠性分析，或更换可被证据支持的问题；
3. 明确负向结果和数据域边界，不用内部平均分掩盖失败。

## 6. 历史教训

- 方向会议提出的是假设与实验议程，不等于已完成贡献。
- 动态 checklist 很快过期，因此完成状态只维护一个事实入口。
- 结构复杂、参数更多或名称新颖都不能替代机制隔离。
- 最终故事必须从已确认的代码与实验倒推，不能用预期结果组织论文。
