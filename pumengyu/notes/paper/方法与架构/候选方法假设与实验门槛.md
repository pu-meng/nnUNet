# 候选方法假设与实验门槛

本文件只记录尚未被实验充分回答的候选方向。MedNeXt、MLA、MoE 与 `C→rC→C` 的基础机制见 [`MedNeXt_MLA_MoE基础模块与计算量.md`](MedNeXt_MLA_MoE基础模块与计算量.md)；已经完成的 Progressive Patch、Large Kernel 等负向或近中性结果见 [`../实验与分析/负向与近中性消融汇总.md`](../实验与分析/负向与近中性消融汇总.md)。未通过下述决策门的设想不能写成论文贡献。

## 1. 当前候选方向总表

| 候选方向 | 想解决的问题 | 当前状态 | 进入正式训练前的最低证据 |
|---|---|---|---|
| 普通 3D 卷积替换 depthwise 卷积 | depthwise 空间混合能力可能不足 | 低优先级，未训练 | 参数/FLOPs 匹配对照和小规模 pilot |
| 局部频域 + 三维形状判别 | 肿瘤与低密度非肿瘤结构混淆导致 FP | 诊断优先，未训练 | 无训练可分性分析跨病例成立 |
| 正常肝定向 masked reconstruction | 小肿瘤监督稀疏、低对比度异常不敏感 | 候选预训练，未训练 | 随机遮挡预训练对照与固定微调预算 |

当前论文的主方法仍是 MedNeXt_MLA_MoE；这里的候选方向不是已完成模块，也不能与当前方法一起包装成“多创新点”。

## 2. 普通卷积替换：先做公平成本控制

### 假设

MedNeXtBlock 的 `7×7×7` depthwise convolution 只在每个通道内做空间混合，跨通道交互主要由后续 `1×1×1` 扩展与压缩承担。换成普通 3D 卷积可能增强联合空间—通道建模，但也会显著增加参数、FLOPs 与显存。

### 不能直接做的归因

- 直接替换后 Dice 提高，不能证明“联合空间—通道建模更好”，因为模型容量同时增大。
- 只比较参数量不够；大核普通 3D 卷积的实际显存和吞吐可能成为主要差异。
- DownBlock/UpBlock 含步幅、转置卷积和残差投影，不能机械套用普通 MedNeXtBlock 的公式。

### 最小实验

1. 只改 bottleneck 普通 block，保持训练数据、patch、loss、schedule 与 seed 不变。
2. 同时报 Params、FLOPs、峰值显存和单 patch 延迟。
3. 增加参数匹配控制，例如缩小通道宽度或减少 block 数。
4. 若 pilot 没有稳定改善小病灶 Recall 或外部域 FP，立即停止全网替换。

## 3. 频域与形状：先验证病例是否真的可分

### 观察与边界

- `ircadb_014` 有原始 `metastasectomie` 标注，可作为术后区域困难负样本。
- `liver_41` 只有低密度阴影和模型误报证据，不能据此声称它是术后切除腔。
- “29/30 个 trainer 共同误报”只能说明它是跨模型难例，不能证明 FFT 能解决。

### 可检验假设

真实肿瘤与困难负样本可能在局部频谱、纹理、边界梯度或三维形状上存在稳定差异。频域只回答纹理频率组成，三维球形度、表面积/体积比、曲率和边界梯度用于补充形状证据。

### 决策门

先从训练集和独立验证集抽取真实肿瘤、囊肿/低密度结构、术后区域及普通肝实质候选 ROI，比较：

- 径向功率谱、高频能量比、小波能量；
- HU 分布、局部对比度、Laplacian 与边界梯度；
- 三维体积、球形度、表面积/体积比和曲率。

只有当差异跨病例、跨数据域稳定，才进入下列模型实验：候选区域二次判别器 → 高频辅助输入 → 频域—空间双分支。第一选择是低成本二次判别器，并与纯空间判别器、连通域后处理做公平对照。

### 停止条件

- 差异只由一两个病例驱动；
- 使用测试标签挑特征或阈值；
- 简单 HU、体积或连通域规则已达到同等效果；
- 新模块收益只来自更大感受野或更多参数。

## 4. 正常肝定向 masked reconstruction

### 假设

肿瘤体素稀少且部分小肿瘤接近正常肝实质。先学习“正常肝局部在上下文中应是什么样”，可能提升编码器对异常偏离的敏感度。该假设不能创造原图中不存在的对比度，也不能替代肿瘤监督。

### 最小实现

```text
训练集 CT + 肝脏/肿瘤标签
→ 仅在 label=1 的正常肝区域施加多尺度 3D block mask
→ 共享 MedNeXt encoder
→ 轻量 reconstruction decoder 恢复被遮挡 CT
→ 丢弃重建头，以同一分割配置全量微调
```

第一轮固定一个 mask ratio（例如 40%–60%），不做大范围超参数搜索。

### 必需对照

| 组别 | 预训练 | 微调 | 回答的问题 |
|---|---|---|---|
| A | 无 | 固定分割配置 | 原始基线 |
| B | 全体素随机 masked reconstruction | 与 A 相同 | 一般自监督预训练是否有效 |
| C | 正常肝定向 masked reconstruction | 与 A 相同 | 区域定向是否有额外价值 |

如果资源只允许 pilot，可先做 A vs C；但正式论文要归因于“正常肝定向”，必须补 B。划分必须先固定，预训练不能使用 val/test 影像或标签。

### 评价与停止条件

- 主看 tiny/small tumor Recall、case-level 漏检和外部域稳定性，不只看 Overall Dice。
- 若收益只在训练集、单一 seed 或单一数据域出现，不升级为主线。
- 若一般随机遮挡与正常肝定向相当，只能归因为一般预训练。
- 完整 3D diffusion 只在遮挡重建已经证明有效后考虑，否则训练和采样成本 ROI 过低。

## 5. 统一研究纪律

每个候选模块在进入论文前必须能写成同一条链：

```text
观察到的失败现象
→ 可证伪假设
→ 最小机制
→ 单变量与成本匹配对照
→ 多病例/多域证据
→ 明确的适用边界和失败条件
```

无法形成这条链的模块应停留在想法库，不进入 proposed method。
