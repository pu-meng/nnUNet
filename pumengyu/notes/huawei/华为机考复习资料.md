# 1. 基础模型

## 1.1 决策树（Decision Tree）

按特征一步步做判断，像流程图：

```
                  年龄 > 30?
                 /           \
               是               否
              /                   \
        收入 > 5万?             学历 = 本科?
        /       \               /         \
      是          否           是            否
    批贷款      不批          批贷款        不批
```

- 每个节点选**最能区分数据**的特征来分裂（用基尼系数或信息增益衡量）
- 叶子节点就是最终答案
- 优点：可解释性强，能看到决策过程
- 缺点：容易过拟合，树太深就把训练数据"背"下来了
- 连续值(年龄,收入):
算法把可能的切分点都试一遍,找最优阈值,如年龄在[0,30]之间,算法会尝试[0,1],[1,2],[2,3]...[29,30]这些切分点,每个切分点计算一次基尼/信息增益,选得分最高的;

阈值也是自动决定的,每个候选阈值都算一遍基尼/信息增益,选择得分最好的那个阈值;
  $$\text{Gini}(节点) = 1 - \sum\limits^{n}\limits_{i=1} p_i^2$$   
   例子：节点里有10个样本，6个批贷款，4个不批：                       
  p_批 = 0.6,  p_不批 = 0.4
  Gini = 1 - (0.6² + 0.4²) = 1 - (0.36+0.16) = 0.48   

  选择让基尼系数最小的特征和阈值.比如100个类别,如果高度集中到少数几个类别,那么基尼系数就小;

  信息增益公式    
              
  $$\text{InfoGain}(D, A) = H(D) - \sum_{v} \frac{|D_v|}{|D|} H(D_v)$$

  具体例子（10个样本，6批4不批，按"收入>5万"分裂）：                                                 
分裂前：
  H(D) = -(0.6·log₂0.6 + 0.4·log₂0.4) = 0.971                                           
分裂后：
    左(收入>5万，7个)：5批2不批 → H = 0.863                                   
    右(收入≤5万，3个)：1批2不批 → H = 0.918                                                 
  加权熵 = 7/10 × 0.863 + 3/10 × 0.918 = 0.880 
  信息增益: 0.971 - 0.880 = 0.091

熵$H(D)$:

$H(D) = -\sum_{i=1}^{n} p_i \log_2 p_i$

加权熵(分裂后):

$H_{after}=\sum_{v\in{左,右}}\frac{|D_v|}{|D|}\cdot H(D_v)$


划分决策树,每个节点只管自己的那份数据,也就是第二层可能不是都按照一个特征进行的划分;

## 1.2 随机森林（Random Forest）

在决策树基础上加两层随机，变成集成模型：

- **数据随机**：每棵树用 Bootstrap 有放回采样的子集
- **特征随机**：每次分裂只随机选部分特征

```
原始数据
   ↓ Bootstrap采样
子集1  子集2  ...子集n
  ↓      ↓         ↓
树1    树2    ...  树n   ← 并行训练，互不干扰
            ↓
     投票（分类）/ 平均（回归）
```

- 优点：抗过拟合、不需要特征归一化、可输出特征重要性
- 缺点：可解释性比单棵决策树差，速度比单树慢

类比excel数据,就是对行和列进行随机挑选,然后训练多个决策树,最后投票/平均.

## 1.3 逻辑回归（Logistic Regression）

**名字叫回归，实际做分类**，在线性回归外面套一个 sigmoid：

$$\hat{y} = \text{sigmoid}(w_1x_1 + w_2x_2 + ... + b) = \frac{1}{1+e^{-z}}$$

```
输入特征 → 加权求和 → sigmoid → 输出0~1的概率 → 设阈值0.5 → 0或1
```

- sigmoid 把任意实数压缩到 (0,1)，可以理解为概率
- 本质是学一条**线性决策边界**
- 优点：简单、快、可解释、输出概率
- 缺点：只能处理线性可分问题，复杂非线性关系学不了

**在 Stacking 中用作元模型**：学习"给各子模型的预测结果加权组合"，刚好是线性加权，逻辑回归完美胜任。

---

## 1.4 KNN（K-Nearest Neighbors，K近邻）

**没有训练过程**，预测时直接找最近的K个邻居投票：

```
新样本来了 → 计算它和所有训练样本的距离
           → 找最近的K个
           → K个里哪个类别多就预测哪个（分类）
           → 或取K个的平均值（回归）
```

- K=1：最近邻居是啥就是啥，容易过拟合
- K=N：所有样本投票，等于预测最多数类别，欠拟合
- K一般取奇数，防止平票

| 对比 | 说明 |
|------|------|
| 优点 | 简单直觉，无需训练，天然支持多分类 |
| 缺点 | 预测慢（要算所有距离），内存大，高维数据效果差 |
| 适用 | 小数据集、低维特征、快速验证基线 |

# 2. 集成学习

将多个不同或相同的基础模型组合起来，通过加权平均、投票等方法，得到最终的预测结果。集成学习可以提升模型的稳定性和泛化能力。

集成学习分为三大类：**Boosting**、**Bagging**（并行训练，投票/平均）、**Stacking**

## 2.1 Bagging（Bootstrap Aggregating，自举聚合）

```
原始数据集
   ↓ 有放回随机采样
子集1  子集2  子集3  ...子集n
  ↓      ↓      ↓        ↓
模型1  模型2  模型3  ...模型n   ← 并行，互不干扰
         ↓
    投票（分类）/ 平均（回归）
         ↓
       最终结果
```
每个子集有放回的采样,子集有重叠,

最终结果,分类任务 $\rightarrow$投票,
回归任务 $\rightarrow$平均

典型代表:随机森林.


## 2.2 Boosting（提升）

```
原始数据集
   ↓
模型1
   ↓
误差计算
   ↓
数据权重调整
   ↓
模型2,重点学习上一轮的错误,找出新的错误
   ↓
误差计算
   ↓
数据权重调整
   ↓
...
   ↓
最终结果
```
|机制|描述|
|---|---|
|样本权重调整|模型1预测对的样本权重降低,预测错的样本权重提高|
|模型权重|表现好的模型在最终投票时权重更大|
|每轮模型独立|每个模型是全新训练的,不共享参数,只是训练数据的分布变了|
|每轮模型种类|可以不同,也可以相同,但是实践中几乎都用同一种,AdaBoost/XGBoost默认动用决策树,且一般是浅树(深度1-3),原因是弱分类器叠加才能"提升",用强模型反而容易过拟合|


Boosting的思路:

一堆"刚好比瞎猜好一点的模型,叠加起来,就能有很好的效果."

代表:AdaBoost,XGBoost,LightGBM.
 
|Boosting的经典例子|思路|
|---|---|
|AdaBoost(自适应提升)|每轮训练后调整样本权重,错误样本权重增大,下一轮模型专注于这些难样本,最终各个模型加权投票,表现好的模型权重更大.分类器通常是深度为1的决策树|
|XGBoost(极端梯度提升)|每轮新模型拟合上一轮的残差,最终预测是所有模型输出累加,支持二阶导数优化,内置正则化过拟合,速度快,比赛首选|
|LightGBM(轻量梯度提升)|思路和XGBoost一样,但是对速度进行了大量优化,叶子优先生长,而非按层生长,更快更准,更适合工业大数据,占据内存更少|

XGBoost: X是extrme(极端的,极致的);G(Gradient,梯度);Boost(提升)

### 2.2.1 XGBoost 的原理

第一轮:模型1预测房价
真实:[100,200,300,400,500]
预测:[110,190,290,390,490]

残差:真实-预测=[-10,10,-10,10,-10]

第二轮:模型2预测残差,把残差当成新的"标签"来训练模型2;就是把误差当作标签,训练下一个模型去预测这个误差

真实:[-10,10,-10,10,-10]
预测:[-8,9,-8,9,-8]

残差:[2,-1,2,-1,2]

第三轮:模型3预测残差
真实:[2,-1,2,-1,2]
预测:[2,-1,2,-1,2]

残差:[0,0,0,0,0]

**XGBoost 二阶导数优化**

XGBoost 对损失函数做泰勒二阶展开，每个样本同时计算一阶导 $g$（方向）和二阶导 $h$（步长），更新量 = $-g/h$。

普通梯度下降:新参数=旧参数-lr$\times$g,lr是人工设的固定学习率

牛顿法:新参数=旧参数-$\frac{g}{h}$,学习率变成自适应的$1/h$


**XGBoost的正则化,L1和L2正则化:**
  $\Omega(f) = \gamma T + \frac{1}{2}\lambda \sum\limits_{j=1}\limits^{T}       
  w_j^2$
  $\gamma$是叶子节点个数的惩罚系数,$T$是叶子节点个数, $\lambda$是正则化系数, $w_j$是叶子节点的权重,防止某个叶子节点权重太高;
$T$不是常数,训练时动态变化,$\gamma$控制节点分裂的容易程度,$\gamma$越大,分裂越难,树越浅.

**为什么神经网络不用：** 神经网络参数量百万级，二阶导需要 Hessian 矩阵（参数量²），存都存不下。XGBoost 每个样本只有一个输出值，二阶导只是一个标量，代价极低。

**常见损失函数的一阶/二阶导：**

| 损失函数 | $g$（一阶） | $h$（二阶） | 说明 |
|----------|------------|------------|------|
| MSE: $(y-\hat{y})^2$ | $2(\hat{y}-y)$ | $2$（常数） | 二阶无额外信息 |
| 二元交叉熵 | $p - y$ | $p(1-p)$ | 每个样本不同 |
| 多分类交叉熵 | $p_k - y_k$ | $p_k(1-p_k)$ | 每个样本不同 |


### 2.2.2 LightGBM（轻量梯度提升）

核心优化:

1.直方图算法:
连续特诊分箱,内存占用降;
XGBoost的连续特征切分,比如样本值为:[1.2,3.5,3.6,...]一共n个,那么取相邻值计算中点,作为候选阈值,n个样本选出n-1个候选阈值;


**LightGBM**:
同样的数据,按照值域分成256个等宽的水桶;
具体是先找到值域,min=,max=,然后(min,max)分成256个等宽的区间,然后每个样本,找到它属于哪个区间,然后这个区间里所有样本,都算作这个样本的候选阈值;

**每个桶不存原始值,存的是**:该桶的样本数count、该桶所有样本的梯度之和sum_g、二阶导之和sum_h;
原始值丢弃,只保留统计量;候选阈值 = 桶的右边界,共256个,而不是n-1个;

**梯度(g,h)如何计算（在建树之前算好）:**

每轮建树前,先用当前预测值ŷ对每个样本算梯度:
g是一阶导数,h是二阶导数
  交叉熵: g = ŷ - y,  h = ŷ(1-ŷ)
  MSE:    g = 2(ŷ-y), h = 2



梯度和特征值无关,只由预测误差决定;特征值只决定样本落入哪个桶.
每个桶的,g_桶1=每个样本的g相加, h_桶1=每个样本的h相加.
**Gain的计算（每次分裂永远是二分）:**

试"在桶k处分裂" = 左边取桶1~k,右边取桶k+1~末尾:

  左边累加: sum_g左 = g_桶1 + g_桶2 + ... + g_桶k
            sum_h左 = h_桶1 + h_桶2 + ... + h_桶k
  右边 = 总和 - 左边（不用重新算）

  Gain = sum_g左²/sum_h左 + sum_g右²/sum_h右 - sum_g总²/sum_h总
         ↑左边得分          ↑右边得分          ↑不分裂时的得分

减去总的是因为:Gain>0才说明分裂有收益;Gain<γ就不分裂(正则化惩罚)

扫描所有切分点(前缀累加,只扫一遍):
  试桶1: 左=桶1,       右=桶2~5 → Gain_1
  试桶2: 左=桶1+2,     右=桶3~5 → Gain_2
  试桶3: 左=桶1+2+3,   右=桶4~5 → Gain_3
  试桶4: 左=桶1+2+3+4, 右=桶5   → Gain_4
  → 选Gain最大的切分点,用其右边界作为阈值,切成左右两组

**叶子输出值:** w = -sum_g / sum_h
**更新预测值:** ŷ += lr × w → 用新ŷ重新算g,h → 建下一棵树,

这里的lr是额外的收缩系数



2.Leaf-wise:

Leaf-wise:叶子优先生长;层优化(Level-wise)

比如当前所有叶子:

- 叶子A:根据所有特征最优增益0.8
- 叶子B:根据所有特征最优增益0.6
- 叶子C:根据所有特征最优增益0.4
- 最终只选择分裂叶子A,因为A的增益最大,其他叶子不管.

XGBoost(层优化):每层所有节点都分裂一次;

LightGBM(叶子优先):每次只分裂当前增益最大的叶子,


3.Goss采样:
保留梯度大的难样本


**GBDT(Gradient Boosting Decision Tree,梯度提升决策树):**
归类:Boosting集成学习,串行训练

XGBoost/LightGBM都是GBDT的变种,

**核心思路**:
每轮新树专门拟合上一轮的残差（负梯度）
     
  模型1 → 预测值，算残差                     
  模型2 → 拟合残差，再算残差              
  模型3 → 拟合残差...           
  最终 = 所有树的输出累加 

二阶导自适应调整每个样本的更新幅度，MSE 的 h=2 是常数，分类任务才是二阶导真正发挥作用的地方。

**阶数越高越精确？** 是的，这是泰勒展开的思想，但三阶以上边际收益急剧下降，二阶是性价比最高的截断点。
|数据类型|适合的模型|
|---|---|
|表格数据(Excel那种)|XGBoost,LightGBM,随机森林|
|图像数据/3D体数据|CNN/Transformer|
|文本数据(文章)|RNN,LSTM,Transformer,BERT/GPT|
BERT/GPT都是网络架构和UNet是同一个层面的东西

BERT:Transformer的encoder部分,处理文本
GPT:Transformer的decoder部分,生成文本

## 2.3 Stacking（堆叠法）

```
原始数据
   ↓
第一层（多个不同类型的模型）：
  决策树   SVM   神经网络   KNN
    ↓       ↓       ↓       ↓
    预测1  预测2   预测3   预测4
              ↓
    把这4个预测值拼成新的特征矩阵
              ↓
        第二层：元模型（如逻辑回归）
              ↓
           最终输出
```

第一层模型尽量多样化，差异越大越好
元模型学习"怎么综合利用这些预测"
效果通常最强，但最复杂、最慢

### 2.3.1 总结

这三个都可以做分类和回归,内部都在做回归,最后根据任务类型;
回归任务$\rightarrow$直接输出累加结果的数值;

分类任务$\rightarrow$套一个sigmoid/softmax$\rightarrow$输出概率$\rightarrow$0或1.


# 3. 过拟合的常见解法与优缺点分析

> **过拟合**：模型在训练数据上表现优秀，但在新数据上表现差的现象（俗称"书呆子模型"）

---

## 3.1 六大解法对比

| # | 方法 | 核心思路 | ✅ 优点 | ❌ 缺点 |
|---|------|----------|---------|---------|
| 1 | **数据增强** | 增加样本多样性；强迫学习本质特征 | 根本提升泛化；无需新数据 | 结构化数据受限；可能引入噪声 |
| 2 | **正则化 (L1/L2)** | 限制参数值；降低复杂度 | 实现简单广泛适用；L1特征选择/L2平滑 | 需调参λ；过大欠拟合 |
| 3 | **特征选择** | 删除噪声特征；减少冗余 | 降低计算成本；提升可解释性 | 激进删除丢信息；可能导致偏差 |
| 4 | **Dropout** | 随机关闭神经元；减少依赖 | 提升鲁棒性；类集成效果 | 训练时间延长；推理需关闭 |
| 5 | **早停法** | 监控验证集损失；适时停止训练 | 无需调参省资源；避免过度训练 | 依赖验证集代表性；可能过早停止 |
| 6 | **降低复杂度** | 减少网络层数/神经元；改用简单模型 | 彻底避免噪声敏感；模型更轻量 | 过度简化欠拟合；丢失非线性能力 |

---

# 4.聚类学习

## 常见的聚类算法有哪些？如何评价聚类效果？

### 1.1、什么是聚类？

聚类是一种**无监督学习**方法，将相似的样本自动归为一组，无需提前标注标签。

---

### 1.2、五大常见聚类算法（完整版）

| 算法 | 核心思想 | 优点 | 缺点 | 典型案例 |
|------|----------|------|------|----------|
| **K-Means** | 基于距离划分，随机选K个中心迭代更新 | 简单高效 | 需预设K，对异常值敏感 | 用户分群 |
| **DBSCAN** | 基于密度，核心点邻域密度扩展 | 任意形状，抗噪声 | 参数敏感 | 地理聚类 |
| **层次聚类** | 逐步合并/分裂，形成树状结构 | 无需预设K | 计算复杂度高 | 基因分析 |
| **高斯混合模型（GMM）** | 多个高斯分布混合生成数据 | 软分配，概率输出 | 需假设分布形式 | 语音识别 |
| **均值漂移（Mean Shift）** | 以随机点为滑动窗口中心，反复移向窗口内点的均值，直至收敛到密度最高处 | **自动确定簇数量**，对噪声鲁棒 | 窗口大小难调优，效率低 | 图像分割（相似颜色区域聚合） |


#### 1.2.1 K-Means:
- 初始随机选择K个中心点
- 按照距离把所有点分配到最近的中心,成为一个簇
- 对每个簇,取所有点的均值,得到新的K个中心点
- 用新的中心点再次按照距离重新分配
- 不断迭代,一直到中心不再移动

#### 1.2.2 DBSCAN(Density-Based Spatial Clustering of Applications with Noise):
给定两个超参数MinPts和$\varepsilon$:

- 第一步,对每个点,数它的$\varepsilon$范围内有几个点
- 如果超过MinPts,则该点为核心点,先把所有点区分成核心点和非核心点;
- 下一步,核心点先把范围内的点都拉进这个簇,
- 新加入的点如果也是核心点,就继续把它范围内的点加入簇,没有新点加入,这个簇结束;
- 最后所有都处理完,未分配的点,就是噪声;边界点就是被分配,但是不是核心点的点;

#### 1.2.3 层次聚类:
- 初始每个点是一个簇
- 不断合并距离最近的两个簇,直到只剩下一个簇

#### 1.2.4 高斯混合模型（GMM）:
- 假设数据服从K个高斯分布的混合
---

##### 三、均值漂移算法原理补充

$$\text{新中心} = \frac{\sum_{x_i \in N(x)} K(x_i - x)\, x_i}{\sum_{x_i \in N(x)} K(x_i - x)}$$

三步流程：
1. 以随机点为**滑动窗口中心**
2. 计算窗口内所有点的均值，将中心**移至该均值点**
3. 重复迭代，直至收敛到**局部密度最高处**

> 与 DBSCAN 的关键区别：DBSCAN 需手动设定密度阈值 $\varepsilon$，而均值漂移通过带宽（窗口大小）**自动发现簇的数量**，更适合簇形状不规则且数量未知的场景。

---

#### 3 四、聚类效果评价

###### ✅ 内部指标（无标签时使用）

- **轮廓系数（Silhouette）**
  - 范围 $[-1, 1]$，越接近 1 越好
  - 公式：$s(i) = \dfrac{b(i) - a(i)}{\max(a, b)}$
  - $a(i)$ 为样本与同簇其他点的平均距离，$b(i)$ 为与最近邻簇的平均距离

- **Calinski-Harabasz 指数（CH）**：越大越好，评估簇间分离度与簇内紧密度之比

- **Davies-Bouldin 指数（DBI）**：越小越好，评估簇内散度与簇间距离的比值

###### ✅ 外部指标（有真实标签时使用）

- **调整兰德指数（ARI）**：范围 $[-1, 1]$，越大越好，衡量与真实分配的相似度
- **归一化互信息（NMI）**：范围 $[0, 1]$，越大越好

---

##### 五、一句话总结

> 聚类是无监督学习，相似样本分组。评价靠**内部指标**（如轮廓系数）和**外部指标**（如调整兰德指数），结合业务实际判断。

### 5.2.1 Lagrange 插值
- **思想**：用 $n+1$ 个节点唯一确定一个 $n$ 次多项式
- **公式**：$L(x) = \sum_{i=0}^{n} y_i \prod_{j \neq i} \frac{x - x_j}{x_i - x_j}$
- **优点**：构造简单，无需导数信息
- **缺点**：高次 + 等距节点 → **Runge 现象**（端点剧烈振荡）
- 假设在区间[-1,1]上插值,左断电-1,右端点1,中间的点叫做节点,也是采样的点;
- 端点=区间最左边和最右边的点


> **Runge 现象**：以 $f(x)=\frac{1}{1+25x^2}$ 为例，节点越多误差反而越大，根本原因是高次基函数在靠近端点的区域处数值极大导致误差放大。解决方案：改用 Chebyshev 节点，或换插值方法。更类似边界区域震荡


```python
import numpy as np

# 第一步：定义目标函数
def f(x):
    return 1 / (1 + 25 * x**2)
# 为什么用这个函数：它是 Runge 1901 年提出的经典反例
# 在 x=0 处值为 1，在 x=±1 处值为 1/26 ≈ 0.038，函数本身非常光滑

# 第二步：定义 Lagrange 插值
def lagrange(x_nodes, y_nodes, x):
    n = len(x_nodes)
    result = 0
    for i in range(n):
        # 计算第 i 个基函数 ℓ_i(x)
        Li = 1.0
        for j in range(n):
            if j != i:
                Li *= (x - x_nodes[j]) / (x_nodes[i] - x_nodes[j])
        result += y_nodes[i] * Li
    return result

# 第三步：用 5 个节点插值，在 x=0.95 处比较
n = 5
x_nodes = np.linspace(-1, 1, n)   # 等距节点：-1, -0.5, 0, 0.5, 1
y_nodes = f(x_nodes)               # 对应函数值

x_test = 0.95
print(f"真实值  f(0.95) = {f(x_test):.6f}")
print(f"5节点插值结果   = {lagrange(x_nodes, y_nodes, x_test):.6f}")

# 第四步：换成 21 个节点，同样在 x=0.95 比较
n = 21
x_nodes = np.linspace(-1, 1, n)
y_nodes = f(x_nodes)
print(f"21节点插值结果  = {lagrange(x_nodes, y_nodes, x_test):.6f}")

# 你会看到：
# 真实值        ≈ 0.042
# 5节点          ≈ 0.26   （误差大，但在同一量级）
# 21节点         ≈ 40     （误差比真实值大了近1000倍）
```
Rung现象发生需要同时满足两个条件:
- 第一,函数在复平面上有靠近实轴的奇点,越靠近越容易震荡
- 第二,等距节点导致边界处基函数值随着节点指数增大而把第一个问题放大;

### 5.2.2 Hermite 插值
- **思想**：在 Lagrange 基础上，同时匹配**函数值**和**导数值**
- **条件**：每个节点给定 $f(x_i)$ 和 $f'(x_i)$
- **连续性**：分段时保证 $C^1$（一阶导连续），不保证 $C^2$
- **优点**：曲线更贴合原函数，局部性强（修改一段不影响其他段）
- **缺点**：需要在每个节点**预先知道导数值**

**一般形式**

给定 $n+1$ 个节点，每个节点同时给定 $f(x_i)$ 和 $f'(x_i)$，插值多项式为：

$$H(x) = \sum_{i=0}^{n} f(x_i)\, h_i(x) + \sum_{i=0}^{n} f'(x_i)\, \hat{h}_i(x)$$

其中两类基函数为：

$$h_i(x) = \left[1 - 2(x - x_i)\ell_i'(x_i)\right]\ell_i^2(x)$$

$$\hat{h}_i(x) = (x - x_i)\,\ell_i^2(x)$$

$\ell_i(x)$ 为 Lagrange 基函数：$\ell_i(x) = \prod_{j \neq i}\dfrac{x - x_j}{x_i - x_j}$

> **基函数性质**：$h_i(x_j)=\delta_{ij}$，$h_i'(x_j)=0$；$\hat{h}_i(x_j)=0$，$\hat{h}_i'(x_j)=\delta_{ij}$
> 即 $h_i$ 只负责函数值，$\hat{h}_i$ 只负责导数值，互不干扰。

#### 两点三次 Hermite（分段时每段用这个）

令 $h = x_{i+1}-x_i$，$t = \dfrac{x-x_i}{h} \in [0,1]$，则：

$$H(x) = f_i\,\phi_0(t) + f_{i+1}\,\phi_1(t) + h f'_i\,\psi_0(t) + h f'_{i+1}\,\psi_1(t)$$

四个基函数：

$$\phi_0(t)=(1-t)^2(1+2t), \quad \phi_1(t)=t^2(3-2t)$$

$$\psi_0(t)=t(1-t)^2, \quad \psi_1(t)=t^2(t-1)$$

| 基函数 | 在 $t=0$ | 在 $t=1$ | 导数在 $t=0$ | 导数在 $t=1$ | 作用 |
|--------|---------|---------|------------|------------|------|
| $\phi_0$ | 1 | 0 | 0 | 0 | 左端函数值 |
| $\phi_1$ | 0 | 1 | 0 | 0 | 右端函数值 |
| $\psi_0$ | 0 | 0 | 1 | 0 | 左端导数值 |
| $\psi_1$ | 0 | 0 | 0 | 1 | 右端导数值 |

> 四个条件（$f_i, f_{i+1}, f'_i, f'_{i+1}$）唯一确定一段三次多项式，
> 各段独立构造，修改一段完全不影响其他段。

#### 5.2.3 两点三次 Hermite 公式（最常用）

令 $h = x_{i+1}-x_i$，$t = \dfrac{x-x_i}{h} \in [0,1]$，则：

$$H(x) = f_i\,\phi_0(t) + f_{i+1}\,\phi_1(t) + hf'_i\,\psi_0(t) + hf'_{i+1}\,\psi_1(t)$$

四个基函数：

$$\phi_0(t)=(1-t)^2(1+2t), \quad \phi_1(t)=t^2(3-2t)$$

$$\psi_0(t)=t(1-t)^2, \quad \psi_1(t)=t^2(t-1)$$

> 四个条件（$f_i, f_{i+1}, f'_i, f'_{i+1}$）唯一确定一段三次多项式，
> 各段独立构造，修改一段完全不影响其他段。
---
### 5.2.4 三次样条插值（工程最常用 ✅）

#### 5.2.4.1 核心思想

分段三次多项式 + 全局光滑性约束，自动确定导数。
每段各自是三次多项式，但段与段之间要"缝合"得足够光滑。


---

**为什么要分段？**

给定 $n+1$ 个数据点，如果用一个多项式拟合所有点，
次数会达到 $n$，节点越多次数越高，就会出现 Runge 现象。

解决办法：不用一个多项式管全部，
而是**相邻两个节点之间**单独用一个三次多项式来拟合，
这就叫"分段"。

例如有 5 个节点 $x_0, x_1, x_2, x_3, x_4$，
就分成 4 段：$[x_0,x_1],\ [x_1,x_2],\ [x_2,x_3],\ [x_3,x_4]$，
每段各自是一个三次多项式，次数永远是 3，不随节点数增加。

---

**分段之后出现了什么新问题？**

每段是独立构造的，在节点处两段会"撞在一起"，
如果不加约束，两段在节点处可能：
- 函数值不相等（曲线断开）
- 斜率不一样（曲线有折角）
- 弯曲程度突变（曲线看起来不自然）

所以需要在每个节点处强制要求相邻两段"接得上"，
这就是光滑性约束，具体是要求：

$$S_{i-1}(x_i) = S_i(x_i) \quad \text{（接得上，不断开）}$$

$$S_{i-1}'(x_i) = S_i'(x_i) \quad \text{（斜率一样，没有折角）}$$

$$S_{i-1}''(x_i) = S_i''(x_i) \quad \text{（弯曲程度一样，视觉光滑）}$$

"缝合"就是这三个等式，保证两段在节点处完全一致。

---

**"自动确定导数"是什么意思？**

Hermite 插值需要你手动给出每个节点处的导数值 $f'(x_i)$，
才能构造插值多项式。

三次样条不需要你给导数，
它通过上面三个光滑条件列出方程组，
联立求解，**自动算出**每个节点处的导数和弯矩 $M_i = S''(x_i)$，
你只需要给函数值 $y_i$，剩下的由方程组决定。
---

#### 基本定义（逐条展开）

**条件1：每段是三次多项式**

在每个子区间 $[x_i, x_{i+1}]$ 上：

$$S_i(x) = a_i + b_i(x-x_i) + c_i(x-x_i)^2 + d_i(x-x_i)^3$$

共 $n$ 段，每段 4 个系数，总共 $4n$ 个未知数需要确定。

**条件2：插值条件（通过所有数据点）**

$$S(x_i) = y_i \quad i = 0, 1, \ldots, n$$

即曲线必须经过每一个给定的数据点，提供 $n+1$ 个方程。

**条件3：光滑条件（内节点处的连续性）**

在每个内节点 $x_i$（$i=1,\ldots,n-1$）处，相邻两段必须满足：

$$S_{i-1}(x_i) = S_i(x_i) \quad \text{（函数值连续，}C^0\text{）}$$

$$S_{i-1}'(x_i) = S_i'(x_i) \quad \text{（一阶导连续，}C^1\text{）}$$

$$S_{i-1}''(x_i) = S_i''(x_i) \quad \text{（二阶导连续，}C^2\text{）}$$

> **为什么要二阶导连续**：一阶导连续保证曲线没有折角，
> 二阶导连续保证曲率连续，曲线视觉上完全光滑，
> 这是三次样条最核心的特征，也是区别于 Hermite 插值（只有 $C^1$）的关键。
> 
> **考试判断口诀**：看到"节点处二阶导数不连续" → 直接判错，
> 三次样条的定义就是 $C^2$，二阶导不连续就不叫样条。

三个光滑条件共提供 $3(n-1)$ 个方程。

**方程数统计**：

| 来源 | 方程数 |
|------|--------|
| 插值条件 | $n+1$ |
| $C^0$ 连续 | $n-1$ |
| $C^1$ 连续 | $n-1$ |
| $C^2$ 连续 | $n-1$ |
| 合计 | $4n-2$ |

未知数 $4n$ 个，方程 $4n-2$ 个，还差 **2个方程**，由边界条件补全。

---

#### 三弯矩方程（核心公式）

设 $M_i = S''(x_i)$（称为弯矩），$h_i = x_{i+1} - x_i$。

由 $C^2$ 连续条件推导出对每个内节点成立的方程：

$$h_{i-1}M_{i-1} + 2(h_{i-1}+h_i)M_i + h_i M_{i+1} = 6\left(\frac{y_{i+1}-y_i}{h_i} - \frac{y_i-y_{i-1}}{h_{i-1}}\right)$$

这是一个关于所有 $M_i$ 的**三对角线性方程组**，
解出所有 $M_i$ 后即可还原每段的四个系数 $a_i, b_i, c_i, d_i$。

每段系数由 $M_i$ 显式给出：

$$a_i = y_i$$

$$b_i = \frac{y_{i+1}-y_i}{h_i} - \frac{h_i}{6}(M_{i+1}+2M_i)$$

$$c_i = \frac{M_i}{2}$$

$$d_i = \frac{M_{i+1}-M_i}{6h_i}$$

---

#### 边界条件（补全最后2个方程）

| 类型 | 条件 | 含义 |
|------|------|------|
| 自然样条 | $M_0 = M_n = 0$ | 两端曲率为零，端点处"自然弯曲" |
| 固支样条 | $S'(x_0)=f'_0,\ S'(x_n)=f'_n$ | 两端斜率已知，需额外给定 |
| 周期样条 | $S'(x_0)=S'(x_n),\ S''(x_0)=S''(x_n)$ | 用于周期函数 |

---

#### 为什么能避免 Runge 现象

Lagrange 高次插值用**一整根**高次多项式拟合所有节点，
次数越高，端点处基函数值越大，导致边界振荡。

三次样条**永远只用三次多项式**，不管节点有多少，
每段只在局部 $[x_i, x_{i+1}]$ 上构造，次数不随节点数增加，
端点处不存在基函数爆炸的问题，因此从结构上就消除了 Runge 现象。

> 类比：Lagrange 是用一根长木棍弯曲穿过所有点，木棍越长越难控制两端；
> 三次样条是用很多短木棍首尾相接，每根只管自己那一段，两端自然不会失控。

---

#### 与 Hermite 插值对比

| 对比项 | Hermite 插值 | 三次样条 |
|--------|-------------|---------|
| 连续性 | $C^1$ | $C^2$ |
| 是否需要导数 | ✅ 每个节点都要给 $f'$ | ❌ 自动确定 |
| 局部性 | 完全局部，改一段不影响其他 | 弱局部，改一点影响全局 |
| 光滑程度 | 一阶导连续，有折曲率 | 二阶导连续，完全光滑 |

### 三种方法横向对比

| 方法 | 匹配条件 | 连续性 | 需要导数 | Runge风险 |
|------|---------|--------|---------|-----------|
| Lagrange | 函数值 | $C^0$ | ❌ | ⚠️ 高次时有 |
| Hermite | 函数值 + 导数值 | $C^1$ | ✅ 必须给 | 较小 |
| 三次样条 | 函数值 + 全局光滑 | $C^2$ | ❌ 自动确定 | ✅ 无 |
