### 4.3 算法模板
```python
# DFS模板
def dfs(node, visited):
    if not node or node in visited:
        return
    visited.add(node)
    # 处理当前节点
    for neighbor in node.neighbors:
        dfs(neighbor, visited)

# BFS模板
def bfs(start):
    queue = deque([start])
    visited = set([start])
    while queue:
        node = queue.popleft()
        # 处理当前节点
        for neighbor in node.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

# 动态规划模板
def dp_problem(nums):
    n = len(nums)
    dp = [0] * n
    dp[0] = nums[0]
    for i in range(1, n):
        dp[i] = max(dp[i-1] + nums[i], nums[i])
    return max(dp)
```

## 六、考试技巧

### 6.1 时间分配建议
- **第一题**：20-30分钟（确保100分）
- **第二题**：40-50分钟（争取80+分）
- **第三题**：60-70分钟（争取部分分数）
- **检查**：10分钟

### 6.2 解题步骤
1. **审题**（5分钟）
   - 理解题意
   - 确定输入输出格式
   - 分析边界条件

2. **设计**（10分钟）
   - 选择合适的数据结构
   - 设计算法流程
   - 考虑时间空间复杂度

3. **编码**（20-30分钟）
   - 模块化编写
   - 添加必要注释
   - 保持代码整洁

4. **测试**（10分钟）
   - 测试样例
   - 边界测试
   - 性能测试

### 6.3 常见陷阱
1. **输入输出格式**
   - 注意多组测试数据
   - 注意空格和换行

2. **边界条件**
   - 空输入
   - 极大/极小值
   - 重复元素

3. **性能优化**
   - 避免O(n²)算法
   - 使用合适的数据结构
   - 注意内存限制
