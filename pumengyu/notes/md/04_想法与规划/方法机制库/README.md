# 方法机制库

这里保存可复用的方法原理，不保存某次实验的完成状态或论文结果。

| 文件 | 内容 |
|---|---|
| [`架构机制.md`](架构机制.md) | MLA、Depthwise Conv、MoE、Attention、Conv、SSM 和条件计算等架构机制 |
| [`通用方法.md`](通用方法.md) | 多尺度、自监督、生成模型、训练技巧与跨领域方法 |

## 新方法记录模板

```markdown
### 方法名（论文，年份）

**问题**：它针对什么已知现象或结构限制？

**包装说法**：论文标题或摘要如何描述？

**真正做了什么**：用 tensor flow、公式或数字说明核心操作。

**核心**：一句话概括机制。

**与当前问题的对应关系**：为什么可能适用于当前 3D 肝肿瘤分割？

**代价与边界**：参数、计算、显存、信息损失和适用条件。

**验证方式**：需要什么公平对照、消融和分组指标？
```

仅“看起来先进”不足以进入实验计划。候选方法必须先说明真实问题、输入输出和验证方式。
