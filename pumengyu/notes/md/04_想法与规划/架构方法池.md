# Attention（Transformer 核心）

**真正做了什么**：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d}}\right)V$$

$QK^T$ 是每个位置和所有位置的点积相关性矩阵，**由输入内容动态生成**，不同样本权重不同。

```
卷积：权重固定，训练完不变
Attention：权重 = QK^T，每次输入都重新算
```

**核心**：内容自适应的动态全局权重，这是和卷积的根本区别，不是感受野大小。

##### Transformer 的本质改变

###### 稀疏注意力（Sparse Attention，Longformer / BigBird，2020）

**问题**：标准 Attention $QK^T$ 是 $N \times N$ 的矩阵，序列长 N 大时内存和计算都是 $O(N^2)$，根本跑不动。

**真正做了什么**：不做全局 $N \times N$，每个 token 只和一小部分 token 做 attention：

```
局部窗口：每个 token 只看相邻 k 个 token     → O(N·k)
全局 token：少量特殊 token（如 [CLS]）和所有位置做 attention
稀疏模式：两者组合，覆盖局部 + 少量全局
```

$$\text{稀疏}QK^T \in \mathbb{R}^{N \times k} \quad \text{而非} \quad \mathbb{R}^{N \times N}$$

**核心**：$O(N^2) \rightarrow O(N \cdot k)$，代价是放弃任意两个 token 之间的直接交互，只保留局部和少量全局。

---

###### 滑窗注意力（Window Attention，Swin Transformer，2021）

**真正做了什么**：把特征图切成不重叠的小窗口（如 $7 \times 7$），只在窗口内部做 Attention；下一层把窗口 shift 半个窗口，让相邻窗口信息交换：

```
Layer 1：窗口 [0:7, 0:7]、[0:7, 7:14]... 各自独立做 Attention
Layer 2：shift，窗口 [3:10, 3:10]... 跨越上层窗口边界
```

**核心**：把 $O(N^2)$ 降到 $O(N \cdot w^2)$（w 是窗口大小），跨窗口靠 shift 间接传递，不是真正的全局 Attention。

**和稀疏注意力的区别**：Swin 是硬分块（窗口内全 Attention），稀疏 Attention 是软稀疏（每个 token 选 k 个位置）。

---

###### 线性注意力（Linear Attention，Performer，2020）

**问题**：softmax 让 $QK^T$ 的计算顺序必须先算 $N \times N$ 的矩阵，再乘 V。

**真正做了什么**：用核函数 $\phi$ 近似 softmax，把计算顺序改成先算 $K^TV$：

$$\text{标准}：\text{softmax}(QK^T)V \quad O(N^2 d)$$

$$\text{线性}：\phi(Q)(\phi(K)^T V) \quad O(N d^2)$$

先算括号里的 $\phi(K)^T V \in \mathbb{R}^{d \times d}$（和 N 无关），再左乘 $\phi(Q)$：

```
N=4096, d=64:
  标准 Attention：4096² × 64 ≈ 10亿次乘法
  线性 Attention：4096 × 64² ≈ 1700万次乘法
```

**核心**：$O(N^2) \rightarrow O(N \cdot d^2)$，代价是用核函数近似替换 softmax，精度有损失。

---

###### Flash Attention（Dao et al., 2022）

**包装说法**：IO-aware exact attention，精确 Attention 的高效实现

**真正做了什么**：**不改公式，改内存访问模式**。

GPU 有两级内存：HBM（显存，大但慢）和 SRAM（片上缓存，小但极快）。标准实现每步都要把中间结果写回 HBM：

```
标准实现：
  QK^T → 写回 HBM（N×N 矩阵，很大）
  softmax → 写回 HBM
  × V → 写回 HBM
  共 3 次大矩阵读写 HBM

Flash Attention：
  按 tile 分块，每块完整算完再写回
  QK^T、softmax、×V 全在 SRAM 里完成
  只有最终结果写 HBM 一次
```

**核心**：结果完全一样（精确），但 HBM 读写次数从 $O(N^2)$ 降到 $O(N)$，速度提升 2-4×，显存从 $O(N^2)$ 降到 $O(N)$。

**和线性 Attention 的区别**：线性 Attention 改了公式（近似），Flash Attention 不改公式（精确），只改实现。

###### GQA / MQA（Grouped/Multi-Query Attention，2019/2023）

**问题**：推理时 KV Cache 随序列长度线性增长，多头情况下每个头都存一份 K、V，显存压力大。

**真正做了什么**：

```
MHA（标准）：H 个头，每头独立 Q/K/V   → KV Cache = H 份
MQA：        H 个头共享同一组 K/V      → KV Cache = 1 份
GQA：        H 个头分 G 组，组内共享 K/V → KV Cache = G 份（G < H）
```

$$\text{KV Cache 显存} = \frac{G}{H} \times \text{MHA}$$

**核心**：Q 保持多头（保证表达能力），K/V 合并共享（减少 Cache），推理显存直降 G 倍。代价是 K/V 表达能力略降，实验证明 G=8 时几乎无损。

##### Conv 的本质改变

###### 空洞卷积（Dilated / Atrous Conv，DeepLab，2015）

**真正做了什么**：卷积核采样位置中间插"空洞"，采样点不再连续：

```
普通 3×3 conv（dilation=1）：
  X X X
  X X X   ← 9 个相邻位置
  X X X

空洞 3×3 conv（dilation=2）：
  X . X . X
  . . . . .
  X . X . X   ← 9 个采样点，但覆盖 5×5 的范围
  . . . . .
  X . X . X
```

**参数量**：完全不变（还是 $k^2 \times C^2$），但感受野从 $k$ 变成 $k + (k-1)(d-1)$。

$$\text{dilation=}d \text{ 的 3×3：感受野} = 2d+1$$

**核心**：参数不增，感受野指数扩大，代价是中间的点没被采样（可能丢失细节）。

**和 Depthwise 大核的区别**：Depthwise 大核连续采样（信息完整），空洞卷积跳跃采样（节省参数但有空洞）。
空洞卷积在2D自然图像分割有效,在3D医学图像被大核depthwise(MedNeXt)替代,

---

###### 可变形卷积（Deformable Conv，DCN，2017）

**真正做了什么**：采样位置不再是固定网格，而是由网络从输入中学出偏移量 $\Delta p$：

```
计算流程：

输入 x: [B, C, H, W]
  ↓
offset_net（一个普通 3×3 conv，C → 18 通道）
  ↓
offsets: [B, 18, H, W]   ← 9个采样点 × 2方向(Δx,Δy) = 18

主卷积滑窗到位置 (h, w) 时：
  查 offsets[:, :, h, w] → 得到该位置专属的 9 对偏移量
  普通采样点：(h+kh, w+kw)
  偏移后采样点：(h+kh+Δx_k, w+kw+Δy_k)  ← 非整数，用双线性插值取值
  对这 9 个位置的值乘以卷积核权重，加和 → 一个输出值

输出: [B, C_out, H, W]   ← 形状和普通卷积完全相同
```

**参数量**：

```
普通 3×3 conv：9 × C × C = 9C²
可变形 conv：
  offset_net：9 × C × 18 = 162C   ← 额外增加
  主卷积：    9C²                  ← 和普通 conv 一样
  总计：      9C² + 162C           ← 比普通 conv 多
```

**可变形 conv 优化的不是效率，而是建模能力**：

| 目标 | 普通 conv | Depthwise | 可变形 conv |
|------|-----------|-----------|------------|
| 节省参数 | 基准 | ✅ 大幅节省 | ❌ 反而增加 |
| 节省计算量 | 基准 | ✅ 大幅节省 | ❌ 反而增加 |
| 采样形状灵活 | ❌ 固定方格 | ❌ 固定方格 | ✅ 内容自适应 |

同样的 9C² 主卷积参数，普通 conv 永远在方格上采，可变形 conv 能采到更相关的位置——**同等参数，信息质量更高**。

**双线性插值（2D）**：偏移量是小数，特征图只有整数位置有值，用周围 4 个邻居加权平均：

```
采样位置 (1.3, 2.7)，找周围 4 个整数点：

       y=2       y=3
x=1  f(1,2)   f(1,3)
x=2  f(2,2)   f(2,3)

α = 1.3-1 = 0.3，β = 2.7-2 = 0.7

先 x 方向插：
  f(1.3, 2) = 0.7×f(1,2) + 0.3×f(2,2)
  f(1.3, 3) = 0.7×f(1,3) + 0.3×f(2,3)
再 y 方向插：
  f(1.3, 2.7) = 0.3×f(1.3,2) + 0.7×f(1.3,3)

= 4 个邻居的加权平均，权重 = 到各点距离的反比
```

**三线性插值（3D）**：多了 z 方向，从 4 个邻居扩展到 8 个邻居体素：

```
采样位置 (1.3, 2.7, 4.2)，α=0.3, β=0.7, γ=0.2

依次在 x→y→z 方向各插一次：
  x 方向插 4 次 → 4 个中间值
  y 方向插 2 次 → 2 个中间值
  z 方向插 1 次 → 最终值

= 8 个邻居体素的加权平均
```

3D 可变形 conv 每采一个点需要查 8 个体素，3×3×3 核有 27 个采样点 → **27×8 = 216 次查表 + 加权求和**，这是 3D 下开销大、很少用的原因。

**核心**：卷积采样形状由输入内容动态决定——检测到细长目标自动横向拉伸，检测到圆形目标自动收缩。不节省参数/计算，优化的是几何建模能力。3D 医学图像里极少用（插值开销大 + 器官形状相对规则）。

##### 替代 Attention 和 Conv 的新范式

###### SSM / Mamba（State Space Model，2023）

**问题**：Attention $O(N^2)$ 太慢，线性 Attention 精度有损，能不能找到既精确又 $O(N)$ 的序列建模方法？

**真正做了什么**：用控制论里的状态空间方程建模序列：

$$h_t = Ah_{t-1} + Bx_t$$
$$y_t = Ch_t$$

$h_t$ 是隐状态，$x_t$ 是输入，$y_t$ 是输出。每个时间步只更新隐状态，不需要看所有历史 token。

**Mamba 的关键改进**（S4 → Mamba）：让 $A, B, C$ 矩阵由输入 $x_t$ 动态生成（Selective SSM）：

```
普通 SSM：A, B, C 是固定参数，对所有 token 一样
Mamba：   A(x_t), B(x_t), C(x_t) 由当前输入决定 → 内容自适应
```

**复杂度**：推理时 $O(N)$（递推），训练时用并行扫描算法也是 $O(N \log N)$，远优于 Attention。

**和 Attention 的本质区别**：
```
Attention：每个位置和所有位置直接交互（全对全）
Mamba：    信息通过隐状态 h 逐步传递（序列递推）
代价：     Mamba 对很久之前的信息有遗忘，Attention 无遗忘
```

**在医学图像的应用**：U-Mamba / SegMamba，用 Mamba 替换 UNet bottleneck 的 Attention，$O(N)$ 复杂度支持更高分辨率的 3D 特征图建模。

##### Conv 的基础结构创新

###### 残差连接（Residual Connection，ResNet，2015）

**问题**：网络层数超过 20 层后，梯度反向传播时逐层相乘越来越小，趋向于 0（梯度消失），深层参数几乎不更新。

**真正做了什么**：在 block 输入和输出之间加一条直连通道：

```
输出 = F(x) + x
         ↑      ↑
    卷积变换   输入直通（恒等映射）
```

反向传播时梯度有两条路：
$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\left(\frac{\partial F}{\partial x} + 1\right)$$

括号里的 $+1$ 保证梯度不会消失——即使 $\frac{\partial F}{\partial x} \approx 0$，梯度仍然能完整流回去。

**核心**：让梯度有一条不经过非线性变换的"高速公路"直通回去，解锁了 100+ 层深网络的训练。所有现代架构（Transformer、ConvNeXt、MedNeXt）都依赖残差连接。

---

###### 通道注意力（Squeeze-and-Excitation，SE Network，2018）

**真正做了什么**：用极少的参数让网络学会"哪些通道更重要"：

```
输入 [B, C, D, H, W]
↓ Global Average Pooling（空间维度压缩）
[B, C, 1, 1, 1]
↓ FC (C → C/r)  → ReLU  → FC (C/r → C)  → Sigmoid
[B, C, 1, 1, 1]   ← 每个通道一个权重 ∈ (0,1)
↓ 逐通道相乘（广播）
输出 [B, C, D, H, W]
```

参数量仅 $\frac{2C^2}{r}$（r=16 时极少），但给每个通道一个全局上下文感知的权重。

**核心**：CNN 里最轻量的全局上下文机制——不用 Attention，用全局池化 + FC 就能让通道自适应重标定。

---

###### 非局部网络（Non-local Network，2018）

**真正做了什么**：在 CNN 中间直接嵌入一个 self-attention 操作：

```
y_i = (1/C(x)) Σ_j f(x_i, x_j) · g(x_j)

f(x_i, x_j) = softmax(θ(x_i)^T · φ(x_j))   ← 和 Attention 的 QK^T 完全等价
g(x_j) = W_g · x_j                            ← 和 Attention 的 V 等价
```

是 ViT 之前，最早把 self-attention 引入图像任务的工作。每个位置和所有位置交互，获得真正的全局感受野。

**核心**：证明 CNN 中间插全局 Attention 是有效的，是从纯 CNN 走向 Transformer 的桥梁。代价是计算量 $O(N^2)$，只能插在分辨率低的深层。

---

###### 结构重参数化（Structural Re-parameterization，RepVGG / RepLKNet，2021）

**真正做了什么**：训练和推理用不同的结构——训练时多分支（表达能力强），推理时合并成单 conv（速度快）：

```
训练时：
  3×3 conv ─┐
  1×1 conv ─┼─ 相加 → 输出
  恒等映射  ─┘

推理时（等价合并）：
  一个 3×3 conv → 输出   ← 参数合并后完全等价，但只有一次 conv
```

合并方法：把 1×1 conv 用 zero-padding 变成 3×3，把恒等映射也变成 3×3（对角为 1 其余为 0），三个 3×3 conv 直接相加权重。

**核心**：训练时的多分支带来更好的优化景观和梯度多样性，推理时合并后不增加任何计算量。训练和推理的结构可以解耦。

##### Transformer 的位置编码创新

###### RoPE（旋转位置编码，RoFormer，2021）

**问题**：标准 Transformer 的位置编码是绝对的（给每个位置加一个固定向量），无法直接表达相对位置关系，且长度外推困难。

**真正做了什么**：把位置信息编码进 Q 和 K 的旋转里，使得 $Q_m \cdot K_n$ 天然只依赖相对位置 $m-n$：

$$Q_m = R_m \cdot q, \quad K_n = R_n \cdot k$$

$$Q_m \cdot K_n = q^T R_m^T R_n k = q^T R_{m-n} k$$

$R_\theta$ 是旋转矩阵，每两个维度一组，旋转角度 = 位置 × 频率：

```
[q_0, q_1] → [q_0·cos(mθ) - q_1·sin(mθ),  q_0·sin(mθ) + q_1·cos(mθ)]
```

**核心**：不需要显式的相对位置矩阵，$QK^T$ 的计算自动包含相对位置信息，且对超出训练长度的位置有更好的外推能力。现代 LLM（LLaMA、DeepSeek）全部用 RoPE。

##### 通用效率范式

###### LoRA（Low-Rank Adaptation，2021）

**问题**：微调大模型需要更新所有参数，显存和计算都是全量，代价极高。

**真正做了什么**：冻结原始权重 $W_0$，只训练两个低秩矩阵的乘积 $\Delta W = BA$：

$$W = W_0 + \Delta W = W_0 + BA$$

$$B \in \mathbb{R}^{d \times r}, \quad A \in \mathbb{R}^{r \times k}, \quad r \ll \min(d, k)$$

```
参数量对比（d=k=4096, r=8）：
  全量微调：4096 × 4096 = 16,777,216
  LoRA：    4096×8 + 8×4096 = 65,536   ← 降低 256×
```

推理时直接合并 $W = W_0 + BA$，无额外计算开销。

**核心**：假设权重更新 $\Delta W$ 是低秩的——实验验证这个假设在大多数任务上成立。用低秩分解大幅降低可训练参数，但保留原模型全部能力。

###### 知识蒸馏（Knowledge Distillation，KD，Hinton 2015）

**真正做了什么**：不用 one-hot 硬标签，用大模型（Teacher）的软概率分布训练小模型（Student）：

```
Teacher 输出：[0.85, 0.10, 0.03, 0.02]   ← 软标签，包含类间相似度信息
硬标签：      [1.00, 0.00, 0.00, 0.00]   ← 只告诉对错，没有关系信息

Loss = α · KL(Student || Teacher) + (1-α) · CrossEntropy(Student, hard_label)
```

Teacher 的软标签隐含了"猫和狗比猫和汽车更像"这类知识，Student 学到的不只是分类结果，而是 Teacher 的"世界观"。

**核心**：压缩模型能力的根本方法，不是让小模型学数据，而是让小模型学大模型的输出分布。医学图像里常用于把大 3D 模型蒸馏成轻量部署版本。

##### MoE 系列：条件计算

###### Expert Choice 路由（2022）

**问题**：标准 MoE 里 token 选 expert，热门 expert 被过度选择，冷门 expert 几乎不用（负载不均），需要额外的均衡 loss。

**真正做了什么**：翻转路由方向——**expert 选 token**，每个 expert 从所有 token 里选 Top-K 个处理：

```
标准 MoE：每个 token 选 Top-2 expert   → 热门 expert 爆满，冷门闲置
Expert Choice：每个 expert 选 Top-K token → 每个 expert 负载完全相同
```

$$\text{Expert}_e \text{ 处理的 token} = \text{Top-K}_{t}(\text{score}_{e,t})$$

**核心**：从根本上解决负载不均，不需要辅助 loss，每个 expert 处理完全相同数量的 token。代价是部分 token 可能被多个 expert 处理（重复），或没有 expert 处理（跳过）。

---

###### Mixture of Depths（MoD，2024）

**问题**：MoE 选择"用哪个 expert"，但每个 token 都要过所有层。能不能让简单 token 跳过某些层？

**真正做了什么**：在每个 Transformer 层前加一个 router，决定哪些 token 经过这一层，哪些直接跳过（残差直通）：

```
所有 token → router → Top-K token 进入 Attention+FFN → 输出
                    → 其余 token 走残差直通（跳过本层）

计算量 = K/N × 标准计算量
```

**核心**：MoE 是在专家维度稀疏，MoD 是在深度维度稀疏——简单 token 浅层就够，复杂 token 走完所有层，动态分配深度。

---

###### Dynamic Conv / CondConv（条件卷积，2019）

**真正做了什么**：卷积核权重不再固定，由当前输入动态生成——Conv 侧的 MoE 思想：

```
标准 conv：   y = W * x                      ← W 固定
CondConv：    y = (Σ_k α_k(x) · W_k) * x    ← n 个专家卷积核加权融合
              α_k(x) = softmax(router(x))    ← 权重由输入决定
```

每个样本用不同的卷积核组合，表达能力 = n 个独立卷积核的集成，计算量只增加 router 的开销。

**核心**：把 MoE 的"按内容选专家"思想引入卷积——卷积核不再是全局共享的固定参数，而是随输入内容动态混合。比标准 conv 更强，比完全独立的多个 conv 更省。
