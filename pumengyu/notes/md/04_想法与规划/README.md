## 分类入口

| 目录 | 内容 |
|---|---|
| [`方法机制库/`](方法机制库/) | 架构机制、通用方法和统一记录模板 |
| [`历史记录/`](历史记录/) | 由过期组会与投稿计划压缩得到的阶段复盘；仅用于追踪思路演化 |

## 维护规则

- 新想法优先补充到已有主题文件，不为一次对话创建平行笔记。
- 方法原理进入 `方法机制库/`；真实实验结果进入 `02_实验结果/` 或论文实验分析目录。
- 含“当前最优”“正在运行”或 GPU 排期的历史文件必须标明日期，不得作为当前实验状态依据。
- 合并后删除已经完整迁移的旧文件，并搜索仓库内旧路径引用。
