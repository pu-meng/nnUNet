# 多尺度特征融合

###### FPN（Feature Pyramid Network，CVPR 2017）

**问题**：目标检测里小目标在深层特征图上分辨率太低，大目标在浅层语义太弱——单一尺度特征无法兼顾。

**真正做了什么**：构建一条自顶向下的特征金字塔，把深层语义传回浅层：

```
CNN 自底向上（正常前向）：
  C2(stride=4)  → C3(stride=8)  → C4(stride=16) → C5(stride=32)

FPN 自顶向下：
  P5 = 1×1 conv(C5)
  P4 = upsample(P5) + 1×1 conv(C4)
  P3 = upsample(P4) + 1×1 conv(C3)
  P2 = upsample(P3) + 1×1 conv(C2)

每个 Pi 独立输出预测（检测/分割），4 个不同尺度同时用
```

**核心**：一次前向传播，免费得到多尺度语义特征。U-Net 的 skip connection 本质是 FPN 的前身——医学图像里的 encoder-decoder 结构和 FPN 是同一套思路，只是 U-Net 用 concat，FPN 用相加。

---

###### PANet（Path Aggregation Network，CVPR 2018）

**真正做了什么**：FPN 自顶向下之后，再加一条自底向上路径，让底层精确位置信息补充到深层：

```
FPN：  C2→C3→C4→C5（bottom-up）+ P5→P4→P3→P2（top-down，语义向下传）
PANet：FPN 基础上再加 P2→P3→P4→P5（bottom-up path，定位向上补）

最终每个输出节点 = 两条路径融合
```

**核心**：FPN 信息流单向，底层精确边界信息到 P5 要走 100+ 层（ResNet 里），PANet 加短路，最多走 10 层。

##### 检测范式的本质革新

###### Anchor-Free 检测（FCOS，ICCV 2019）

**问题**：Faster R-CNN / YOLO 需要预设 anchor box，大量超参（尺寸/比例），匹配规则复杂。

**真正做了什么**：去掉 anchor，每个 feature map 点直接回归四条边的距离：

```
对 feature map 每个点 (x, y)，直接输出：
  (l, r, t, b) → 该点到目标框 left/right/top/bottom 的距离
  class score
  centerness = sqrt(min(l,r)/max(l,r) × min(t,b)/max(t,b))
  ← centerness 越接近中心越高，抑制远离目标中心的低质量预测
```

**核心**：把检测变成纯像素级回归，无需 anchor 匹配。centerness 分支才是 FCOS 真正的创新点——几何中心性过滤低质量框，效果媲美复杂的 anchor 设计。

---

###### DETR（Detection Transformer，ECCV 2020，Facebook）

**真正做了什么**：把目标检测变成集合预测，彻底去掉 NMS 和 anchor：

```
CNN backbone → 特征图展平成序列
↓
Transformer Encoder（token 自注意力，全局感受野）
↓
Transformer Decoder（N 个可学习 object query）
  每个 query 用 cross-attention 从 encoder 特征里提取信息
  输出 N 个（class, box）预测

Loss：匈牙利算法（二分图最优匹配）→ 预测集合和 GT 集合一一配对
```

**核心**：NMS 和 anchor 是人工后处理，DETR 用集合匹配 loss 让网络端到端学。代价：收敛慢（需要 500 epoch，Faster R-CNN 只要 36），Deformable DETR 用稀疏可变形注意力解决了这个问题。

##### 自监督预训练

###### 对比学习（Contrastive Learning，SimCLR/MoCo，2020）

**真正做了什么**：不用标签，同一张图的两个增强版本在特征空间相互靠近，不同图的特征互相推开：

```
图片 x → 增强 aug1 → encoder → z1
图片 x → 增强 aug2 → encoder → z2

Loss（InfoNCE）：
  L = -log [exp(sim(z1,z2)/τ) / Σ_k exp(sim(z1,z_k)/τ)]
  ↑ 正对相似度高，负样本相似度低

MoCo 改进：用 momentum encoder + queue 存负样本 → 不需要超大 batch
```

**核心**：把自监督转化为实例判别——每张图是自己独一无二的类别。数据增强的设计（裁剪/颜色抖动/翻转）决定网络学到什么不变性。

---

###### MAE（Masked Autoencoder，CVPR 2022，Kaiming He）

**真正做了什么**：遮住 ViT 输入 75% 的 patch，让模型重建被遮住的像素：

```
图片 → 切成 N 个 patch
随机选 25% → 只有这些进 encoder（省掉 75% token 的计算）
被遮住的 patch 用 [MASK] token 补充 → lightweight decoder 重建原像素

Loss = MSE on masked patches only（不惩罚可见 patch）
```

**核心**：图像有大量冗余，75% 遮挡率才够难（BERT 只遮 15%）。只有 25% token 进 encoder，训练比 ViT 全量快 3× 以上。预训练后 fine-tune 效果超过监督预训练。

---

###### CLIP（Contrastive Language-Image Pretraining，OpenAI 2021）

**真正做了什么**：用 4 亿图文对，让图像 encoder 和文本 encoder 输出对齐到同一空间：

```
图片 → ViT → 图像特征 v ∈ R^d
文字描述 → Transformer → 文本特征 t ∈ R^d

N 个样本组成 N×N 相似度矩阵：
  对角线（配对）相似度最大化
  非对角（不配对）最小化
  → 对行列分别做 cross-entropy

零样本推理：把所有类名写成"a photo of a {class}"→ 文本特征
           图像特征和所有类名文本特征计算相似度 → 最高的就是预测类别
```

**核心**：监督信号来自互联网自然存在的图文关系，不需要人工标注。零样本迁移——见过的语义概念都能分类，只需写文字描述。

---

###### DINO / DINOv2（Self-Distillation，Meta 2021/2023）

**真正做了什么**：不用标签，Student 看局部 crop，Teacher 看全局，Student 要预测 Teacher 的输出分布：

```
图片 → 多个随机 crop（局部 + 全局）
Student encoder：处理所有 crop → 输出分布
Teacher encoder：只处理全局 crop（momentum 更新，不反传梯度）→ 目标分布

Loss：Student 输出 → minimize cross-entropy with Teacher 输出
     stop gradient on Teacher（防止 collapse）
```

**核心**：ViT 的 attention map 自发出现语义分割（无需任何分割标签）。DINOv2 在 1.4 亿图上训练，是目前最强通用视觉特征——下游任务线性 probe 媲美全量微调。

##### 生成模型的核心机制

###### GAN（Generative Adversarial Network，NeurIPS 2014，Goodfellow）

**真正做了什么**：两个网络对抗博弈，Generator 造假图，Discriminator 分辨真假：

$$\min_G \max_D \;\mathbb{E}[\log D(x)] + \mathbb{E}[\log(1 - D(G(z)))]$$

```
D 最大化：区分真假的能力
G 最小化：被 D 识别为假的概率

纳什均衡：G 生成分布 = 真实数据分布 → D 输出恒 0.5
```

**核心**：不显式定义"好图片"，通过对抗隐式学习数据分布。代价：训练不稳定（梯度消失/模式崩塌），WGAN 用 Wasserstein 距离+梯度惩罚解决稳定性，StyleGAN 用 AdaIN 实现风格控制。

---

###### Diffusion Model / DDPM（NeurIPS 2020，Ho et al.）

**真正做了什么**：正向逐步加高斯噪声直到变成纯噪声，逆向过程学会逐步去噪：

$$q(x_t | x_{t-1}) = \mathcal{N}\!\left(x_t;\, \sqrt{1-\beta_t}\, x_{t-1},\, \beta_t I\right)$$

$$L = \mathbb{E}_{x_0, \varepsilon, t}\left[\|\varepsilon - \varepsilon_\theta(x_t, t)\|^2\right]$$

直接预测噪声 $\varepsilon$（比预测 $x_0$ 更稳定）。

```
DDIM：用非马尔可夫链跳步推理，1000 步 → 50 步
Stable Diffusion：把去噪放在 VAE 压缩的 latent space 做，速度 ×8
条件生成：把 CLIP 文本特征注入 UNet 去噪网络（via cross-attention）
```

**核心**：把生成转化为去噪——每步只预测当前噪声，化难为易。质量远超 GAN，但推理慢是固有缺点（多步迭代）。

##### 密集连接

###### DenseNet（Dense Connections，CVPR 2017，黄高）

**真正做了什么**：每一层的输入 = 所有前面层输出的 concat（不是相加）：

$$x_l = H_l([x_0, x_1, \ldots, x_{l-1}])$$

```
ResNet：  x_l = F(x_{l-1}) + x_{l-1}    ← 相加，维度不变
DenseNet：x_l = F(concat[x_0,...,x_{l-1}]) ← concat，通道线性增长

每层只增加 k 个通道（growth rate，通常 k=32）
第 l 层输入通道数 = k_0 + k×(l-1)（k_0 为初始通道数）
```

**核心**：梯度通过 concat 直接流到任何一层，天然解决梯度消失。特征复用——浅层精确特征不被覆盖，一直保留到最后。医学图像小数据场景下常用（HarDNet 是高效变种）。

---

##### 注意力的空间增强

###### CBAM（Convolutional Block Attention Module，ECCV 2018）

**真正做了什么**：先通道注意力再空间注意力，串联两步：

```
步骤1 - 通道注意力（增强版 SE）：
  MaxPool(空间) + AvgPool(空间) → 各得 [B, C, 1, 1]
  共享 MLP → sigmoid → 通道权重 → 乘回输入

步骤2 - 空间注意力：
  MaxPool(通道) + AvgPool(通道) → 各得 [B, 1, H, W]
  concat → 7×7 conv → sigmoid → 空间权重 → 乘回输入
```

**核心**：SE 只问"哪个通道重要"，CBAM 再问"哪个位置重要"。两步串联，参数极少（7×7 conv + 一个 MLP），可插入任意 block。

---

###### Cross-Attention（编解码器注意力，原始 Transformer 2017）

**真正做了什么**：Q 来自一个序列，K/V 来自另一个序列——跨序列信息查询：

$$\text{Attn}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d}}\right)V$$
$$Q = W_Q \cdot x_{target}, \quad K = W_K \cdot x_{source}, \quad V = W_V \cdot x_{source}$$

```
应用场景：
  机器翻译：decoder query → encoder source 语言特征里找对齐
  DETR：object query → CNN 特征图里找目标位置
  Stable Diffusion：去噪网络 query → CLIP 文本特征（文字条件注入）
  你的 MLA：patch query → 多尺度特征里聚合信息（本质就是 cross-attention）
```

**核心**：Self-Attention 问自己，Cross-Attention 问别人。多模态融合、条件生成、Encoder-Decoder 的基础操作。

##### 归一化扩展

###### Group Normalization（GN，ECCV 2018，Kaiming He）

**真正做了什么**：把 C 个通道分成 G 组，每组内做归一化：

```
输入 [B, C, D, H, W]，分 G 组

BN：归一化 [B, D, H, W]       → B 太小时均值方差估计不准
IN：归一化 [D, H, W]          → 破坏通道间相关性
GN：归一化 [C/G, D, H, W]     → 不依赖 B，保留组内通道结构

G=1 时退化为 LN，G=C 时退化为 IN
```

**核心**：检测/分割任务 batch size 通常只有 1~2，BN 失效。GN 完全不依赖 batch，效果稳定。Mask R-CNN 后期版本、Detectron2 框架默认用 GN。

##### 训练技巧的本质

###### Mixup / CutMix（ICLR 2018 / ICCV 2019）

**真正做了什么**：

```
Mixup：新图 = λ·图A + (1-λ)·图B，标签也按 λ 混合
       λ ~ Beta(α, α)，α=0.2 时多数情况 λ 接近 0 或 1

CutMix：把图A的矩形区域替换成图B对应区域，标签按面积比混合
       剪切面积/全图面积 = λ → 标签 = λ·A + (1-λ)·B
```

**核心**：强迫网络对"中间状态"也预测正确，极大提升泛化，等价于隐式正则。CutMix 保留局部纹理真实性（Mixup 有虚假混叠），分类和分割任务都有效。

---

###### Label Smoothing（标签平滑，Inception-v4 2016）

**真正做了什么**：把 one-hot 硬标签变成软标签：

$$y_{smooth} = (1 - \varepsilon) \cdot y_{one\text{-}hot} + \frac{\varepsilon}{K}$$

```
K=4，ε=0.1：
  硬标签：[0.000, 0.000, 1.000, 0.000]
  软标签：[0.025, 0.025, 0.925, 0.025]
```

**核心**：防止模型对正确类别过度自信（logit 趋向 +∞，等价于过拟合）。ViT 训练默认 ε=0.1，现代分类训练标配。

##### 点云与三维表达

###### PointNet / PointNet++（CVPR 2017，Stanford）

**真正做了什么**：直接处理无序点集，用 MLP + 全局 Max Pooling 学点云特征：

```
N 个点，每点 [x, y, z]

PointNet：
  每个点独立过共享 MLP → [N, d]（权重共享）
  Global Max Pooling over N → [d]（置换不变）

PointNet++（层次聚合）：
  Farthest Point Sampling → 选代表点
  Ball Query → 找邻域点
  局部 PointNet → 局部特征
  多层次聚合（类比 CNN 的感受野增大）
```

**核心**：点云是无序集合，传统 CNN 假设空间网格（不适用）。Max Pooling 是置换不变的——点的顺序任意排列输出相同。比体素化保留更精确位置，计算更省。

---

###### NeRF（Neural Radiance Field，ECCV 2020，Berkeley）

**真正做了什么**：用一个 MLP 隐式表示 3D 场景，输入坐标 + 视角，输出颜色 + 密度：

$$F_\theta: (x, y, z, \theta, \phi) \to (R, G, B, \sigma)$$

```
渲染：沿光线采样 N 个点 → 每点过 MLP → (color, density)
     → 体积渲染积分 → 像素颜色

训练：多张已知相机参数的 2D 图片 → 监督渲染像素颜色
     → MLP 参数 = 整个 3D 场景
```

**核心**：MLP 参数本身就是"场景"，不需要任何显式 3D 结构。新视角合成质量极高。缺点：每个场景单独训练，推理慢（每像素多次 MLP 查询）。

---

###### 3D Gaussian Splatting（ICCV 2023 Best Paper）

**真正做了什么**：用大量 3D 高斯椭球显式表示场景，每个高斯有位置/形状/颜色/透明度，用可微分 rasterizer 投影到 2D：

```
每个 3D Gaussian：μ（中心），Σ（协方差/形状），颜色（球谐系数），α（透明度）

渲染：3D Gaussian → 投影到 2D → 按深度排序 → alpha-blending 合成像素
训练：光度 loss 对所有参数求梯度，密度自适应（分裂过大/删除透明高斯）
```

**核心**：NeRF 隐式 MLP 渲染慢（30s/帧），3DGS 显式高斯快（100+ FPS）。显式表示可以直接编辑（移动/删除单个高斯）。当前 3D 重建和新视角合成的 SOTA 标准。

##### 自动驾驶核心范式

###### BEVFormer（BEV Perception，ECCV 2022）

**问题**：自动驾驶多摄像头角度各异，3D 感知需要融合到统一坐标系（BEV = Bird's Eye View）。

**真正做了什么**：在 BEV 平面定义可学习 grid query，用 Cross-Attention 从各视角图像特征里聚合信息：

```
BEV 平面：H×W 个 query（每个对应地面一个位置）

对每个 BEV query：
  把 3D 参考点投影到各摄像头图像平面
  用 Deformable Attention 从投影点附近采样特征
  所有摄像头采样结果加权融合 → BEV 特征

时序融合：
  当前帧 query 还 cross-attend 上一帧 BEV 特征
  → 动态目标速度估计更准
```

**核心**：不显式预测深度，用 cross-attention 的"软查询"让网络隐式学透视到 BEV 的几何变换。时序 BEV 使动态目标的运动估计稳定。Tesla 的 Occupancy Network 和 BEVFormer 是同一套思路。

##### 分割基础模型

###### SAM（Segment Anything Model，Meta 2023）

**真正做了什么**：训练可接受任意 prompt（点/框/掩码）的通用分割模型，在 10 亿掩码数据上预训练：

```
架构：
  Image Encoder：ViT-H（重，只跑一次，特征可缓存）
  Prompt Encoder：点/框 → sparse embedding；掩码 → dense embedding
  Mask Decoder：2 层 lightweight transformer → 掩码输出

推理：
  用户点一点 / 画一框 → <50ms 出掩码（Image Encoder 预计算）
```

**核心**：把"分割什么"变成"给 prompt，SAM 自动响应"——分割模型从专用变为通用。医学图像直接用 SAM 效果差（CT/MRI 域差距大），MedSAM 是其医学微调版本，用 LiTS 等数据集 fine-tune 后效果大幅提升。

##### 高效微调范式

###### Prefix Tuning / Prompt Tuning（ACL/EMNLP 2021）

**真正做了什么**：冻结模型全部参数，只在 attention 的 K/V 序列前加可训练的 prefix token：

```
标准 attention：Q attend [K_1, ..., K_N]
Prefix Tuning：Q attend [P_1, ..., P_k, K_1, ..., K_N]
               P 是可训练的，模型参数全冻结
               每层都加 prefix（共 L×k 个额外参数）

Prompt Tuning（更简单）：只在输入 embedding 层加 soft token，不在每层加
```

**核心**：LoRA 调权重矩阵，Prefix 调激活空间——两者都是极少参数高效微调，但方向不同。Prefix 更直觉：给模型"隐式提示"，引导其激活特定知识。

---

###### Adapter（Adapter Tuning，Google 2019）

**真正做了什么**：在每个 Transformer block 里插入小型瓶颈网络，冻结原始参数只训练 Adapter：

```
原始 block：Attention → Add&Norm → FFN → Add&Norm
加 Adapter：Attention → Add&Norm → Adapter → FFN → Add&Norm → Adapter

每个 Adapter：
  d → r (down projection, r≪d)
  激活函数
  r → d (up projection)
  + 残差

参数量 = 2dr（r=64 时约为全量的 0.5%）
```

**核心**：LoRA 在权重上加低秩更新，Adapter 在架构上插瓶颈模块——两者殊途同归，都是只训练极少参数。Adapter 更模块化（可以插拔），LoRA 推理时可合并权重（无额外延迟）。

---

##### 新型网络结构范式

###### KAN（Kolmogorov–Arnold Networks，2024，MIT+PKU）

**真正做了什么**：把 MLP 里固定的激活函数换成可学习的一维样条函数：

```
MLP：y = σ(Wx + b)   ← σ 固定（ReLU/GELU），W 可学习
KAN：y = Σ_i φ_i(x_i)  ← φ_i 是可学习样条函数（B-spline），节点只做加法

每条边 = 一个独立的可学习函数曲线
```

**核心**：MLP 学"数值"（权重），KAN 学"函数形式"（曲线）。在科学计算（符号回归、PDE 求解）上参数效率更高——可以从学到的曲线里直接读出数学公式。视觉任务目前不如 MLP，但引发了"激活可学习"方向的讨论。

---

###### Token Merging（ToMe，ICLR 2023，Meta）

**真正做了什么**：在 ViT 每个 block 之间，把相似的 token 合并，减少序列长度：

```
N 个 token → 二分图匹配找最相似 token 对 → top-r 对取均值合并
→ N-r 个 token 进下一个 block

ViT 计算量 ∝ N²，每层减少 r 个 token，L 层后剩 N - r×L 个
```

**核心**：ViT 的图像 patch 冗余极高（背景区域大量相似 token），合并后精度几乎不变（ImageNet 掉 0.2%），推理速度提升 2×。不改模型参数，推理时插入即可。
