## 核心主线

**所有创新本质上都在做同一件事**：

> 在固定计算预算下，把省出来的空间用在更有价值的地方（更大感受野 / 更深网络 / 更多参数 / 更高效路由）

---

## MLA（Multi-head Latent Attention，DeepSeek-V2）

**包装说法**：低秩 KV 压缩，高效长序列建模

**真正做了什么**：

标准 Attention 的 KV Cache 是瓶颈：每个 token 要存 K 和 V，序列长了显存爆炸。

MLA 把 K、V 先压缩到低维潜变量 c（d_c = d/4），推理时只存 c，需要时再解压：

```
标准：存 K[N, d] + V[N, d]       → 显存 O(N·d)
MLA：存 c[N, d_c]，d_c = d/4    → 显存 O(N·d/4)
推理时：K = W_K · c，V = W_V · c
```

**核心**：用一次低秩线性映射，把 KV 显存压缩 4 倍，长序列推理成本降到可接受范围。

**省出来的额度用在**：支持更长上下文，或更大 batch size。

## Depthwise Separable Conv（MobileNet / MedNeXt）

**包装说法**（MedNeXt）：借鉴 ConvNeXt 架构，对齐 Transformer 设计哲学

**真正做了什么**：

标准卷积参数是 $k^3 \times C^2$，k 和 C 同时大就爆炸。解耦空间混合和通道混合：

```
Depthwise k×k×k：只做空间混合，参数 k³C（无 C² 项）
Pointwise 1×1×1：只做通道混合，参数 C²（无 k³ 项）
合计：k³C + C²
```

C 够大时（C ≥ 19），$k^3C + C^2 < 27C^2$（标准 3×3×3），**参数更少，感受野更大**。

**核心**：把参数中的 $k^3 \times C^2$ 拆成 $k^3C + C^2$，消掉耦合项，参数省出来支撑更大的核。

**省出来的额度用在**：核从 3 扩到 7（甚至更大），感受野成三次方增长。

**MedNeXt 的真实贡献**：把这个操作从 2D 搬到 3D 医学图像，验证大核在体积分割任务上同样有效。LN/GELU 是 ResNet 现代化的工程细节，和 Transformer 无本质关联。

## MoE（Mixture of Experts）

### 第一层：基础 MoE（早就有，不是 DeepSeek 的创新）

**真正做了什么**：

N 个 expert（每个就是一个 FFN），router 是一个线性层，简单粗暴地为每个 token 选 Top-K：

```
router = nn.Linear(d_model, N, bias=False)   ← 就一个线性层

每个 token：
  scores = router(token)          → N 维 logits
  topk_idx = scores.topk(K)      → 选 Top-K 个 expert
  只走这 K 个，其余 N-K 个不激活

计算量 = K 个 expert
参数量 = N 个 expert
```

**核心**：计算量和参数量解耦，参数堆 N 个，每次只算 K 个。

---

### 第二层：共享 Expert（DeepSeek MoE 的真实创新）

**问题**：基础 MoE 里每个路由 expert 既要学通用知识又要学专化知识，互相干扰，需要更多 expert 才够用。

**做了什么**：加 1~2 个共享 expert，所有 token 必走，专门学通用知识；路由 expert 只需专注各自细分方向：

```
输出 = shared_expert(x) + Σ gate_k · routed_expert_k(x)
         ↑ 所有 token 必走      ↑ router 选 Top-K 个
```

你的代码实现（`mla_unetr.py:185`）：
```python
out = (self.shared_expert(x_flat) + routed).reshape(B, N, D)
```

**节省在哪里**：共享 expert 把通用知识兜底，路由 expert 专化效率更高，**更少的路由 expert 可以达到标准 MoE 更多 expert 的同等效果**。不是降低单次计算量，是提升了 expert 容量利用率。

**额外细节（loss-free bias 负载均衡）**：
router 容易总选同几个 expert（负载不均）。DeepSeek V3 用 EMA 统计各 expert 被选频率，自动调 bias 抑制过热 expert、激励冷门 expert，不加辅助 loss，梯度路径更干净。你的代码里 `update_expert_bias()` 就是这个。

## Attention（Transformer 核心）

**真正做了什么**：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d}}\right)V$$

$QK^T$ 是每个位置和所有位置的点积相关性矩阵，**由输入内容动态生成**，不同样本权重不同。

```
卷积：权重固定，训练完不变
Attention：权重 = QK^T，每次输入都重新算
```

**核心**：内容自适应的动态全局权重，这是和卷积的根本区别，不是感受野大小。

## Transformer 的本质改变

### 稀疏注意力（Sparse Attention，Longformer / BigBird，2020）

**问题**：标准 Attention $QK^T$ 是 $N \times N$ 的矩阵，序列长 N 大时内存和计算都是 $O(N^2)$，根本跑不动。

**真正做了什么**：不做全局 $N \times N$，每个 token 只和一小部分 token 做 attention：

```
局部窗口：每个 token 只看相邻 k 个 token     → O(N·k)
全局 token：少量特殊 token（如 [CLS]）和所有位置做 attention
稀疏模式：两者组合，覆盖局部 + 少量全局
```

$$\text{稀疏}QK^T \in \mathbb{R}^{N \times k} \quad \text{而非} \quad \mathbb{R}^{N \times N}$$

**核心**：$O(N^2) \rightarrow O(N \cdot k)$，代价是放弃任意两个 token 之间的直接交互，只保留局部和少量全局。

---

### 滑窗注意力（Window Attention，Swin Transformer，2021）

**真正做了什么**：把特征图切成不重叠的小窗口（如 $7 \times 7$），只在窗口内部做 Attention；下一层把窗口 shift 半个窗口，让相邻窗口信息交换：

```
Layer 1：窗口 [0:7, 0:7]、[0:7, 7:14]... 各自独立做 Attention
Layer 2：shift，窗口 [3:10, 3:10]... 跨越上层窗口边界
```

**核心**：把 $O(N^2)$ 降到 $O(N \cdot w^2)$（w 是窗口大小），跨窗口靠 shift 间接传递，不是真正的全局 Attention。

**和稀疏注意力的区别**：Swin 是硬分块（窗口内全 Attention），稀疏 Attention 是软稀疏（每个 token 选 k 个位置）。

---

### 线性注意力（Linear Attention，Performer，2020）

**问题**：softmax 让 $QK^T$ 的计算顺序必须先算 $N \times N$ 的矩阵，再乘 V。

**真正做了什么**：用核函数 $\phi$ 近似 softmax，把计算顺序改成先算 $K^TV$：

$$\text{标准}：\text{softmax}(QK^T)V \quad O(N^2 d)$$

$$\text{线性}：\phi(Q)(\phi(K)^T V) \quad O(N d^2)$$

先算括号里的 $\phi(K)^T V \in \mathbb{R}^{d \times d}$（和 N 无关），再左乘 $\phi(Q)$：

```
N=4096, d=64:
  标准 Attention：4096² × 64 ≈ 10亿次乘法
  线性 Attention：4096 × 64² ≈ 1700万次乘法
```

**核心**：$O(N^2) \rightarrow O(N \cdot d^2)$，代价是用核函数近似替换 softmax，精度有损失。

---

### Flash Attention（Dao et al., 2022）

**包装说法**：IO-aware exact attention，精确 Attention 的高效实现

**真正做了什么**：**不改公式，改内存访问模式**。

GPU 有两级内存：HBM（显存，大但慢）和 SRAM（片上缓存，小但极快）。标准实现每步都要把中间结果写回 HBM：

```
标准实现：
  QK^T → 写回 HBM（N×N 矩阵，很大）
  softmax → 写回 HBM
  × V → 写回 HBM
  共 3 次大矩阵读写 HBM

Flash Attention：
  按 tile 分块，每块完整算完再写回
  QK^T、softmax、×V 全在 SRAM 里完成
  只有最终结果写 HBM 一次
```

**核心**：结果完全一样（精确），但 HBM 读写次数从 $O(N^2)$ 降到 $O(N)$，速度提升 2-4×，显存从 $O(N^2)$ 降到 $O(N)$。

**和线性 Attention 的区别**：线性 Attention 改了公式（近似），Flash Attention 不改公式（精确），只改实现。

---

### GQA / MQA（Grouped/Multi-Query Attention，2019/2023）

**问题**：推理时 KV Cache 随序列长度线性增长，多头情况下每个头都存一份 K、V，显存压力大。

**真正做了什么**：

```
MHA（标准）：H 个头，每头独立 Q/K/V   → KV Cache = H 份
MQA：        H 个头共享同一组 K/V      → KV Cache = 1 份
GQA：        H 个头分 G 组，组内共享 K/V → KV Cache = G 份（G < H）
```

$$\text{KV Cache 显存} = \frac{G}{H} \times \text{MHA}$$

**核心**：Q 保持多头（保证表达能力），K/V 合并共享（减少 Cache），推理显存直降 G 倍。代价是 K/V 表达能力略降，实验证明 G=8 时几乎无损。

## Conv 的本质改变

### 空洞卷积（Dilated / Atrous Conv，DeepLab，2015）

**真正做了什么**：卷积核采样位置中间插"空洞"，采样点不再连续：

```
普通 3×3 conv（dilation=1）：
  X X X
  X X X   ← 9 个相邻位置
  X X X

空洞 3×3 conv（dilation=2）：
  X . X . X
  . . . . .
  X . X . X   ← 9 个采样点，但覆盖 5×5 的范围
  . . . . .
  X . X . X
```

**参数量**：完全不变（还是 $k^2 \times C^2$），但感受野从 $k$ 变成 $k + (k-1)(d-1)$。

$$\text{dilation=}d \text{ 的 3×3：感受野} = 2d+1$$

**核心**：参数不增，感受野指数扩大，代价是中间的点没被采样（可能丢失细节）。

**和 Depthwise 大核的区别**：Depthwise 大核连续采样（信息完整），空洞卷积跳跃采样（节省参数但有空洞）。
空洞卷积在2D自然图像分割有效,在3D医学图像被大核depthwise(MedNeXt)替代,

---

### 可变形卷积（Deformable Conv，DCN，2017）

**真正做了什么**：采样位置不再是固定网格，而是由网络从输入中学出偏移量 $\Delta p$：

```
计算流程：

输入 x: [B, C, H, W]
  ↓
offset_net（一个普通 3×3 conv，C → 18 通道）
  ↓
offsets: [B, 18, H, W]   ← 9个采样点 × 2方向(Δx,Δy) = 18

主卷积滑窗到位置 (h, w) 时：
  查 offsets[:, :, h, w] → 得到该位置专属的 9 对偏移量
  普通采样点：(h+kh, w+kw)
  偏移后采样点：(h+kh+Δx_k, w+kw+Δy_k)  ← 非整数，用双线性插值取值
  对这 9 个位置的值乘以卷积核权重，加和 → 一个输出值

输出: [B, C_out, H, W]   ← 形状和普通卷积完全相同
```

**参数量**：

```
普通 3×3 conv：9 × C × C = 9C²
可变形 conv：
  offset_net：9 × C × 18 = 162C   ← 额外增加
  主卷积：    9C²                  ← 和普通 conv 一样
  总计：      9C² + 162C           ← 比普通 conv 多
```

**可变形 conv 优化的不是效率，而是建模能力**：

| 目标 | 普通 conv | Depthwise | 可变形 conv |
|------|-----------|-----------|------------|
| 节省参数 | 基准 | ✅ 大幅节省 | ❌ 反而增加 |
| 节省计算量 | 基准 | ✅ 大幅节省 | ❌ 反而增加 |
| 采样形状灵活 | ❌ 固定方格 | ❌ 固定方格 | ✅ 内容自适应 |

同样的 9C² 主卷积参数，普通 conv 永远在方格上采，可变形 conv 能采到更相关的位置——**同等参数，信息质量更高**。

**双线性插值（2D）**：偏移量是小数，特征图只有整数位置有值，用周围 4 个邻居加权平均：

```
采样位置 (1.3, 2.7)，找周围 4 个整数点：

       y=2       y=3
x=1  f(1,2)   f(1,3)
x=2  f(2,2)   f(2,3)

α = 1.3-1 = 0.3，β = 2.7-2 = 0.7

先 x 方向插：
  f(1.3, 2) = 0.7×f(1,2) + 0.3×f(2,2)
  f(1.3, 3) = 0.7×f(1,3) + 0.3×f(2,3)
再 y 方向插：
  f(1.3, 2.7) = 0.3×f(1.3,2) + 0.7×f(1.3,3)

= 4 个邻居的加权平均，权重 = 到各点距离的反比
```

**三线性插值（3D）**：多了 z 方向，从 4 个邻居扩展到 8 个邻居体素：

```
采样位置 (1.3, 2.7, 4.2)，α=0.3, β=0.7, γ=0.2

依次在 x→y→z 方向各插一次：
  x 方向插 4 次 → 4 个中间值
  y 方向插 2 次 → 2 个中间值
  z 方向插 1 次 → 最终值

= 8 个邻居体素的加权平均
```

3D 可变形 conv 每采一个点需要查 8 个体素，3×3×3 核有 27 个采样点 → **27×8 = 216 次查表 + 加权求和**，这是 3D 下开销大、很少用的原因。

**核心**：卷积采样形状由输入内容动态决定——检测到细长目标自动横向拉伸，检测到圆形目标自动收缩。不节省参数/计算，优化的是几何建模能力。3D 医学图像里极少用（插值开销大 + 器官形状相对规则）。

## 替代 Attention 和 Conv 的新范式

### SSM / Mamba（State Space Model，2023）

**问题**：Attention $O(N^2)$ 太慢，线性 Attention 精度有损，能不能找到既精确又 $O(N)$ 的序列建模方法？

**真正做了什么**：用控制论里的状态空间方程建模序列：

$$h_t = Ah_{t-1} + Bx_t$$
$$y_t = Ch_t$$

$h_t$ 是隐状态，$x_t$ 是输入，$y_t$ 是输出。每个时间步只更新隐状态，不需要看所有历史 token。

**Mamba 的关键改进**（S4 → Mamba）：让 $A, B, C$ 矩阵由输入 $x_t$ 动态生成（Selective SSM）：

```
普通 SSM：A, B, C 是固定参数，对所有 token 一样
Mamba：   A(x_t), B(x_t), C(x_t) 由当前输入决定 → 内容自适应
```

**复杂度**：推理时 $O(N)$（递推），训练时用并行扫描算法也是 $O(N \log N)$，远优于 Attention。

**和 Attention 的本质区别**：
```
Attention：每个位置和所有位置直接交互（全对全）
Mamba：    信息通过隐状态 h 逐步传递（序列递推）
代价：     Mamba 对很久之前的信息有遗忘，Attention 无遗忘
```

**在医学图像的应用**：U-Mamba / SegMamba，用 Mamba 替换 UNet bottleneck 的 Attention，$O(N)$ 复杂度支持更高分辨率的 3D 特征图建模。

## Conv 的基础结构创新

### 残差连接（Residual Connection，ResNet，2015）

**问题**：网络层数超过 20 层后，梯度反向传播时逐层相乘越来越小，趋向于 0（梯度消失），深层参数几乎不更新。

**真正做了什么**：在 block 输入和输出之间加一条直连通道：

```
输出 = F(x) + x
         ↑      ↑
    卷积变换   输入直通（恒等映射）
```

反向传播时梯度有两条路：
$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial y}\left(\frac{\partial F}{\partial x} + 1\right)$$

括号里的 $+1$ 保证梯度不会消失——即使 $\frac{\partial F}{\partial x} \approx 0$，梯度仍然能完整流回去。

**核心**：让梯度有一条不经过非线性变换的"高速公路"直通回去，解锁了 100+ 层深网络的训练。所有现代架构（Transformer、ConvNeXt、MedNeXt）都依赖残差连接。

---

### 通道注意力（Squeeze-and-Excitation，SE Network，2018）

**真正做了什么**：用极少的参数让网络学会"哪些通道更重要"：

```
输入 [B, C, D, H, W]
↓ Global Average Pooling（空间维度压缩）
[B, C, 1, 1, 1]
↓ FC (C → C/r)  → ReLU  → FC (C/r → C)  → Sigmoid
[B, C, 1, 1, 1]   ← 每个通道一个权重 ∈ (0,1)
↓ 逐通道相乘（广播）
输出 [B, C, D, H, W]
```

参数量仅 $\frac{2C^2}{r}$（r=16 时极少），但给每个通道一个全局上下文感知的权重。

**核心**：CNN 里最轻量的全局上下文机制——不用 Attention，用全局池化 + FC 就能让通道自适应重标定。

---

### 非局部网络（Non-local Network，2018）

**真正做了什么**：在 CNN 中间直接嵌入一个 self-attention 操作：

```
y_i = (1/C(x)) Σ_j f(x_i, x_j) · g(x_j)

f(x_i, x_j) = softmax(θ(x_i)^T · φ(x_j))   ← 和 Attention 的 QK^T 完全等价
g(x_j) = W_g · x_j                            ← 和 Attention 的 V 等价
```

是 ViT 之前，最早把 self-attention 引入图像任务的工作。每个位置和所有位置交互，获得真正的全局感受野。

**核心**：证明 CNN 中间插全局 Attention 是有效的，是从纯 CNN 走向 Transformer 的桥梁。代价是计算量 $O(N^2)$，只能插在分辨率低的深层。

---

### 结构重参数化（Structural Re-parameterization，RepVGG / RepLKNet，2021）

**真正做了什么**：训练和推理用不同的结构——训练时多分支（表达能力强），推理时合并成单 conv（速度快）：

```
训练时：
  3×3 conv ─┐
  1×1 conv ─┼─ 相加 → 输出
  恒等映射  ─┘

推理时（等价合并）：
  一个 3×3 conv → 输出   ← 参数合并后完全等价，但只有一次 conv
```

合并方法：把 1×1 conv 用 zero-padding 变成 3×3，把恒等映射也变成 3×3（对角为 1 其余为 0），三个 3×3 conv 直接相加权重。

**核心**：训练时的多分支带来更好的优化景观和梯度多样性，推理时合并后不增加任何计算量。训练和推理的结构可以解耦。

---

## Transformer 的位置编码创新

### RoPE（旋转位置编码，RoFormer，2021）

**问题**：标准 Transformer 的位置编码是绝对的（给每个位置加一个固定向量），无法直接表达相对位置关系，且长度外推困难。

**真正做了什么**：把位置信息编码进 Q 和 K 的旋转里，使得 $Q_m \cdot K_n$ 天然只依赖相对位置 $m-n$：

$$Q_m = R_m \cdot q, \quad K_n = R_n \cdot k$$

$$Q_m \cdot K_n = q^T R_m^T R_n k = q^T R_{m-n} k$$

$R_\theta$ 是旋转矩阵，每两个维度一组，旋转角度 = 位置 × 频率：

```
[q_0, q_1] → [q_0·cos(mθ) - q_1·sin(mθ),  q_0·sin(mθ) + q_1·cos(mθ)]
```

**核心**：不需要显式的相对位置矩阵，$QK^T$ 的计算自动包含相对位置信息，且对超出训练长度的位置有更好的外推能力。现代 LLM（LLaMA、DeepSeek）全部用 RoPE。

---

## 通用效率范式

### LoRA（Low-Rank Adaptation，2021）

**问题**：微调大模型需要更新所有参数，显存和计算都是全量，代价极高。

**真正做了什么**：冻结原始权重 $W_0$，只训练两个低秩矩阵的乘积 $\Delta W = BA$：

$$W = W_0 + \Delta W = W_0 + BA$$

$$B \in \mathbb{R}^{d \times r}, \quad A \in \mathbb{R}^{r \times k}, \quad r \ll \min(d, k)$$

```
参数量对比（d=k=4096, r=8）：
  全量微调：4096 × 4096 = 16,777,216
  LoRA：    4096×8 + 8×4096 = 65,536   ← 降低 256×
```

推理时直接合并 $W = W_0 + BA$，无额外计算开销。

**核心**：假设权重更新 $\Delta W$ 是低秩的——实验验证这个假设在大多数任务上成立。用低秩分解大幅降低可训练参数，但保留原模型全部能力。

---

### 知识蒸馏（Knowledge Distillation，KD，Hinton 2015）

**真正做了什么**：不用 one-hot 硬标签，用大模型（Teacher）的软概率分布训练小模型（Student）：

```
Teacher 输出：[0.85, 0.10, 0.03, 0.02]   ← 软标签，包含类间相似度信息
硬标签：      [1.00, 0.00, 0.00, 0.00]   ← 只告诉对错，没有关系信息

Loss = α · KL(Student || Teacher) + (1-α) · CrossEntropy(Student, hard_label)
```

Teacher 的软标签隐含了"猫和狗比猫和汽车更像"这类知识，Student 学到的不只是分类结果，而是 Teacher 的"世界观"。

**核心**：压缩模型能力的根本方法，不是让小模型学数据，而是让小模型学大模型的输出分布。医学图像里常用于把大 3D 模型蒸馏成轻量部署版本。

---

## MoE 系列：条件计算

### Expert Choice 路由（2022）

**问题**：标准 MoE 里 token 选 expert，热门 expert 被过度选择，冷门 expert 几乎不用（负载不均），需要额外的均衡 loss。

**真正做了什么**：翻转路由方向——**expert 选 token**，每个 expert 从所有 token 里选 Top-K 个处理：

```
标准 MoE：每个 token 选 Top-2 expert   → 热门 expert 爆满，冷门闲置
Expert Choice：每个 expert 选 Top-K token → 每个 expert 负载完全相同
```

$$\text{Expert}_e \text{ 处理的 token} = \text{Top-K}_{t}(\text{score}_{e,t})$$

**核心**：从根本上解决负载不均，不需要辅助 loss，每个 expert 处理完全相同数量的 token。代价是部分 token 可能被多个 expert 处理（重复），或没有 expert 处理（跳过）。

---

### Mixture of Depths（MoD，2024）

**问题**：MoE 选择"用哪个 expert"，但每个 token 都要过所有层。能不能让简单 token 跳过某些层？

**真正做了什么**：在每个 Transformer 层前加一个 router，决定哪些 token 经过这一层，哪些直接跳过（残差直通）：

```
所有 token → router → Top-K token 进入 Attention+FFN → 输出
                    → 其余 token 走残差直通（跳过本层）

计算量 = K/N × 标准计算量
```

**核心**：MoE 是在专家维度稀疏，MoD 是在深度维度稀疏——简单 token 浅层就够，复杂 token 走完所有层，动态分配深度。

---

### Dynamic Conv / CondConv（条件卷积，2019）

**真正做了什么**：卷积核权重不再固定，由当前输入动态生成——Conv 侧的 MoE 思想：

```
标准 conv：   y = W * x                      ← W 固定
CondConv：    y = (Σ_k α_k(x) · W_k) * x    ← n 个专家卷积核加权融合
              α_k(x) = softmax(router(x))    ← 权重由输入决定
```

每个样本用不同的卷积核组合，表达能力 = n 个独立卷积核的集成，计算量只增加 router 的开销。

**核心**：把 MoE 的"按内容选专家"思想引入卷积——卷积核不再是全局共享的固定参数，而是随输入内容动态混合。比标准 conv 更强，比完全独立的多个 conv 更省。

---

## 多尺度特征融合

### FPN（Feature Pyramid Network，CVPR 2017）

**问题**：目标检测里小目标在深层特征图上分辨率太低，大目标在浅层语义太弱——单一尺度特征无法兼顾。

**真正做了什么**：构建一条自顶向下的特征金字塔，把深层语义传回浅层：

```
CNN 自底向上（正常前向）：
  C2(stride=4)  → C3(stride=8)  → C4(stride=16) → C5(stride=32)

FPN 自顶向下：
  P5 = 1×1 conv(C5)
  P4 = upsample(P5) + 1×1 conv(C4)
  P3 = upsample(P4) + 1×1 conv(C3)
  P2 = upsample(P3) + 1×1 conv(C2)

每个 Pi 独立输出预测（检测/分割），4 个不同尺度同时用
```

**核心**：一次前向传播，免费得到多尺度语义特征。U-Net 的 skip connection 本质是 FPN 的前身——医学图像里的 encoder-decoder 结构和 FPN 是同一套思路，只是 U-Net 用 concat，FPN 用相加。

---

### PANet（Path Aggregation Network，CVPR 2018）

**真正做了什么**：FPN 自顶向下之后，再加一条自底向上路径，让底层精确位置信息补充到深层：

```
FPN：  C2→C3→C4→C5（bottom-up）+ P5→P4→P3→P2（top-down，语义向下传）
PANet：FPN 基础上再加 P2→P3→P4→P5（bottom-up path，定位向上补）

最终每个输出节点 = 两条路径融合
```

**核心**：FPN 信息流单向，底层精确边界信息到 P5 要走 100+ 层（ResNet 里），PANet 加短路，最多走 10 层。

---

## 检测范式的本质革新

### Anchor-Free 检测（FCOS，ICCV 2019）

**问题**：Faster R-CNN / YOLO 需要预设 anchor box，大量超参（尺寸/比例），匹配规则复杂。

**真正做了什么**：去掉 anchor，每个 feature map 点直接回归四条边的距离：

```
对 feature map 每个点 (x, y)，直接输出：
  (l, r, t, b) → 该点到目标框 left/right/top/bottom 的距离
  class score
  centerness = sqrt(min(l,r)/max(l,r) × min(t,b)/max(t,b))
  ← centerness 越接近中心越高，抑制远离目标中心的低质量预测
```

**核心**：把检测变成纯像素级回归，无需 anchor 匹配。centerness 分支才是 FCOS 真正的创新点——几何中心性过滤低质量框，效果媲美复杂的 anchor 设计。

---

### DETR（Detection Transformer，ECCV 2020，Facebook）

**真正做了什么**：把目标检测变成集合预测，彻底去掉 NMS 和 anchor：

```
CNN backbone → 特征图展平成序列
↓
Transformer Encoder（token 自注意力，全局感受野）
↓
Transformer Decoder（N 个可学习 object query）
  每个 query 用 cross-attention 从 encoder 特征里提取信息
  输出 N 个（class, box）预测

Loss：匈牙利算法（二分图最优匹配）→ 预测集合和 GT 集合一一配对
```

**核心**：NMS 和 anchor 是人工后处理，DETR 用集合匹配 loss 让网络端到端学。代价：收敛慢（需要 500 epoch，Faster R-CNN 只要 36），Deformable DETR 用稀疏可变形注意力解决了这个问题。

---

## 自监督预训练

### 对比学习（Contrastive Learning，SimCLR/MoCo，2020）

**真正做了什么**：不用标签，同一张图的两个增强版本在特征空间相互靠近，不同图的特征互相推开：

```
图片 x → 增强 aug1 → encoder → z1
图片 x → 增强 aug2 → encoder → z2

Loss（InfoNCE）：
  L = -log [exp(sim(z1,z2)/τ) / Σ_k exp(sim(z1,z_k)/τ)]
  ↑ 正对相似度高，负样本相似度低

MoCo 改进：用 momentum encoder + queue 存负样本 → 不需要超大 batch
```

**核心**：把自监督转化为实例判别——每张图是自己独一无二的类别。数据增强的设计（裁剪/颜色抖动/翻转）决定网络学到什么不变性。

---

### MAE（Masked Autoencoder，CVPR 2022，Kaiming He）

**真正做了什么**：遮住 ViT 输入 75% 的 patch，让模型重建被遮住的像素：

```
图片 → 切成 N 个 patch
随机选 25% → 只有这些进 encoder（省掉 75% token 的计算）
被遮住的 patch 用 [MASK] token 补充 → lightweight decoder 重建原像素

Loss = MSE on masked patches only（不惩罚可见 patch）
```

**核心**：图像有大量冗余，75% 遮挡率才够难（BERT 只遮 15%）。只有 25% token 进 encoder，训练比 ViT 全量快 3× 以上。预训练后 fine-tune 效果超过监督预训练。

---

### CLIP（Contrastive Language-Image Pretraining，OpenAI 2021）

**真正做了什么**：用 4 亿图文对，让图像 encoder 和文本 encoder 输出对齐到同一空间：

```
图片 → ViT → 图像特征 v ∈ R^d
文字描述 → Transformer → 文本特征 t ∈ R^d

N 个样本组成 N×N 相似度矩阵：
  对角线（配对）相似度最大化
  非对角（不配对）最小化
  → 对行列分别做 cross-entropy

零样本推理：把所有类名写成"a photo of a {class}"→ 文本特征
           图像特征和所有类名文本特征计算相似度 → 最高的就是预测类别
```

**核心**：监督信号来自互联网自然存在的图文关系，不需要人工标注。零样本迁移——见过的语义概念都能分类，只需写文字描述。

---

### DINO / DINOv2（Self-Distillation，Meta 2021/2023）

**真正做了什么**：不用标签，Student 看局部 crop，Teacher 看全局，Student 要预测 Teacher 的输出分布：

```
图片 → 多个随机 crop（局部 + 全局）
Student encoder：处理所有 crop → 输出分布
Teacher encoder：只处理全局 crop（momentum 更新，不反传梯度）→ 目标分布

Loss：Student 输出 → minimize cross-entropy with Teacher 输出
     stop gradient on Teacher（防止 collapse）
```

**核心**：ViT 的 attention map 自发出现语义分割（无需任何分割标签）。DINOv2 在 1.4 亿图上训练，是目前最强通用视觉特征——下游任务线性 probe 媲美全量微调。

---

## 生成模型的核心机制

### GAN（Generative Adversarial Network，NeurIPS 2014，Goodfellow）

**真正做了什么**：两个网络对抗博弈，Generator 造假图，Discriminator 分辨真假：

$$\min_G \max_D \;\mathbb{E}[\log D(x)] + \mathbb{E}[\log(1 - D(G(z)))]$$

```
D 最大化：区分真假的能力
G 最小化：被 D 识别为假的概率

纳什均衡：G 生成分布 = 真实数据分布 → D 输出恒 0.5
```

**核心**：不显式定义"好图片"，通过对抗隐式学习数据分布。代价：训练不稳定（梯度消失/模式崩塌），WGAN 用 Wasserstein 距离+梯度惩罚解决稳定性，StyleGAN 用 AdaIN 实现风格控制。

---

### Diffusion Model / DDPM（NeurIPS 2020，Ho et al.）

**真正做了什么**：正向逐步加高斯噪声直到变成纯噪声，逆向过程学会逐步去噪：

$$q(x_t | x_{t-1}) = \mathcal{N}\!\left(x_t;\, \sqrt{1-\beta_t}\, x_{t-1},\, \beta_t I\right)$$

$$L = \mathbb{E}_{x_0, \varepsilon, t}\left[\|\varepsilon - \varepsilon_\theta(x_t, t)\|^2\right]$$

直接预测噪声 $\varepsilon$（比预测 $x_0$ 更稳定）。

```
DDIM：用非马尔可夫链跳步推理，1000 步 → 50 步
Stable Diffusion：把去噪放在 VAE 压缩的 latent space 做，速度 ×8
条件生成：把 CLIP 文本特征注入 UNet 去噪网络（via cross-attention）
```

**核心**：把生成转化为去噪——每步只预测当前噪声，化难为易。质量远超 GAN，但推理慢是固有缺点（多步迭代）。

---

## 密集连接

### DenseNet（Dense Connections，CVPR 2017，黄高）

**真正做了什么**：每一层的输入 = 所有前面层输出的 concat（不是相加）：

$$x_l = H_l([x_0, x_1, \ldots, x_{l-1}])$$

```
ResNet：  x_l = F(x_{l-1}) + x_{l-1}    ← 相加，维度不变
DenseNet：x_l = F(concat[x_0,...,x_{l-1}]) ← concat，通道线性增长

每层只增加 k 个通道（growth rate，通常 k=32）
第 l 层输入通道数 = k_0 + k×(l-1)（k_0 为初始通道数）
```

**核心**：梯度通过 concat 直接流到任何一层，天然解决梯度消失。特征复用——浅层精确特征不被覆盖，一直保留到最后。医学图像小数据场景下常用（HarDNet 是高效变种）。

---

## 注意力的空间增强

### CBAM（Convolutional Block Attention Module，ECCV 2018）

**真正做了什么**：先通道注意力再空间注意力，串联两步：

```
步骤1 - 通道注意力（增强版 SE）：
  MaxPool(空间) + AvgPool(空间) → 各得 [B, C, 1, 1]
  共享 MLP → sigmoid → 通道权重 → 乘回输入

步骤2 - 空间注意力：
  MaxPool(通道) + AvgPool(通道) → 各得 [B, 1, H, W]
  concat → 7×7 conv → sigmoid → 空间权重 → 乘回输入
```

**核心**：SE 只问"哪个通道重要"，CBAM 再问"哪个位置重要"。两步串联，参数极少（7×7 conv + 一个 MLP），可插入任意 block。

---

### Cross-Attention（编解码器注意力，原始 Transformer 2017）

**真正做了什么**：Q 来自一个序列，K/V 来自另一个序列——跨序列信息查询：

$$\text{Attn}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d}}\right)V$$
$$Q = W_Q \cdot x_{target}, \quad K = W_K \cdot x_{source}, \quad V = W_V \cdot x_{source}$$

```
应用场景：
  机器翻译：decoder query → encoder source 语言特征里找对齐
  DETR：object query → CNN 特征图里找目标位置
  Stable Diffusion：去噪网络 query → CLIP 文本特征（文字条件注入）
  你的 MLA：patch query → 多尺度特征里聚合信息（本质就是 cross-attention）
```

**核心**：Self-Attention 问自己，Cross-Attention 问别人。多模态融合、条件生成、Encoder-Decoder 的基础操作。

---

## 归一化扩展

### Group Normalization（GN，ECCV 2018，Kaiming He）

**真正做了什么**：把 C 个通道分成 G 组，每组内做归一化：

```
输入 [B, C, D, H, W]，分 G 组

BN：归一化 [B, D, H, W]       → B 太小时均值方差估计不准
IN：归一化 [D, H, W]          → 破坏通道间相关性
GN：归一化 [C/G, D, H, W]     → 不依赖 B，保留组内通道结构

G=1 时退化为 LN，G=C 时退化为 IN
```

**核心**：检测/分割任务 batch size 通常只有 1~2，BN 失效。GN 完全不依赖 batch，效果稳定。Mask R-CNN 后期版本、Detectron2 框架默认用 GN。

---

## 训练技巧的本质

### Mixup / CutMix（ICLR 2018 / ICCV 2019）

**真正做了什么**：

```
Mixup：新图 = λ·图A + (1-λ)·图B，标签也按 λ 混合
       λ ~ Beta(α, α)，α=0.2 时多数情况 λ 接近 0 或 1

CutMix：把图A的矩形区域替换成图B对应区域，标签按面积比混合
       剪切面积/全图面积 = λ → 标签 = λ·A + (1-λ)·B
```

**核心**：强迫网络对"中间状态"也预测正确，极大提升泛化，等价于隐式正则。CutMix 保留局部纹理真实性（Mixup 有虚假混叠），分类和分割任务都有效。

---

### Label Smoothing（标签平滑，Inception-v4 2016）

**真正做了什么**：把 one-hot 硬标签变成软标签：

$$y_{smooth} = (1 - \varepsilon) \cdot y_{one\text{-}hot} + \frac{\varepsilon}{K}$$

```
K=4，ε=0.1：
  硬标签：[0.000, 0.000, 1.000, 0.000]
  软标签：[0.025, 0.025, 0.925, 0.025]
```

**核心**：防止模型对正确类别过度自信（logit 趋向 +∞，等价于过拟合）。ViT 训练默认 ε=0.1，现代分类训练标配。

## 点云与三维表达

### PointNet / PointNet++（CVPR 2017，Stanford）

**真正做了什么**：直接处理无序点集，用 MLP + 全局 Max Pooling 学点云特征：

```
N 个点，每点 [x, y, z]

PointNet：
  每个点独立过共享 MLP → [N, d]（权重共享）
  Global Max Pooling over N → [d]（置换不变）

PointNet++（层次聚合）：
  Farthest Point Sampling → 选代表点
  Ball Query → 找邻域点
  局部 PointNet → 局部特征
  多层次聚合（类比 CNN 的感受野增大）
```

**核心**：点云是无序集合，传统 CNN 假设空间网格（不适用）。Max Pooling 是置换不变的——点的顺序任意排列输出相同。比体素化保留更精确位置，计算更省。

---

### NeRF（Neural Radiance Field，ECCV 2020，Berkeley）

**真正做了什么**：用一个 MLP 隐式表示 3D 场景，输入坐标 + 视角，输出颜色 + 密度：

$$F_\theta: (x, y, z, \theta, \phi) \to (R, G, B, \sigma)$$

```
渲染：沿光线采样 N 个点 → 每点过 MLP → (color, density)
     → 体积渲染积分 → 像素颜色

训练：多张已知相机参数的 2D 图片 → 监督渲染像素颜色
     → MLP 参数 = 整个 3D 场景
```

**核心**：MLP 参数本身就是"场景"，不需要任何显式 3D 结构。新视角合成质量极高。缺点：每个场景单独训练，推理慢（每像素多次 MLP 查询）。

---

### 3D Gaussian Splatting（ICCV 2023 Best Paper）

**真正做了什么**：用大量 3D 高斯椭球显式表示场景，每个高斯有位置/形状/颜色/透明度，用可微分 rasterizer 投影到 2D：

```
每个 3D Gaussian：μ（中心），Σ（协方差/形状），颜色（球谐系数），α（透明度）

渲染：3D Gaussian → 投影到 2D → 按深度排序 → alpha-blending 合成像素
训练：光度 loss 对所有参数求梯度，密度自适应（分裂过大/删除透明高斯）
```

**核心**：NeRF 隐式 MLP 渲染慢（30s/帧），3DGS 显式高斯快（100+ FPS）。显式表示可以直接编辑（移动/删除单个高斯）。当前 3D 重建和新视角合成的 SOTA 标准。

---

## 自动驾驶核心范式

### BEVFormer（BEV Perception，ECCV 2022）

**问题**：自动驾驶多摄像头角度各异，3D 感知需要融合到统一坐标系（BEV = Bird's Eye View）。

**真正做了什么**：在 BEV 平面定义可学习 grid query，用 Cross-Attention 从各视角图像特征里聚合信息：

```
BEV 平面：H×W 个 query（每个对应地面一个位置）

对每个 BEV query：
  把 3D 参考点投影到各摄像头图像平面
  用 Deformable Attention 从投影点附近采样特征
  所有摄像头采样结果加权融合 → BEV 特征

时序融合：
  当前帧 query 还 cross-attend 上一帧 BEV 特征
  → 动态目标速度估计更准
```

**核心**：不显式预测深度，用 cross-attention 的"软查询"让网络隐式学透视到 BEV 的几何变换。时序 BEV 使动态目标的运动估计稳定。Tesla 的 Occupancy Network 和 BEVFormer 是同一套思路。

---

## 分割基础模型

### SAM（Segment Anything Model，Meta 2023）

**真正做了什么**：训练可接受任意 prompt（点/框/掩码）的通用分割模型，在 10 亿掩码数据上预训练：

```
架构：
  Image Encoder：ViT-H（重，只跑一次，特征可缓存）
  Prompt Encoder：点/框 → sparse embedding；掩码 → dense embedding
  Mask Decoder：2 层 lightweight transformer → 掩码输出

推理：
  用户点一点 / 画一框 → <50ms 出掩码（Image Encoder 预计算）
```

**核心**：把"分割什么"变成"给 prompt，SAM 自动响应"——分割模型从专用变为通用。医学图像直接用 SAM 效果差（CT/MRI 域差距大），MedSAM 是其医学微调版本，用 LiTS 等数据集 fine-tune 后效果大幅提升。

## 高效微调范式

### Prefix Tuning / Prompt Tuning（ACL/EMNLP 2021）

**真正做了什么**：冻结模型全部参数，只在 attention 的 K/V 序列前加可训练的 prefix token：

```
标准 attention：Q attend [K_1, ..., K_N]
Prefix Tuning：Q attend [P_1, ..., P_k, K_1, ..., K_N]
               P 是可训练的，模型参数全冻结
               每层都加 prefix（共 L×k 个额外参数）

Prompt Tuning（更简单）：只在输入 embedding 层加 soft token，不在每层加
```

**核心**：LoRA 调权重矩阵，Prefix 调激活空间——两者都是极少参数高效微调，但方向不同。Prefix 更直觉：给模型"隐式提示"，引导其激活特定知识。

---

### Adapter（Adapter Tuning，Google 2019）

**真正做了什么**：在每个 Transformer block 里插入小型瓶颈网络，冻结原始参数只训练 Adapter：

```
原始 block：Attention → Add&Norm → FFN → Add&Norm
加 Adapter：Attention → Add&Norm → Adapter → FFN → Add&Norm → Adapter

每个 Adapter：
  d → r (down projection, r≪d)
  激活函数
  r → d (up projection)
  + 残差

参数量 = 2dr（r=64 时约为全量的 0.5%）
```

**核心**：LoRA 在权重上加低秩更新，Adapter 在架构上插瓶颈模块——两者殊途同归，都是只训练极少参数。Adapter 更模块化（可以插拔），LoRA 推理时可合并权重（无额外延迟）。

---

## 新型网络结构范式

### KAN（Kolmogorov–Arnold Networks，2024，MIT+PKU）

**真正做了什么**：把 MLP 里固定的激活函数换成可学习的一维样条函数：

```
MLP：y = σ(Wx + b)   ← σ 固定（ReLU/GELU），W 可学习
KAN：y = Σ_i φ_i(x_i)  ← φ_i 是可学习样条函数（B-spline），节点只做加法

每条边 = 一个独立的可学习函数曲线
```

**核心**：MLP 学"数值"（权重），KAN 学"函数形式"（曲线）。在科学计算（符号回归、PDE 求解）上参数效率更高——可以从学到的曲线里直接读出数学公式。视觉任务目前不如 MLP，但引发了"激活可学习"方向的讨论。

---

### Token Merging（ToMe，ICLR 2023，Meta）

**真正做了什么**：在 ViT 每个 block 之间，把相似的 token 合并，减少序列长度：

```
N 个 token → 二分图匹配找最相似 token 对 → top-r 对取均值合并
→ N-r 个 token 进下一个 block

ViT 计算量 ∝ N²，每层减少 r 个 token，L 层后剩 N - r×L 个
```

**核心**：ViT 的图像 patch 冗余极高（背景区域大量相似 token），合并后精度几乎不变（ImageNet 掉 0.2%），推理速度提升 2×。不改模型参数，推理时插入即可。
