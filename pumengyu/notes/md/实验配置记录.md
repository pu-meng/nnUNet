## 二、Mixin 功能速查

> 所有 Trainer 均由基类 `nnUNetTrainer` + 若干 Mixin 组合而成，实现在 `pumengyu/mixins.py`

| Mixin | 作用层面 | 核心机制 | 关键超参 |
|---|---|---|---|
| `SizeStratifiedOversampleMixin` | 数据采样 | 按肿瘤体素数百分位分层，不同大小 case 重复不同次数；边界从当前 fold 训练集自动算，无硬编码阈值 | `SSO_TINY_PCTL=20`, `SSO_SMALL_PCTL=45`, `SSO_HUGE_PCTL=90` 及各分层重复次数 |
| `NoMirrorMixin` | 数据增强 | 关闭训练和推理时所有轴的镜像增强；动机：肝脏右侧不对称，左右镜像产生解剖噪音 | 无 |
| `TumorOnlyTrainMixin` | 数据采样 | 从训练集剔除所有无肿瘤 case，验证集不变；故意让模型从未见"应全黑"输入 | 无 |
| `ExternalNoTumorMixin` | 数据采样 | 向训练集追加 25 个外部无肿瘤 case（CHAOS CT×20 + IRCADb×5），不修改 splits_final.json | `EXT_CASES` 列表 |
| `UnifiedFocalLossMixin` | Loss | CE+Dice 之上叠加 AsymmetricUnifiedFocalLoss（肿瘤类二值化），惩罚漏检 | `UFL_LAMBDA=0.5`, `UFL_DELTA=0.5`, `UFL_GAMMA=0.2` |
| `TverskyLossMixin` | Loss | 叠加 AsymmetricFocalTverskyLoss（delta=0.7），FN 惩罚是 FP 的 2.3 倍 | `TVL_DELTA=0.7`, `TVL_GAMMA=0.75`, `TVL_LAMBDA=1.0` |
| `NoTumorFPPenaltyMixin` | Loss | 对 GT 无肿瘤的 patch，额外惩罚"预测出肿瘤的概率均值"；有肿瘤 patch 不受影响 | `NTFP_LAMBDA=1.0` |
| `CopyPasteMixin` | 训练 step | 建小肿瘤 ROI 库；每个 batch 以 50% 概率从库中抽 ROI 粘贴到肝脏区域 | `CP_PROB=0.5`, `CP_MAX_LOCS=5000`, `CP_MARGIN=3` |
| `AutoReportMixin` | 辅助 | 验证结束后自动生成 `report_custom.json / .txt` | 无 |
| `AutoInternalTestMixin` | 辅助 | 验证结束后自动对测试集（26 case）推理并生成 `test_report_custom.txt` | 无 |

## 三、各 Trainer 完整配置

### 3.1 当前 results_v2 已跑实验

#### `nnUNetTrainer_Baseline`
```
继承链：AutoInternalTestMixin → AutoReportMixin → nnUNetTrainer
```
- 完全原版 nnUNet，零修改，作为所有对比实验的参照点
- **状态：✅ 已完成**

---

#### `nnUNetTrainer_SizeOversampleV2`
```
继承链：AutoInternalTestMixin → SizeStratifiedOversampleMixin → AutoReportMixin → nnUNetTrainer
```
- 过采样倍数：极小(≤P20)×**6**，小(P20~P45)×**5**，中/大×1，极大(>P90)×3，无肿瘤×**6**
- 相比 V1（×3/×2/×3/×3），大幅提升小肿瘤和无肿瘤曝光频率
- **状态：✅ 已完成**

---

#### `nnUNetTrainer_SizeOversampleV3`
```
继承链：AutoInternalTestMixin → SizeStratifiedOversampleMixin → AutoReportMixin → nnUNetTrainer
```
- 过采样倍数：极小×**8**，小×**6**，**中(P45~P90)×3**（V2 是 1×），极大×3，无肿瘤×6
- 在 V2 基础上新增中等肿瘤过采样，实现全尺寸均衡
- **状态：✅ 已完成（当前最优）**

---

#### `Tr_Stage1_TumorOnly`
```
继承链：AutoInternalTestMixin → TumorOnlyTrainMixin → AutoReportMixin → nnUNetTrainer
```
- 训练集只保留有肿瘤 case（~79/92），无肿瘤 case 全部剔除
- 目的：故意让模型从未见过"应全黑"的输入，推理时对无肿瘤 case 产生大量 FP 概率图
- 验证集不过滤（观察 FP 量，这是期望的行为）
- **状态：✅ 已完成（两阶段方案 Stage1）**

---

#### `nnUNetTrainer_NoMirror`
```
继承链：AutoInternalTestMixin → NoMirrorMixin → AutoReportMixin → nnUNetTrainer
```
- 关闭训练和推理时所有轴的镜像增强（nnUNet 默认开启 x/y/z 三轴）
- 消融目标：单一变量对照 Baseline，验证去除镜像对肝脏分割的影响
- **状态：🔲 待训练**
- 训练命令：
```bash
RESULTS_FOLDER=/home/PuMengYu/nnUNet_workspace/results_v2 \
nnUNetv2_train 3 3d_fullres 0 -tr nnUNetTrainer_NoMirror
```

## 六、消融分析结论

| 对比 | 肿瘤Dice变化 | 无肿瘤误报 | 结论 |
|------|-------------|----------|------|
| Baseline → SizeOversampleV2 | +0.032 (+4.9%) | 100%→66.7% | 过采样有效，提升分割同时降低误报 |
| SizeOversampleV2 → SizeOversampleV3 | -0.008 | 持平 | 中等肿瘤过采样略降整体 Dice，V2 综合更优 |
