# 显式结构复现鲁棒性实验

> 更新：2026-07-02  
> 新 Trainer：`nnUNetTrainer_DeepDWIBMedConfig`

---

## 1. 核心问题

本实验不是为了简单证明 DW+IB 有效，而是回答一个更细的问题：

> MedNeXt 的性能是否可以由论文/结构图中显式公开的信息独立复现？

换句话说，我们想区分两类贡献：

1. **显式结构范式**：通道数、block 数、expansion ratio、DW conv、inverted bottleneck、encoder-decoder 层级。
2. **隐性实现细节**：官方代码里的 block 内部顺序、up/down 细节、padding、normalization group 数、skip 处理、deep supervision 输出等。

如果只对齐显式结构信息、不复用官方 MedNeXt 代码，也能接近 MedNeXt，说明该方法鲁棒，核心贡献主要来自公开可复现的结构范式。

如果仍明显低于 MedNeXt，说明 MedNeXt 的性能不仅来自结构图，还依赖代码级微观实现细节。

---

## 2. 已有结果

| 模型 | 参数量 | 内部 Overall | 外部 Overall | 解释 |
|---|---:|---:|---:|---|
| DeepPlainResGN | ~61M | 0.7966 | 0.7442 | 深度 + 残差 + GN 不够 |
| DeepDWIBResGN | 58.12M | 0.8198 | 0.7886 | DW+IB 明显有效，但未复现 MedNeXt |
| MedNeXt-L | 61.78M | 0.8402 | 0.7705 | 官方/移植 MedNeXt-L |
| MedNeXt_MLA | — | 0.8259 | 0.8079 | 当前外部最优 |

`DeepDWIBResGN` 已经证明 DW+IB 是有效成分，但它没有对齐 decoder 的 block 组织和每层 expansion ratio，因此还不能回答“显式结构参数对齐后能否复现 MedNeXt”。

---

## 3. 新实验：DeepDWIBMedConfig

`nnUNetTrainer_DeepDWIBMedConfig` 对齐 MedNeXt-L 中显式可见的结构配置，但保持自写实现。

### 显式对齐项

| 项 | 配置 |
|---|---|
| channels | `32,64,128,256,512,256,128,64,32` |
| block_counts | `[3,4,8,8,8,8,8,4,3]` |
| expansion ratio | `[3,4,8,8,8,8,8,4,3]` |
| kernel size | `3` |
| block type | DW conv + inverted bottleneck + residual |
| skip fusion | add |
| deep supervision | `[full, 1/2, 1/4, 1/8, 1/16]` |

### 刻意不对齐项

这些属于论文图外部更难无歧义复现的代码级细节：

| 项 | 本实验处理 |
|---|---|
| 官方 MedNeXt 类 | 不复用 |
| up/down block 细节 | 用自写常规实现 |
| ConvTranspose 后 padding 细节 | 不照搬官方特殊 padding |
| GroupNorm 细节 | 使用 `GroupNorm(8)`，不照搬官方 `num_groups=in_channels` |
| conv bias / 初始化 | 使用自写默认 |
| checkpoint 包装方式 | 使用本项目现有写法 |

实际参数量：

| 模型 | 参数量 |
|---|---:|
| MedNeXt-L | 61,782,192 |

`DeepDWIBMedConfig` 与 MedNeXt-L 只差约 1.3%，适合作为参数量近似对齐的独立复现实验。

## 5. 判定标准

| 结果 | 解释 |
|---|---|
| 接近 MedNeXt-L 内部 0.8402 | 显式结构信息足以复现主要性能，MedNeXt-like DW+IB 设计鲁棒 |
| 明显高于 DeepDWIBResGN 0.8198，但低于 MedNeXt | block_counts/exp_r 等显式超参数很重要，但仍有代码细节贡献 |
| 接近 DeepDWIBResGN 0.8198 | 对齐显式配置收益有限，性能主要依赖更微观实现或官方结构细节 |

推荐论文表述：

> We construct an explicit-configuration MedNeXt-like model by aligning the publicly visible architectural hyperparameters, including channel widths, block counts, expansion ratios, and encoder-decoder hierarchy, while keeping the implementation independent from the official MedNeXt code. This evaluates whether MedNeXt-level performance can be recovered from the explicit architecture alone.

中文表述：

> 我们构建了一个显式结构参数对齐的 MedNeXt-like 模型，对齐通道数、block 数、expansion ratio 和 encoder-decoder 层级，但不复用官方 MedNeXt 代码，也不一比一复刻 block 内部实现细节。该实验用于检验 MedNeXt 的性能是否可以由公开可见的结构设计独立复现。
