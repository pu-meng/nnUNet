# 论文主线

> 状态：当前论文决策入口。正式主稿仍为 [`../paper/论文v3.md`](../paper/论文v3.md)。
>
> 更新：2026-09-02。主方法确定为 `MedNeXt_MLA_MoE`；“外部可靠性”是评价问题，尚未确定为论文标题或已被证明的方法优势。

## 一、已确定的主线

论文以 `MedNeXt_MLA_MoE` 为主方法，不再以 FP-Safe 为主创新。

当前可以固定的方法描述是：

> 保留 MedNeXt-L 的强局部卷积编码器、bottleneck、加法跳跃连接和解码器，仅在 512 通道最低分辨率卷积 bottleneck 后加入两个 MLA+MoE block，研究低分辨率全局交互和 token 条件变换如何影响三维肝肿瘤分割。

主方法的代码事实：

- 父基线是 `MedNeXt-L`，不是普通 nnU-Net `PlainConvUNet`；
- MLA 使用 `512→128` 共享低秩 K/V 投影，随后分别上投影回 512 维；
- MoE-FFN 包含 1 个 shared expert、4 个 routed experts 和 Top-2 选择；
- 当前代码仍计算全部 routed experts，不声称真实稀疏计算加速；
- 解码顺序是 `UpBlock → 形状对齐 → 与 x_res_i 逐元素相加 → decoder stage`。

## 二、尚未确定的论文问题

“主方法是 MLA+MoE”已经确定，但论文最终问题定义和标题仍需要根据修复后重训结果决定。

当前可以保留的候选问题是：

1. 强局部卷积表征与最低分辨率全局交互是否互补；
2. 低秩 K/V attention 和 MoE-FFN 的交互效应是什么；
3. MLA+MoE 在不同数据域为什么出现排名反转和失败模式差异。

“外部可靠性”暂时只作为评价维度，不作为已证实的方法优势，原因是：

- 旧结果中 MLA+MoE 在 IRCADb 上改善明显；
- HCC 上纯 MLA 优于 MLA+MoE；
- internal 与 MedNeXt 的差异很小；
- 现有 MoE 训练受路由状态与 gradient checkpointing 一致性缺陷影响，需修复后重训复核。

因此，当前最安全的表述是“跨数据域行为或数据域依赖性”，不是“统一提升外部可靠性”。

## 三、必须围绕主方法完成的对照

### 3.1 基线层级

| 类型 | 方法 | 用途 |
|---|---|---|
| 框架基线 | nnU-Net `PlainConvUNet` | 说明相对默认 nnU-Net 的变化 |
| 方法父基线 | `MedNeXt-L` | 直接衡量 MLA/MoE 在强卷积骨干上的增量 |
| 强比较方法 | `EfficientMedNeXt-L`等 | 比较强卷积及效率路线 |

### 3.2 核心结构消融

保留 MHA/MLA × MLP/MoE 的 2×2 矩阵：

| Attention | FFN | 方法 |
|---|---|---|
| MHA | MLP | `MedNeXt_MHA` |
| MLA | MLP | `MedNeXt_MLA` |
| MHA | MoE | `MedNeXt_MHA_MoE` |
| MLA | MoE | `MedNeXt_MLA_MoE` |

另需 parameter-matched dense control，用于排除“MoE 收益只来自参数量增加”的解释。

### 3.3 评价层级

- Dataset003/LiTS 风格 internal test；
- 3D-IRCADb；
- HCCReferencedCT v2；
- 病例级统计、小病灶、无肿瘤误报和典型失败分析；
- 参数量、FLOPs、峰值显存和推理时间分开报告。

三个数据域分别报告，不将其合并成一个“外部泛化分数”。

## 四、已降级的旧主线

FP-Safe 不再作为论文主创新。现有证据显示，它虽然改善部分 internal 无肿瘤误报，但三个数据域的 Overall 均下降，并且 IRCADb 误报没有改善。

它的定位是：

- 负结果/次要消融；
- 说明单纯的 no-tumor Top-K 惩罚不能稳定解决跨域误报；
- 不进入标题，不作为主方法名称。

## 六、当前书写边界

现阶段可以写：

- `MedNeXt_MLA_MoE` 是当前主方法；
- MLA 和 MoE 的真实结构、维度变化和控制变量设计；
- 旧结果显示明显的数据域依赖性，重训将检验该现象是否保留；
- FP-Safe 是负结果，SizeOV4 是训练/采样对照，不与主结构贡献混同。

现阶段不能写：

- MLA+MoE 已经统一提升跨域可靠性；
- MoE 已形成可解释的专家分工；
- Top-2 带来实际稀疏推理加速；
- 旧 MoE 数字已通过修复后训练复核；
- 收益已被严格归因于 MLA 或 MoE 单一组件。
