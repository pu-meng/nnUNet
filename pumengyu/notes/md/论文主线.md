# 论文主线

日期：2026-06-28

## 一、当前定位

本论文不再以“提出一个新架构并在内部测试集刷最高 Dice”为主线。

当前主线调整为：

> 临床安全的肝脏肿瘤分割：降低无肿瘤误报、保持小肿瘤召回、提升跨域泛化。

核心观点：

> 高 Dice 的模型不一定临床安全。同域测试集上强大的 MedNeXt 在外部 IRCADb 验证上出现明显性能下降，而一些 MLA/MoE/SizeOV 系列模型虽然内部测试不一定第一，但外部泛化更稳定。因此论文应围绕 false-positive-aware 和 cross-domain robustness 组织。

## 二、为什么不继续押 MLA/MoE 主创新

已有结果说明：

- MLAUNet / MoE 系列有一定效果，但内部测试没有稳定超过 MedNeXt。
- MLAUNet_MoE_SizeOV4 内部 Overall 约 0.8330，低于 MedNeXt_SizeOV4 的 0.8431。
- MedNeXt 是强 published baseline，说明单纯说“新架构更强”不稳。
- MoE 单独增益有限，容易被审稿人认为是复杂组件堆叠。

因此，MLA/MoE 不作为唯一主创新，而作为泛化和全局建模方向的证据之一。

## 三、真正的问题

肝脏肿瘤分割中，临床更关心：

1. 无肿瘤 case 不能乱报肿瘤。
2. 极小肿瘤不能完全漏检。
3. 模型不能只在 LiTS 内部测试集上好看，换到 IRCADb 就掉点。
4. 高 Overall Dice 不能掩盖 false positive 风险。

已有实验中反复出现的问题：

- Baseline Recall 高，但无肿瘤误报严重。
- MedNeXt / MedNeXt_SizeOV4 内部测试最强，但外部验证 drop 明显。
- NoMirror 外部验证崩溃，说明跨域泛化依赖正确增强策略。
- 多个模型都在 liver_41 这类无肿瘤 case 上产生大体积误报。
- 极小肿瘤仍是共同失败点。
- 简单连通域体积阈值后处理不可靠，因为真实 TP 连通域可能极小。

## 四、已有关键证据

### 4.1 内部测试集

Dataset003_Liver 内部测试集：26 cases，其中 23 例有肿瘤，3 例无肿瘤。

关键结果：

| 方法 | Liver Dice | Tumor Dice | Overall | 误报率 |
|---|---:|---:|---:|---:|
| MedNeXt_SizeOV4 | 0.9545 | 0.7317 | 0.8431 | 33% |
| MedNeXt | 0.9521 | 0.7283 | 0.8402 | 33% |
| MLAUNet_MoE_SizeOV4 | 0.9514 | 0.7146 | 0.8330 | 33% |
| MedNeXt_MLA_SizeOV4 | 0.9529 | 0.7040 | 0.8285 | 67% |
| SizeOversampleV2 | 0.9516 | 0.6858 | 0.8187 | 67% |
| MLAUNet | 0.9503 | 0.6793 | 0.8148 | 67% |
| Baseline | 0.9340 | 0.6542 | 0.7941 | 100% |
| DeepPlainResGN | 0.9455 | 0.6477 | 0.7966 | 67% |
| DeepPlainResGN_SizeOV4 | 0.9407 | 0.6409 | 0.7908 | 100% |

结论：

- MedNeXt 系列内部测试最强。
- Baseline 召回高但误报严重。
- DeepPlainResGN 没有接近 MedNeXt，说明“深度 + 残差 + GN + 参数量”不能解释 MedNeXt 的全部优势。
- DW+IB / MedNeXt block 可能是 MedNeXt 内部强性能的重要原因。

### 4.2 外部验证集

IRCADb 外部验证集：20 cases，其中 15 例有肿瘤，5 例无肿瘤。

关键结果：

| 方法 | 外部 Overall | 内部 Overall | Drop |
|---|---:|---:|---:|
| MoE_SizeOV5 | 0.8025 | 0.8167 | -0.0142 |
| MLAUNet | 0.8008 | 0.8148 | -0.0140 |
| SizeOV2 | 0.7992 | 0.8187 | -0.0195 |
| MLA_GK5_V4 | 0.7957 | 0.8173 | -0.0216 |
| MedNeXt_MLA_SizeOV4 | 0.7870 | 0.8285 | -0.0415 |
| MedNeXt_SizeOV4 | 0.7797 | 0.8431 | -0.0634 |
| Baseline | 0.7727 | 0.7941 | -0.0214 |
| MedNeXt | 0.7705 | 0.8402 | -0.0697 |
| DeepResGN_MLA | 0.7551 | 0.7969 | -0.0418 |
| DeepPlainResGN | 0.7442 | 0.7966 | -0.0524 |

结论：

- MedNeXt 内部强，但外部 drop 大。
- MLAUNet 和 MoE_SizeOV5 外部验证更稳。
- Baseline 虽然内部不高，但 drop 比 MedNeXt 小。
- 论文可以强调：同域最高分不代表跨域鲁棒。

## 五、新方法方向：FP-Safe

当前确定的新方法主线：

> FP-Safe Liver Tumor Segmentation

目标：

1. 降低无肿瘤 case 的 false positive。
2. 保持有肿瘤 case 的 Dice 和 Recall。
3. 缩小内部测试与外部验证之间的 drop。
4. 把临床安全性作为评价重点，而不是只看平均 Dice。

### 5.1 第一阶段方法

已实现：`TopKNoTumorFPPenaltyMixin`

Loss：

```text
L = L_CE+Dice + lambda_fp * mean(topk(P_tumor | no-tumor sample))
```

默认参数：

```text
TKN_TOPK_PERCENT = 0.01
TKN_TUMOR_FP_LAMBDA = 1.0
```

设计理由：

- 旧的 `NoTumorFPPenaltyMixin` 惩罚 mean tumor probability，容易被大片背景稀释。
- false positive 通常是局部高置信区域，因此 Top-K 惩罚更直接。
- 该 loss 只作用于 GT 无肿瘤 sample，不直接影响有肿瘤 sample 的分割路径。

### 5.2 已新增 Trainer

```text
nnUNetTrainer_FPSafe
nnUNetTrainer_SizeOV4_FPSafe
nnUNetTrainer_MedNeXt_FPSafe
```

对应目标：

| Trainer | 目标 |
|---|---|
| nnUNetTrainer_FPSafe | 验证 FP loss 本身是否有效 |
| nnUNetTrainer_SizeOV4_FPSafe | 验证采样 + FP loss 是否协同 |
| nnUNetTrainer_MedNeXt_FPSafe | 验证强 backbone 上是否能降低误报和外部 drop |

详细计划见：


## 七、如果 FP-Safe 第一阶段有效

论文贡献可以写成：

1. 提出 false-positive-aware Top-K loss，显式抑制无肿瘤 case 的高置信假阳性。
2. 结合 size-aware sampling，缓解小肿瘤与无肿瘤 case 的训练长尾。
3. 在 LiTS 内部测试和 IRCADb 外部验证上系统证明：FP-Safe 能提升临床安全性和跨域鲁棒性。
4. 系统分析强 baseline 的同域-跨域差异，说明高内部 Dice 不等于临床可靠。

## 八、如果 FP-Safe 第一阶段不够有效

可继续做：

### 8.1 Tumor Presence Auxiliary Head

分割网络额外预测 patch/case 是否含肿瘤。

Loss：

```text
L = L_seg + lambda_cls * L_presence + lambda_fp * L_topk_fp
```

目标：让模型学会“这个 patch 是否应该存在肿瘤”，进一步降低无肿瘤误报。

### 8.2 Candidate-level FP Classifier

推理后对每个预测肿瘤连通域提特征：

- 体积
- mean/max probability
- HU 均值/方差
- compactness
- 到肝边界距离
- 是否在肝内

训练轻量分类器过滤 FP：

```text
segmentation network -> tumor candidates -> FP classifier -> final mask
```

这条路线适合写临床安全后处理模块。

### 8.3 Hard Negative Mining

动态记录误报 case，把无肿瘤误报 case 提高采样概率。

## 十、论文结构草案

### 1. Introduction

核心逻辑：

- 肝肿瘤分割已有 nnUNet、MedNeXt 等强方法。
- 但仅看内部测试 Dice 不够，临床应用更关心误报和跨域泛化。
- 无肿瘤 case 的 false positive 会导致不必要的临床负担。
- 极小肿瘤漏检也很关键。
- 本文提出 FP-Safe，并通过内部测试 + IRCADb 外部验证系统评估。

## 十一、当前一句话总结

> 本论文的核心不是声称一个复杂新架构全面超过 MedNeXt，而是证明并解决一个更临床真实的问题：高同域 Dice 的肝肿瘤分割模型仍可能在无肿瘤病例和外部数据上不安全；FP-Safe 通过显式抑制无肿瘤高置信假阳性，朝临床安全和跨域稳健方向改进。
