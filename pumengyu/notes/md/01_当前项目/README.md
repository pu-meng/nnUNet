# 当前项目

这是日常阅读的主目录，只保留四份核心文档。这里的原则是：README 只负责导航；实验状态、结果结论、方法解释和研究问题各有唯一入口，不再保留重复的“项目交接稿”或平行汇报稿。

1. [`研究问题来源与论文分类汇报.md`](研究问题来源与论文分类汇报.md)：论文问题的五类来源和代表论文。
2. [`当前方法与架构.md`](当前方法与架构.md)：方法的真实代码结构与计算边界。
3. [`当前实验与重训.md`](当前实验与重训.md)：重训命令、运行状态、验收标准和后续决策。
4. [`当前结果与结论.md`](当前结果与结论.md)：修复后当前结果、统计结论，以及明确标注的历史全量结果快照。

阅读顺序：先看本页，再看实验状态；需要了解结构时看方法文档，需要讨论论文定位时看研究问题文档。完整病例、原始实验和专项审计仍在 [`../02_实验档案/`](../02_实验档案/README.md)，不在本目录复制。

需要追溯细节时，再进入 [`../02_实验档案/`](../02_实验档案/README.md)。
