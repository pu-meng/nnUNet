# SAM Paper Vocabulary Notes

来源：Segment Anything (SAM) 论文阅读笔记

---

# 1. Core Concepts

## loop

含义：
- 循环
- 闭环

论文语境：

data engine loop

模型帮助标注数据  
→ 获得新的数据  
→ 新数据训练模型  
→ 模型能力增强  
→ 再帮助标注更多数据

表示一种数据-模型互相促进的闭环。

---

## zero-shot

含义：
- 零样本

论文语境：

模型没有针对新的任务进行训练，
但是可以直接完成任务。

例如：

SAM 在没有训练肝脏分割任务的情况下，
通过 prompt 仍然可以完成部分分割。

---

## promptable

含义：
- 可提示的
- 可以通过 prompt 控制

论文语境：

输入：

image + prompt

输出：

mask

prompt 可以是：

- point
- box
- mask
- text

---

# 2. Prompt Related

## engineered text prompts

含义：

人工设计的文本提示词

拆分：

engineered:
- 人工设计的
- 精心构造的

text prompts:
- 文本提示

例如：

"cat with black ears"

作为模型输入提示。

---

## prompted

含义：

被提示的

论文语境：

prompted segmentation

表示：

通过 prompt 指导模型完成分割。

---

## foreground point

含义：

前景点

论文语境：

位于目标内部的点击点。

例如：

点击肝脏区域中的一个点：

foreground point

点击背景：

background point

---

## grid

含义：

网格

论文语境：

grid of points

表示：

在图像中按照规则布置大量点。

---

# 3. Common Academic Words

## albeit

含义：

虽然；尽管

常见结构：

albeit + adj/adv

例如：

albeit slightly better

虽然稍微更好。

---

## albeit to a less extent

含义：

虽然程度较小

例如：

A improves performance,
albeit to a less extent.

A 提升了性能，
但是提升幅度较小。

---

## broad

含义：

广泛的

例如：

broad range of tasks

广泛的任务范围。

---

## hinge on

含义：

取决于；关键依赖于

例如：

Performance hinges on data quality.

性能取决于数据质量。

---

## entangled

含义：

纠缠的；相互关联的

论文语境：

多个因素无法简单分离。

例如：

Data size and model scale are entangled.

数据规模和模型规模相互影响。

---

## comprehensive

含义：

全面的；综合性的

例如：

comprehensive evaluation

全面评估。

---

## objective

含义：

目标

例如：

training objective

训练目标函数。

---

# 4. Evaluation Related

## a suite of

含义：

一整套；一系列

注意：

suite ≠ suit

例如：

a suite of experiments

一系列实验。

---

## evaluate

含义：

评估；评价

例如：

evaluate model performance

评估模型性能。

---

## verify

含义：

验证；核实

区别：

evaluate:
评价表现如何

verify:
确认某个结论是否正确

例如：

verify the effectiveness

验证有效性。

---

## consistently

含义：

一致地；稳定地

例如：

consistently outperforms

持续稳定超过。

表示不是偶然一次结果。

---

## annotated

含义：

标注的

例如：

manually annotated mask

人工标注的 mask。

---

## manually

含义：

手动地；人工地

例如：

manually labeled data

人工标注数据。

---

## human ratings

含义：

人工评分

论文语境：

由人评价模型输出。

区别：

automatic metrics:
自动指标

human ratings:
人工评价

---

# 5. Transfer / Data

## transfer protocol

含义：

迁移协议；迁移方案

论文语境：

描述模型如何从一个任务迁移到另一个任务。

包括：

- 是否 fine-tune
- 使用多少数据
- 如何测试

---

## preliminary

含义：

初步的

例如：

preliminary results

初步结果。

表示：

结果还不是最终结论。

---

## nevertheless

含义：

然而；尽管如此

逻辑：

虽然前面存在问题，
但是后面的结论仍成立。

---

# 6. Release / Open Source

## release

含义：

发布；公开

例如：

release the model

发布模型。

---

## permissive

含义：

宽松的；限制较少的

论文语境：

permissive license

宽松开源许可证。

允许：

- 使用
- 修改
- 分发

限制较少。

---

## showcase

含义：

展示；展现

例如：

showcase capability

展示能力。

---

# 7. Linux / Engineering Notes

## EACCES

Linux 权限错误。

含义：

Permission denied

没有访问权限。

---

## errno -13

表示：

permission denied

权限不足。

---

## npm

Node Package Manager

Node.js 软件包管理工具。

类似：

Python:
pip

Ubuntu:
apt

Conda:
conda

---

## -g

含义：

global

全局安装。

例如：

npm install -g package

安装到系统全局位置。

---

## syscall

含义：

system call

系统调用。

程序请求操作系统执行功能。

例如：

创建文件：

mkdir syscall
