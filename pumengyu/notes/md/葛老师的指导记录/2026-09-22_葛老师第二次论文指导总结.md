## 2.3 建立已有方法的对比实验表

这次明确理解了一个很重要的问题：

> **引入已有论文结果的主要目的，是建立对比坐标系，而不是证明引用的每一篇论文都是顶级 SOTA。**

因此，comparison paper：

- 不要求全部是顶区论文；
- 不要求全部是最新论文；
- 不要求全部开源；
- 不要求每个方法都在三个数据集上有完整结果。

真正重要的是：

- 数据集尽量一致；
- 任务一致；
- 指标一致；
- 实验口径尽量接近；
- 如果 split / protocol 不一致，需要明确注明；
- 论文没有报告的数据可以写 `–`。

例如：

| Type | Method | LiTS | IRCAD | HCC |
|---|---|---:|---:|---:|
| CNN | Method A | ✓ | – | – |
| ViT | Method B | ✓ | ✓ | – |
| Hybrid | Method C | – | ✓ | ✓ |
| **Ours** | **Proposed Method** | ✓ | ✓ | ✓ |

核心是形成一个：

> **可信、清楚、能解释自己方法处于什么位置的比较表。**

# 3. Idea 1：基于 MoE 的层级信息传播 / Skip Filtering

葛老师指出：

传统 Encoder-Decoder 中的 skip connection 往往是直接连接。

这种方式的问题是：

> **浅层特征中的有效信息和无效信息都会被直接传给 Decoder。**

也就是说，skip connection 本身是一种比较“粗暴”的信息传播方式。

---

## 3.1 研究动机

可以把问题定义为：

> 如何在 Encoder → Decoder 的层级传播过程中，只传递真正有价值的信息，而不是把所有浅层特征全部直接送入 Decoder？

一种常见办法是 attention。

但问题是：

- attention 计算复杂；
- 3D medical segmentation 中空间 token 数量大；
- 多层使用 attention 成本更高。

因此可以考虑：

> **使用轻量 MoE / Router 代替复杂 attention，完成 skip feature 的选择与过滤。**

---

## 3.2 基本结构

假设第 $l$ 层 Encoder 特征为：

$$
E_l
$$

同时引入一个更高层的 reference feature：

$$
R_l
$$

Router 根据当前 Encoder feature 和 reference feature 判断：

> 当前这一层应该调用哪些 expert、保留哪些信息。

可以表示为：

$$
g_l =
\operatorname{Softmax}
\left(
\operatorname{MLP}
\left[
\operatorname{GAP}(E_l),
\operatorname{GAP}(R_l)
\right]
\right)
$$

不同 Expert 处理 Encoder feature：

$$
X_l^{(k)} = Expert_k(E_l)
$$

最终得到过滤后的 skip feature：

$$
\tilde E_l=
E_l+
\sum_{k=1}^{K}
g_{l,k}X_l^{(k)}
$$

再将：

$$
\tilde E_l
$$

传给 Decoder。

---

## 3.3 核心思想

这不是简单地：

> “给 MedNeXt 再加一个 MoE”。

而是围绕一个具体问题：

> **Skip connection 中的信息应该被选择性传播。**

可以形成更明确的论文表述：

> **Reference-guided hierarchical feature filtering**

或：

> **MoE-based selective skip information propagation**

核心贡献应强调：

- 层级 skip 不再直接粗暴传递；
- 引入 reference feature 作为判断依据；
- Router 负责信息选择；
- Expert 负责不同类型的特征处理；
- 相比 full attention 更轻量。

# 4. Idea 2：Few-shot Reference Memory

第二个方向是：

> 使用少量具有代表性的病例作为 memory/reference，辅助当前病例的分割。

---

## 4.1 基本思想

传统模型：

$$
X \rightarrow Model \rightarrow Mask
$$

新的思路：

$$
X + Reference\ Memory
\rightarrow Model
\rightarrow Mask
$$

也就是说，模型在处理当前病例时，不只是依赖当前病例自身的信息，还可以参考少量过去的典型病例。

---

## 4.2 Memory 中不一定保存原始 CT

可以保存少量病例经过 Encoder 后得到的多尺度特征：

$$
\mathcal M=
\{M_1,M_2,\dots,M_N\}
$$

对于当前病例的特征：

$$
F_l
$$

首先计算与 memory feature 的相关性。

可以使用：

- cosine similarity
- attention
- gating
- lightweight router

然后只选择真正相关的 reference：

$$
M_l^*=
\sum_i
\alpha_iM_{i,l}
$$

最后进行特征融合：

$$
\tilde F_l=
F_l+
G_l(F_l,M_l^*)\odot M_l^*
$$

---

## 4.3 为什么需要“过滤”

关键不是：

> 把 memory 全部加进去。

而是：

> **memory 只能作为参考，只有真正有帮助的信息才应该进入当前病例。**

因此可以使用：

- Attention
- Gate
- Router
- Similarity selection

控制 reference information 的注入。

---

# 5. 两个 Idea 其实可以统一到一个主题

这两个方向表面上分别是：

1. Encoder → Decoder 的内部信息传播；
2. Memory → Current case 的外部信息传播。

但它们的核心其实一致：

# **Selective Information Propagation**

即：

> **不是所有信息都应该被无条件传播，模型需要学习“什么信息值得传、传多少、传到哪里”。**

---

## 5.1 内部信息传播

$$
Encoder
\rightarrow
Selective\ Filtering
\rightarrow
Decoder
$$

解决：

> Skip connection 中的信息冗余与无效传播。

---

## 5.2 外部信息传播

$$
Memory
\rightarrow
Retrieval/Filtering
\rightarrow
Current\ Feature
$$

解决：

> Reference information 中并不是所有内容都适合当前病例。

---

## 5.3 可以形成统一的论文故事

最终论文不应该写成：

> MedNeXt + MLA + MoE + Attention + Memory

而应该形成一个统一问题：

> **如何在医学图像分割中实现有效、轻量、选择性的信息传播？**

然后所有模块都围绕这个问题服务。

这样论文会从“模块堆叠”转变成：

> **问题驱动的方法设计。**

# 8. 当前论文的四个核心组成部分

从今天开始，可以把论文推进压缩成四个核心任务：

## ① Method Figure

把方法讲清楚。

## ② Main Results

证明方法有效。

## ③ Comparison

说明方法在已有研究中的位置。

## ④ Ablation

证明提升来自哪些设计。

只要这四部分不断被补齐，论文就会越来越接近完整。
