# MedNeXt 选择性跳跃连接实验设计

**设计日期：2026-09-29**
**当前状态（2026-10-01）：E1 已完成三域正式评估；E2 已实现并通过 CPU 前向/反向与恒等初始化检查，尚未启动训练。历史 MedNeXt（E0）只作为参考对照，不让严格的重跑配对阻塞主线。**

## 一句话结论

第一步在纯 MedNeXt 上验证“encoder 特征是否应该经过 decoder 条件过滤后再传播”。推荐先实现轻量的 **Decoder-Conditioned Selective Skip（DCSS）**，不要同时加入 MLA、MoE、Memory、SizeOV 或新损失。只有轻量门控优于原始桥联和参数匹配对照后，才进入 MoE 桥联实验。

## 1. 当前问题

当前 MedNeXt-L 有四条 encoder–decoder 跳跃连接，每一级都是直接相加：

\[
F_i^{out}=D_i+E_i
\]

其中：

- \(E_i\)：第 \(i\) 级 encoder 输出，包含空间细节和局部纹理；
- \(D_i\)：第 \(i\) 级 decoder 上采样特征，表示当前解码阶段需要恢复的语义；
- \(F_i^{out}\)：送入后续 decoder block 的融合特征。

代码中的四级融合均为 `encoder skip + decoder upsample`，没有判断 encoder 信息是否与当前 decoder 语义匹配。因此待验证的问题不是笼统的“增加一个注意力模块”，而是：

> decoder 能否根据当前解码需求，只接收 encoder 中与肝脏、肿瘤及其边界有关的信息，并抑制不匹配的纹理、背景和噪声？

## 2. 研究问题与可证伪假设

### Research Question

在三维肝脏肿瘤分割中，MedNeXt 的无条件加法跳跃连接是否会传递与当前 decoder 阶段不匹配的信息？decoder 条件的空间–通道过滤能否改善肿瘤分割和跨域稳定性？

### H1

在不修改 MedNeXt 主干、训练策略和损失函数的条件下，使用 decoder 条件门控过滤 encoder skip，可以：

1. 保持肝脏 Dice 基本稳定；
2. 提高肿瘤 Dice、Recall 或 lesion-wise recall；
3. 降低完整漏检和背景误报；
4. 在 LiTS、3D-IRCADb-01、HCC-TACE-Seg 中至少表现出跨种子、跨数据域的一致改善，而不是只提高训练域结果。

## 3. 推荐方法：DCSS

在每一级桥联中，先由 encoder 特征和 decoder 特征共同生成门控：

\[
H_i=\operatorname{GELU}
\left(
\operatorname{GN}(W_eE_i+W_dD_i)
\right)
\]

然后分别计算空间选择和通道选择：

\[
Z_i=Z_i^{spatial}+Z_i^{channel}
\]

使用恒等初始化门控：

\[
G_i=1+\tanh(Z_i)
\]

过滤后的 skip 和融合结果为：

\[
\tilde E_i=G_i\odot E_i
\]

\[
F_i^{out}=D_i+\tilde E_i
\]

### 输入、层和输出

- 输入：\(E_i,D_i\in\mathbb R^{B\times C_i\times D_i\times H_i\times W_i}\)。
- `1×1×1 Conv`：把 encoder 和 decoder 映射到相同的轻量隐藏维度。
- 空间分支：输出 \(B\times1\times D_i\times H_i\times W_i\)，选择三维位置。
- 通道分支：全局池化后输出 \(B\times C_i\times1\times1\times1\)，选择特征类型。
- 输出：\(\tilde E_i\) 与原 skip 形状完全一致，继续与 \(D_i\) 相加。

最后一层卷积和全连接层零初始化，使训练开始时 \(Z_i=0\)、\(G_i=1\)。因此初始网络严格等价于原始 MedNeXt：

\[
D_i+1\cdot E_i=D_i+E_i
\]

这可以避免普通 sigmoid 门在初始化时把 skip 统一缩小到约 0.5，也降低小肿瘤信息在训练早期被错误关闭的风险。

## 4. 最小可行实验

第一轮只训练四组：

| 编号 | 方法 | 桥联方式 | 要回答的问题 |
|---|---|---|---|
| E0 | MedNeXt | \(D+E\) | 原始基线 |
| E1 | MedNeXt + Skip Conv | \(D+\operatorname{Conv}(E)\) | 增加参数和特征变换本身是否有效 |
| E2 | MedNeXt + Spatial Attention Gate | decoder 条件空间门 | 经典空间过滤是否有效 |
| E3 | MedNeXt + DCSS | decoder 条件空间门 + 通道门 | 同时选择位置和通道是否优于 E0–E2 |

E1 是必要的参数匹配对照。如果缺少 E1，E3 的提升不能排除“只是增加了卷积和参数”的解释。

### 控制变量

四组实验必须使用：

- 相同的 Dataset003_Liver 数据和 fold；
- 相同训练、验证、内部测试病例清单；
- 相同随机种子；
- 相同 patch、batch size、数据增强和 oversampling；
- 相同 CE + Dice loss；
- 相同优化器、学习率计划、训练 epoch 和深监督；
- 相同推理参数和 mirror TTA；
- 全部从头训练。

第一轮不得同时加入 MLA、MoE、Memory、SizeOV、GRN、新损失或 HCC 适配，否则无法隔离 skip 过滤的贡献。

## 5. 扩展消融

只有 E3 在最小实验中优于 E0 和 E1，才继续以下实验：

| 消融 | 验证目的 |
|---|---|
| 空间门 only | 空间定位是否贡献主要收益 |
| 通道门 only | 通道语义选择是否有效 |
| 空间门 + 通道门 | 两种选择是否互补 |
| 仅浅层 skip 0–1 | 是否主要改善边界和小肿瘤细节 |
| 仅深层 skip 2–3 | 是否主要抑制语义不匹配 |
| 四层全部使用 | 完整方法 |
| 不输入 decoder 特征 | 判断收益是否真正来自 encoder–decoder 匹配 |
| 普通 sigmoid、无恒等初始化 | 判断恒等初始化是否提高稳定性 |

可以先对已训练 MedNeXt 做“推理时屏蔽单条 skip”的低成本敏感性检查，用来选择优先训练的尺度。但这种检查会产生分布偏移，只能作为筛选依据，不能代替重新训练后的正式消融。

## 6. 第二阶段：MoE 桥联

只有 DCSS 证明“选择性过滤”有效后，再扩展为 Mixture of Skip Experts：

| Expert | 作用 |
|---|---|
| Identity expert | 保留原始 encoder 信息 |
| Local expert | 使用 `3×3×3 depthwise convolution` 做局部去噪 |
| Context expert | 使用空洞 depthwise convolution 提取较大范围上下文 |
| Null expert | 输出零，明确表示拒绝传播 |

Router 同时读取 \(E_i\) 和 \(D_i\)：

\[
\tilde E_i=\sum_{k=0}^{3}p_{i,k}(E_i,D_i)T_k(E_i)
\]

Null expert 必须保留。没有 Null expert，router 只能决定“怎样加工”，不能真正决定“不传”。

第一版先使用 softmax 软路由。只有软路由有效且专家利用率没有塌缩后，再测试 Top-2。MoE 阶段还需要：

- 等参数量 dense experts 对照；
- 固定平均路由对照；
- 随机或打乱 router 对照；
- 专家利用率、路由熵和 Null expert 使用率；
- 参数量、峰值显存和推理时间。

否则实验只能证明增加多个卷积分支有效，不能证明 MoE 在选择信息。

## 7. 评价指标

### 分割结果

- Liver Dice；
- Tumor Dice；
- Tumor HD95；
- Tumor Recall、Precision；
- lesion-wise recall；
- complete-miss rate；

- gate 小于 0.5、接近 1、大于 1 的体素比例；
- tumor、liver、background 和肿瘤边界带内的 gate 分布；
- 正确检出、完整漏检和明显误报病例的 gate 可视化；
- 浅层与深层 gate 的差异。

### 计算代价

- 参数量；
- FLOPs；
- 训练峰值显存；
- 单病例推理时间；
- 相对原始 MedNeXt 的增量。

## 8. 支持与否定标准

### 支持 H1

至少应满足：

1. E3 优于 E0；
2. E3 优于参数匹配的 E1；
3. 至少三个随机种子的变化方向基本一致；
4. LiTS 内部测试和至少一个外部数据域改善；
5. 肿瘤 Recall、lesion-wise recall 或 complete-miss rate改善；
6. 门控图显示背景信息更多被抑制，肿瘤和边界信息得到保留；
7. 额外计算代价处于可接受范围。

### 否定或削弱 H1

出现以下情况时不能宣称选择性传播有效：

- 只提高 LiTS，IRCADb 和 HCC 同时下降；
- E1 与 E3 效果基本相同；
- gate 长期接近全 1，实际上没有过滤；
- gate 在小肿瘤区域系统性降低；
- 只有一个随机种子提升；
- 只有 Liver Dice 提高，而肿瘤 Dice、Recall 和漏检没有改善；
- 参数、显存和时间开销明显高于收益。

## 9. 实施边界

建议新建独立实现：

- `MedNeXtSelectiveSkip`；
- `build_mednext_large_selective_skip`；
- `nnUNetTrainer_MedNeXt_SelectiveSkip`。

不得直接改写现有 `MedNeXt`、`MedNeXtMLABot` 或原 trainer，避免影响已有实验和 checkpoint。梯度检查点分支与普通 forward 分支必须同步实现和测试。

四个桥联位置统一使用类似接口：

```python
filtered_skip = self.skip_gates[stage](encoder_skip, decoder_up)
dec_x = decoder_up + filtered_skip
```

### 历史 E0 的使用边界

历史 `nnUNetTrainer_MedNeXt` 结果可作为背景，但不能作为 E1 的公平因果对照：

| 项目 | 历史 E0 | 已完成 E1 | 影响 |
|---|---|---|---|
| 训练拓扑 | 单 GPU，batch 2 | 双 GPU DDP，每卡 batch 1（全局 batch 2） | 全局 batch 相同，但 DDP 梯度同步和每卡增强流不同 |
| 训练实现 | 2026-06，启用 `torch.compile` | 2026-09，E1 强制 eager | 编译路径不同 |
| 内部 NIfTI | 未保留 | 26/26 | 无法做病例级配对统计 |
| HCC 外部正式结果 | 当前结果根未找到 | 21/21 | 无法做同一 E0/E1 外部比较 |

两者的 Dataset003、fold 0、3D patch `128³`、初始 LR `0.01` 与 1000 epoch 相同。历史 E0 可作为工程与结果参考，但论文中不据此作严格的单变量机制归因；重点看后续 E2、E3 是否在同一当前实验链中给出一致信号。

### 当前下一步：直接推进 E2

E2 只加入 decoder-conditioned spatial gate，保持 E1 的 Dataset003、fold 0、训练预算、损失、增强、深监督、推理与三域完整评估链路。它要回答的实际问题是：相比只变换 skip 的 E1，让 decoder 决定“哪些空间位置的 encoder 信息应通过”是否能改善肿瘤检出与外部 HCC 表现。

E2 已新增以下独立实现，未改写 E0/E1：

- `DecoderConditionedSpatialGate`：拼接同尺度 encoder skip 与 decoder upsample，生成单通道三维空间门；
- `MedNeXtSpatialGateE2` 与 `build_mednext_large_spatial_gate_e2`；
- `nnUNetTrainer_MedNeXt_SpatialGate_E2`：沿用 E1 的 eager DDP 路径。

空间门的末层为零初始化，因此训练开始时：

$$
\tilde E_i=(1+\tanh(0))E_i=E_i,
\qquad F_i^{out}=D_i+E_i.
$$

已完成 CPU 小模型的 shape、5 层 deep-supervision 前向和反向传播检查；尚未运行 GPU smoke 或正式训练。

E2 完成后，优先比较 E1 与 E2 的 HCC Tumor Dice、Recall、完整漏检、IRCADb 肿瘤结果及内部性能。若 E2 没有明确优势，停止 DCSS 线；若有可重复的正向信号，再实现 E3 的空间+通道门。

## 12. 当前决策

当前优先顺序确定为：

1. 直接实现并训练 E2（decoder-conditioned spatial gate）；
2. E2 完成后，以 E1 为当前最直接参考，决定是否训练 E3（空间+通道 DCSS）；
3. E3 若在肿瘤检出和至少一个外部域给出稳定正向信号，再进行空间/通道/尺度消融与 MoE bridge；
4. few-shot adaptation 与 Memory 晚于上述纯 source-only bridge 实验，不能与第一轮同时加入。
