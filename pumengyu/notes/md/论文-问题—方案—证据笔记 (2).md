# 深度学习与医学图像分割论文：问题—方案—证据笔记



## 1. 统一阅读框架

每篇论文先回答下面六个问题，不要一上来就抄网络结构。

1. **研究对象**：分割什么？2D 还是 3D？单器官、肿瘤，还是通用医学图像？
2. **作者声称的问题**：作者在摘要和引言中明确提出了什么困难？
3. **真正的核心问题**：这些困难是三个独立问题，还是一个问题被拆成三种表述？
4. **解决方案**：每个模块、损失或训练策略具体改变了什么？
5. **对应关系**：为什么该方案理论上能解决该问题？中间机制是什么？
6. **证据闭环**：消融、外部验证、统计检验和失败案例是否真的证明了对应关系？

### 先找“一个中心问题”，再拆子缺口

顶尖论文常见的写法不是“三个问题配三个模块”，而是：

> **一个中心研究问题 → 若干可解释的子缺口 → 多个相互配合的设计 → 多层证据。**

- 模块数、贡献点数不等于研究问题数。一个问题完全可以需要三个模块共同解决。
- 只有当两个困难能分别测量、分别消融，并且任一困难单独成立时，才适合称为两个独立问题。
- “小目标、边界模糊、上下文不足”如果最后都指向同一种特征表达不足，应先视为一个中心问题的不同表现。
- 阅读时先用一句话写出中心矛盾，再判断作者是否真的证明了每个子缺口和设计之间的因果关系。

### 证据标签

- **[原文]**：论文明确写出，能够定位到摘要、方法或实验。
- **[推断]**：根据结构和结果作出的合理解释，但不是作者直接证明。
- **[质疑]**：当前证据不足或叙事存在跳跃。
- **[待核对]**：需要回到 PDF、代码或补充材料确认。

## 2. 总览矩阵

| 论文/方法 | 核心问题 | 主要方案 | 是否属于“三个问题—三个模块” | 最值得学习的地方 |
| --- | --- | --- | --- | --- |
| GAN | 如何直接学习复杂数据分布并生成新样本 | Generator 与 Discriminator 的对抗博弈 | 否；两个网络共同定义一个训练目标 | 用学习到的判别信号代替手工概率模型 |
| ResNet | 网络加深后出现优化退化，训练误差反而升高 | 残差映射 `F(x)+x` 与 identity shortcut | 否；一个关键结构解决一个明确问题 | 问题、机制和消融证据非常干净 |
| Attention Is All You Need | RNN 的串行计算和长距离依赖路径 | Self-attention、多头注意力、位置编码、FFN | 是一个整体架构，不宜拆成几个独立问题 | 从计算依赖关系出发重新设计架构 |
| BERT | 单向语言模型不能同时利用左右上下文；下游模型高度定制 | Transformer encoder + MLM + NSP + fine-tuning | 两个预训练任务服务于通用双向表示 | 预训练目标与下游迁移的分工 |
| ViT | 视觉模型是否必须依赖卷积归纳偏置 | 图像 patch token 化 + 标准 Transformer encoder | 否；核心问题是纯 Transformer 能否用于视觉 | 大数据预训练改变架构优劣 |
| MAE | 无标签图像很多，监督标签昂贵；图像信息高度冗余 | 高比例随机遮挡 + 非对称 encoder/decoder + 像素重建 | 两个设计共同支撑一个自监督任务 | 训练策略与下游网络结构必须区分 |
| ConvNeXt | Transformer 的优势究竟来自注意力还是现代化设计 | 按 Swin 设计空间逐步现代化 ResNet | 否；是一条受控实验链 | 用逐步改造而不是一次堆模块回答问题 |
| ConvNeXt V2 | ConvNeXt 与普通 MAE 直接结合效果不佳、通道响应冗余 | FCMAE + GRN + 架构/预训练协同设计 | 接近“两问题—两方案” | architecture 与 pretraining co-design |
| Mamba | Attention 对长序列开销大；传统 SSM 内容选择能力不足 | 输入相关的 selective SSM + 硬件感知并行算法 | 两个技术点共同完成一个线性序列模型 | 算法复杂度与硬件实现同时设计 |
| nnU-Net | 医学分割性能高度依赖整条 pipeline 的任务适配 | 数据集指纹、规则化自动配置、经验选择/集成 | 否；是一个“自动适配 pipeline”的系统问题 | 强 baseline 与实验规范，而非堆新模块 |
| TransUNet | CNN 难显式建模长距离依赖，Transformer 又缺少精细定位 | CNN 特征 + Transformer encoder + U-Net decoder/skip | 否；是互补式混合架构 | 明确区分全局语义与局部高分辨率细节 |
| UNETR | 3D CNN 难以直接学习体素间长程依赖 | 3D patch token + Transformer encoder + 多尺度跳连解码器 | 否；一个 Transformer encoder 配合 U 型恢复路径 | Transformer encoder 不等于 U-Net encoder |
| Swin UNETR | 3D 全局注意力昂贵且医学数据有限 | 分层 shifted-window Transformer + 多尺度 CNN decoder | 否；分层与窗口机制共同解决效率/尺度问题 | 把窗口注意力变成 3D 多尺度编码器 |
| SegResNet | 3D 肿瘤数据有限，纯分割监督容易过拟合 | 残差编码解码器 + 训练期 VAE 重建正则 | 近似“一问题—一辅助分支” | 推理时可丢弃的训练正则分支 |
| MedSAM | 专用模型跨模态、跨任务泛化有限；自然图像 SAM 不适应弱边界医学目标 | 大规模多样化医学数据微调 SAM，保留提示式分割框架 | 否；一个泛化问题由数据、预训练和提示框架共同处理 | 问题规模与数据规模匹配 |
| MedNeXt | 医学数据有限时，如何获得可扩展且易训练的 3D 网络 | ConvNeXt 3D 编解码器、残差上下采样、UpKern、复合缩放 | 更接近“一组相关设计解决同一核心目标” | 每个设计围绕可扩展 3D ConvNet 展开 |
| EfficientMedNeXt | MedNeXt 解码器高分辨率冗余，效率与多尺度感受野仍可优化 | 精简/统一 decoder + DMRFB 空洞多感受野块 | 两阶段优化对应两个可测问题 | 不只看 Dice，还看参数、FLOPs、吞吐与公平训练 |
| FCSU-Net | U 型网络的多尺度表达、跳连语义差距和局部—全局关系不足 | CFMF + FFF + CS attention | 三个子缺口共同服务于一个特征表达问题 | 模块可以多，但中心问题仍应只有一句话 |
| MSA-Net | 模糊边界和尺度变化下难以兼顾定位与边缘精度 | MPAB/ASPP + 双分支编码解码 + FFB | 多个模块共同提升多尺度空间表达 | 跨三类 2D 任务验证通用性，但不能代替 3D 外测 |
| BATseg | 脊髓肿瘤很小、形态位置多变且缺少多类别数据 | 新数据集 + 表面距离场边界分支 + 边界损失 | 数据资源与边界学习是两个贡献，服务于同一任务目标 | 边界问题应使用直接的边界监督和指标 |
| Unified Focal Loss | 前景—背景和类别不平衡使常见 CE/Dice 类损失稳定性不一致 | 统一并可非对称调节的 focal CE/Dice 损失族 | 否；是一个训练目标问题 | 损失函数应在固定网络和划分下比较 |
| FP Reduction Network | 全身 PET/CT 易把正常高摄取器官和炎症误分为肿瘤 | 全局候选分割 + 局部假阳性精修 | 否；一个系统性假阳性问题的两阶段方案 | 用阴性病例和 FP 指标直接对准临床错误 |
| Anatomy-Aware C2F | 硬性肺掩膜会漏掉跨肺壁肿瘤，宽松预测又增加假阳性 | 粗分割 + 解剖感知连通域筛选 + 不确定性细化 | 否；一个“先验不能伤害边界病灶”的权衡问题 | 解剖先验应是软约束而非简单裁剪 |
| LoCo | 少标注条件下，低对比边界和类别相似性使伪标签不可靠 | ICE + BCE 对比学习 + CDF 动态阈值 | 多个子机制共同服务于低对比半监督学习 | 先明确标签稀缺与低对比如何相互作用 |
| ZePT | 常规开放词汇分割的候选掩膜难覆盖细微的未见肿瘤 | 器官查询 → 肿瘤查询、自提示、医学知识对齐 | 否；一个零样本泛肿瘤问题的分阶段方案 | 先证明既有范式在哪一步失效，再设计替代机制 |
| MONAI | 通用深度学习框架缺少医学影像所需的数据、空间和复现支持 | 医学影像组件化开源生态与工作流 | 否；是工程基础设施问题，不是新分割网络 | 软件论文的证据不是单一 Dice 排名 |
| DeepSeek-V3 | 超大模型如何兼顾能力、稀疏计算、推理效率和训练稳定性 | MLA + DeepSeekMoE + 无辅助损失均衡 + MTP/FP8 | 多个工程子问题围绕一个系统目标 | MLA/MoE 的原始收益必须按 3D 分割场景重新证明 |
| Anatomically-guided MAE | 动脉瘤标注少，普通自监督又未聚焦高风险解剖区域 | 动脉邻域掩码 + CT/动脉距离图联合重建 + 3D 因子化注意力 | 多个设计共同服务于一个解剖引导预训练问题 | 预训练目标可注入任务相关但不泄露真值的先验 |
| Multi-source Self-Disambiguation | 多源数据只有部分/稀疏标签且未标区域语义含混 | 自消歧 + 先验知识 + 模态/数据集/类别不平衡处理 | 多个训练障碍属于一个低成本通用模型问题 | 先解决标签语义冲突，再谈多数据集合训 |
| Improved SwinUNet | 肝脏及肿瘤低对比、边界模糊且相邻区域上下文不足 | SFTB 全局—局部融合 + LCAB 大核卷积注意力 | 两个模块共同解决上下文与关键特征表达 | 与本项目任务直接相关，但外部划分需逐项核对 |
| AmbiSSL | 少量多标注者标签与大量无标签数据下，怎样输出多种合理分割 | 多样伪标签 + 半监督潜空间 + 跨解码器监督 | 两个真实约束在一个半监督歧义框架内联合处理 | 单一 Dice 无法评价预测多样性与合理性 |
| SegMoTE | SAM 医学迁移缺少模态适配，盲目混合大数据又会负迁移 | token 级专家选择 + 冻结 mask decoder + 渐进提示 token 化 | 多个机制服务于低成本跨模态适配 | 与我们的 MoE 最相关，但专家单位和计算路径不同 |
| MemSAM-2.5D | 肝肿瘤尺度变化、层间不连续和边界歧义 | HMA + ZSF + CGPM | 明确的三个子缺口，但仍围绕一个 2.5D 连续分割目标 | 三问题写法必须有对应的连续性、边界和病灶级指标 |
| Tyche | 新任务需重训且确定性输出不能表达标注歧义 | 随机上下文分割、预测交互、上下文测试时增强 | 是两个可独立测量的问题，由一个框架联合解决 | “一篇一个中心问题”不是硬性规定，关键是能否独立验证 |
| Resource-Efficient Report Generation | 医疗报告生成使用和训练大 LLM 成本高 | 冻结视觉/语言模型，仅训练映射网络并做 prefix tuning | 否；一个资源效率问题 | 属于报告生成旁支，不能当分割或 MoE 证据 |
| SAGE | 病理形态差异大，静态 CNN–Transformer 对所有区域使用同一路径 | 双路径动态专家 + 分层路由 + SA-Hub 形状对齐 | 一个输入自适应计算问题的多组件方案 | 可借鉴真实稀疏路由及异构专家对齐方式 |
| D-Persona | 多标注者既有合理分歧，又有个人偏好 | 先多样化潜空间，再用专家提示个性化 | 两阶段对应两个不同输出目标 | 不应把多位专家强行压成唯一“真值” |
| MAPSeg | 目标域无标签且存在多种医学影像域偏移 | 3D MAE + 伪标签，统一集中式/联邦/测试时 UDA | 多场景围绕一个无监督域适配问题 | 与本项目“三域可靠性”直接相关，但需要无标签目标域这一设定 |
| Prompt-Mamba-AF | HCC 形态尺度、低对比和扫描域差异下难兼顾上下文与边界 | 解剖提示 + Mamba 状态空间 + 结构感知过滤 | 三个设计围绕稳健 HCC 分割这一中心目标 | 任务最接近本项目，优先核查数据划分和对照公平性 |
| UNETR++ | 3D Transformer 注意力计算昂贵，同时需要空间与通道判别特征 | EPA：空间注意力与通道注意力双分支 | 否；核心贡献集中在一个成对注意力模块 | 双分支有明确计算目标，不只是并联卷积 |
| G-UNETR++ | 局部卷积感受野受限；Transformer 复杂；肝脏边界/几何信息难学 | 主干 + 两个梯度编码器 + Dice/CE/HD 混合损失 | 表面上接近“三问题—三方案”，但对应关系仍需消融验证 | 手工梯度先验如何进入可学习网络 |
| SALSA | 单一 benchmark 和整体 Dice 难说明临床可靠性 | 大规模多中心数据、外部验证、patient-wise 与 tumor-wise 评价、医生比较 | 否；主要创新在数据与验证体系 | 评价设计可以比新模块更有论文价值 |
| OF-TransUNet | nnU-Net 缺少全局上下文；重型 Transformer 代价高；直接全量微调不稳定 | 单个中层 Conv-Transformer + 输出侧优先渐进解冻 | 接近“两个方法问题—两个设计”，外加临床验证问题 | 轻量改动配合严格外测与统计检验 |
| MedNeXt_MLA_MoE（我们的方案） | 跨数据集可靠性不足、困难病灶全局上下文缺失、无瘤病例假阳性 | MedNeXt-L + MLA 低秩注意力 + MoE-FFN；拟加入歧义/失败分析 | 尚未形成闭环 | 必须证明 MLA、MoE 和二者组合各自贡献 |

### 2.1 方法演化主线

这批论文不是互不相关的清单，可以沿下面四条线阅读：

1. **深层网络优化**：ResNet → ConvNeXt → ConvNeXt V2 → MedNeXt → EfficientMedNeXt。
2. **关系建模**：Attention Is All You Need → BERT / ViT → TransUNet / UNETR → Swin UNETR / UNETR++。
3. **无标签预训练**：BERT 的 MLM → MAE 的遮挡图像重建 → ConvNeXt V2 的 FCMAE；这是训练策略主线，不等于分割架构主线。
4. **长序列效率**：Transformer 的全局 attention → Swin 的局部窗口 → Mamba 的 selective state space。

> **术语修正**：`ConvNet` 是卷积神经网络的类别，不对应唯一论文；你写的 `convent2` 按 **ConvNeXt V2** 记录，`rransunet` 按 **TransUNet** 记录。`smoothsegresnet` 暂未找到公认同名论文，先保留为待确认项，不能强行等同于 SegResNet。

### 2.2 这些名称不在同一个层级

| 层级 | 代表方法 | 回答的问题 |
| --- | --- | --- |
| 基础运算/通用架构 | Transformer、ResNet、Mamba | 信息怎样传播，深层或长序列怎样计算 |
| 视觉 backbone | ViT、ConvNeXt、ConvNeXt V2 | 图像怎样编码为通用特征 |
| 预训练目标/训练策略 | BERT、MAE、GAN 的对抗训练 | 没有直接下游标签时怎样学习表示或分布 |
| 医学分割网络 | TransUNet、UNETR、Swin UNETR、SegResNet、MedNeXt | 怎样从医学图像恢复体素级掩膜 |
| 自动化 pipeline | nnU-Net | 怎样依据数据和硬件配置整套训练/推理流程 |
| 基础模型/提示式系统 | MedSAM | 怎样跨任务、跨模态按提示分割目标 |
| 评价与临床验证体系 | SALSA | 怎样证明病灶级、患者级和外部可靠性 |

因此，不能直接问“MAE 和 UNETR 哪个更好”：前者主要是预训练方法，后者是 3D 分割架构。合理的问题应是“UNETR 使用 MAE 类预训练后，是否比随机初始化或监督预训练更好”。

### 2.3 你最近看的论文大致分成三种写法

| 写法 | 典型论文 | 真实关系 | 阅读时的判断 |
| --- | --- | --- | --- |
| 一个核心问题—一个主机制 | ResNet、UNETR++、EfficientMedNeXt | 设计集中，模块和证据边界清楚 | 最适合学习“问题—机制—消融”的干净闭环 |
| 一个核心问题—多个协同模块 | MedNeXt、FCSU-Net、Prompt-Mamba-AF、SegMoTE、MemSAM-2.5D | 多个模块共同解决一个系统矛盾 | 不能因为贡献点多，就人为拆成多个论文问题 |
| 多个相对独立问题—一个联合框架 | Tyche、BERT、MAPSeg 的多场景 UDA | 子问题可分别测量，但共享一个总目标 | 必须分别验证每个子问题，不能只报总指标 |

所以，“顶尖论文是一篇论文只解决一个问题”不是硬规则；更准确的是：顶尖论文通常有一个清楚的中心命题，且每个额外模块都能解释为该命题所必需，证据也不会超出实验真正支持的范围。部分普通或水分较高的论文，确实更容易把“边界、上下文、小目标、类别不平衡”并列成多个创新点，再给每个点配一个模块，但这不能仅凭模块数量判定质量。真正的区分标准是：问题是否独立存在、指标是否对应、消融是否分开、外部数据是否仍然成立。

### 2.4 当前已选方向与可候选问题池

#### 当前锁定的核心问题

> **在跨中心成像分布、患者构成和标注条件存在差异的情况下，如何提高三维肝肿瘤分割模型的外部可靠性，并减少其在未见数据域上的病灶漏检、假阳性与性能不稳定？**

- 现实起点：模型在单一来源数据上训练和选择后，换到不同中心、病例构成或标注条件的数据域时，肿瘤分割可能明显下降或出现严重个案失败。
- 第一证据任务：先证明 source-only 模型的外部可靠性不足是否稳定存在，再定位下降集中在哪个数据域、病例和错误类型。
- 当前方法变量：MedNeXt 局部卷积主干、最低分辨率全局交互以及 attention–FFN 组合；它们是待检验假设，不是已成立机制。
- 最小反证：如果可信模型经过多次独立训练后，在未见外部域仍能保持与内部域相近的肿瘤检出、轮廓精度和严重失败率，则“外部可靠性不足”不应作为核心矛盾。

#### 可候选但暂不同时展开的问题

| 候选问题 | 它真正问什么 | 适合的证据 | 当前状态 |
| --- | --- | --- | --- |
| 小肿瘤/低对比 | 模型为何在小体积、低对比病灶上漏检？ | 按病灶大小、对比度分层的 recall、Dice、HD95 | 失败现象，不能直接当机制问题 |
| 边界与层间连续性 | 模型为何边界偏移或逐层预测断裂？ | HD95、ASSD、表面 Dice、断裂率、病灶级指标 | 可作为子问题 |
| 无瘤病例假阳性 | 提高召回是否以错误激活为代价？ | case-level FP、无瘤病例特异性、误检位置 | 重要安全终点 |
| 跨域外部可靠性 | 内部高分能否在未见中心保持，何时出现漏检、误报或严重失败？ | source-only 三域评价、病例级统计、多 seed、失败分层 | 当前核心问题 |
| 少量适配 | 新中心能否少量标注适配而不完整重训？ | 零样本、5/10/20 例适配、源域保持率 | 后续部署侧问题 |
| 多源标注冲突 | 未标注区域究竟是背景还是未标类别？ | 标签兼容性表、监督掩码、部分标注实验 | 未来联合训练方向 |
| 选择性知识共享 | 新数据带来的知识何时可共享、何时会负迁移？ | 单独/混合/路由训练、专家利用率、负迁移率 | 尚未进行联合训练，暂不作为当前主线 |
| 标注歧义 | 不同专家边界差异是否应被建模而非压成唯一真值？ | 多标注者一致性、校准、多样性覆盖 | 需要多标注者数据，目前非首选 |

> 文献中的“小肿瘤、低对比、边界”等通常是任务现象；跨域、部分标注和多源学习更接近问题设定或机制层。后续挑选时要先统一抽象层级，再比较论文质量。

网上可对照的正式问题定义包括：单源域泛化的“Train Once, Deploy Anywhere”目标、无标签目标域的测试时适配、多源部分/稀疏标注的语义歧义，以及肝肿瘤外部验证中的小病灶和低对比退化。它们说明这些问题并非凭空提出，但不代表已有方法已经解决。

### 2.5 我的论文问题专栏：三维肝肿瘤分割的外部可靠性

#### 论文问题

> **在跨中心成像分布、患者构成和标注条件存在差异的情况下，如何提高三维肝肿瘤分割模型的外部可靠性，并减少其在未见数据域上的病灶漏检、假阳性与性能不稳定？**

英文暂定为：

> **How can the external reliability of 3D liver tumor segmentation be improved across unseen domains with heterogeneous imaging distributions, patient populations, and annotation conditions, while reducing lesion misses, false positives, and performance instability?**

#### 现实意义

医学分割模型通常在单一公开数据集或单一中心上训练和选择，但实际部署会面对不同医院、扫描设备、重建协议、增强时相、患者构成和标注口径。内部测试表现良好并不保证换到新中心后仍能可靠发现肿瘤。病灶漏检、无肿瘤病例误报以及少数病例上的完全失败，比单一平均 Dice 更直接对应临床风险。

#### 从现实问题到研究问题

```text
跨中心数据异质性
→ 内部测试不能代表未见数据域
→ 外部域出现肿瘤指标下降、排名反转或严重病例失败
→ 定位失效发生的数据域、病例属性和错误类型
→ 提出具有明确机制的表征改动
→ 检验外部可靠性是否改善且源域性能不受明显损害
```

#### 术语边界

- **外部可靠性不足**：source-only 模型在未参与训练、调参或 checkpoint 选择的外部数据域上，出现临床相关的性能下降、严重失败或域间不稳定。
- **跨域泛化不足**：模型从训练域迁移到未见域时不能稳定保持分割能力，是当前已有实验能够检验的设定。
- **联合训练负迁移**：加入另一个训练数据集后，目标域性能反而下降。当前没有完成 Dataset003 与 HCC 的直接联合训练，因此不能用现有外部验证证明这一点。
- **标注条件差异**：当前是外部失效的候选解释之一；未进行受控双规范标注或其他因果实验前，不能称为已证实原因。

#### 当前已经具备的存在性证据

1. **可信 source-only 评价链**：重训 Baseline 与修复后 MLA+MoE 均使用 Dataset003_Liver/fold 0 的 `checkpoint_best.pth`，并完成 LiTS 26 例、3D-IRCADb-01 20 例、HCC-TACE-Seg 21 例的预测、`summary.json`、文本报告和可视化验收。
2. **HCC 外部性能明显较低**：重训 Baseline 的 LiTS/IRCADb/HCC Overall 为 `0.8414/0.8429/0.6013`；修复后 MLA+MoE 为 `0.8503/0.8174/0.6458`。这说明问题不是“所有外部域统一下降”，而是外部表现具有明显域依赖性。
3. **肿瘤端下降强于肝脏端**：修复后 MLA+MoE 的 LiTS/IRCADb/HCC Tumor Dice 为 `0.7509/0.6729/0.4511`，HCC 的主要风险表现为肿瘤检出和轮廓恢复不足。
4. **跨方法共识失败**：2026-09-03 的 source-only 比较池中，HCC 21 例有 11 例被至少一半 Trainer 严重分割失败，6 例被当时全部 30 个 Trainer 严重分割失败；严重失败定义为阳性病例 `Tumor Dice < 0.3`。
5. **模型选择具有域依赖性**：MHA、MLA 和不同 FFN 组合在 IRCADb 与 HCC 的相对顺序发生变化，内部排名不能直接代表外部排名。

第 4 项比较池包含修复前 MoE 行，正式论文使用前必须按修复后谱系重新生成；它当前属于强初步证据，不是最终冻结统计。

#### 当前能够得出的判断

> **现有证据支持“外部可靠性不足在 HCC-TACE-Seg 上明显存在，并呈现跨模型共同漏检和严重失败”；不支持“所有外部数据域都统一下降”，也尚未证明成像差异、患者构成或标注条件中的哪一个是主要原因。**

#### 仍需补齐的证据

1. 对可信 source-only 模型池重新生成三域总表、排名相关性和共识失败病例，排除修复前 checkpoint。
2. 对核心 Baseline/MedNeXt/候选方法进行多随机种子或多 fold 训练，区分域效应与训练波动。
3. 分层分析病灶体积、数量、对比度、边界、spacing、CT phase 和可获得的病例信息，寻找外部失败发生的条件。
4. 分别报告 Tumor Dice、Recall、Precision、FPV、FNV、严重失败率和 worst-domain performance，不能只报告 Overall。
5. HCC test 21 例全部为肿瘤阳性，No-tumor FP rate 必须为 `N/A`；若将外部假阳性作为主要结论，需要增加更大的独立阴性外部队列。3D-IRCADb-01 仅有 5 个阴性病例，其 FP 结果只能作为描述性证据。
6. 不同数据集之间的分数差首先证明外部性能不稳定，不能在未控制混杂因素时将下降单独归因于 scanner、患者构成或 annotation policy。

#### 反证与转向条件

- 如果多个可信模型经过多次独立训练后，外部域的肿瘤指标、严重失败率和病例分布均与内部测试相近，则外部可靠性不足不应继续作为核心问题。
- 如果下降只由少数异常病例或评价流程错误造成，应修正数据/评价，而不是设计新网络。
- 如果某个模块只在一个外部域改善、在另一个域退化，应写成域依赖性边界，不能概括为普遍提高鲁棒性。
- 如果失败条件无法与 MLA、MoE 或其他结构机制建立对应关系，应保留外部可靠性研究，但重新选择解决方案。

#### 下一步顺序

1. 冻结可信的 source-only 模型和 checkpoint 清单；
2. 更新三域指标、跨域排名和共同失败病例；
3. 证明外部可靠性不足的存在性和训练稳定性；
4. 再寻找下降发生的病例与成像条件；
5. 最后决定 MLA、MoE 或其他策略是否真正对症。

## 3. 逐篇记录

### 3.1 nnU-Net

**论文定位**  
不是“发明一个更复杂的 U-Net”，而是把医学分割 pipeline 的设计过程自动化。

**作者明确提出的问题 [原文]**

1. 医学分割任务之间的数据尺寸、spacing、类别和显存条件差异很大。
2. 方法性能不只由网络结构决定，还强烈依赖预处理、patch、batch、训练和后处理。
3. 手工为每个数据集配置方案成本高，且难以公平复现。

**解决方案 [原文]**

- 从数据中提取 **dataset fingerprint**。
- 用固定参数、相互依赖的启发式规则和经验决策生成 **pipeline fingerprint**。
- 自动配置预处理、2D/3D 网络、patch/batch、训练、推理与后处理，并选择合适配置或集成。

**问题—方案机制**

`任务差异大 → 读取数据集属性 → 依据显存和空间信息生成配置 → 用统一训练规范验证 → 自动选择结果`

**我们的判断**

- **[推断]** nnU-Net 的核心贡献不是三个模块，而是一个完整系统闭环。
- **[质疑他文]** 新论文若只在 nnU-Net 上加模块，却没有与强 nnU-Net 配置公平比较，很可能把 pipeline 差异误写成结构创新。
- 对我们的项目：nnU-Net v2 肿瘤验证 Dice 已明显优于早期 two-stage，因此它应当是必须击败或至少详细比较的 baseline。

来源：[Nature Methods 论文](https://www.nature.com/articles/s41592-020-01008-z)；[官方代码](https://github.com/MIC-DKFZ/nnUNet)

### 3.2 MedSAM

**作者明确提出的问题 [原文]**

1. 现有医学分割模型往往只针对某一种模态或疾病，跨任务泛化不足。
2. 直接使用自然图像上的 SAM，主要在边界清楚的目标上表现尚可，对弱边界、低对比医学目标存在明显局限。

**解决方案 [原文]**

- 收集 1,570,263 个医学图像—掩膜对，覆盖 10 种模态和 30 多种癌症。
- 在大规模、多样化医学数据上微调 SAM。
- 延续图像编码器、提示编码器和掩膜解码器的提示式分割范式。

**问题—方案机制**

`自然图像域偏移 + 医学任务差异 → 多模态大规模医学数据适配 → 学到更通用的医学图像表征 → 通过提示指定目标`

**我们的判断**

- **[推断]** MedSAM 不是典型的“三个问题—三个新模块”；其核心优势首先来自数据规模与任务覆盖，其次才是 SAM 框架。
- **[质疑]** “通用医学分割”不等于“无需提示的全自动肝肿瘤分割”。与我们的 3D 全自动任务比较时，必须区分提示条件、2D/3D 输入和是否提供目标框。
- **[待核对]** 后续若把 MedSAM 纳入表格，需要记录每个实验的提示形式，不能只抄 Dice。

来源：[Nature Communications 论文](https://www.nature.com/articles/s41467-024-44824-z)；[官方代码](https://github.com/bowang-lab/MedSAM)

### 3.3 MedNeXt

**作者明确提出的问题 [原文]**

1. Transformer 在自然图像上成功，但医学数据标注规模有限，纯 Transformer 未必容易训练。
2. 3D 医学分割需要兼顾局部归纳偏置、较大感受野和网络可扩展性。
3. 简单增大卷积核或模型规模，在有限数据上可能出现性能饱和。
4. 普通上下采样可能损失跨尺度语义信息。

**解决方案 [原文]**

- 完全基于 ConvNeXt block 的 3D 编解码器。
- 残差 ConvNeXt 上采样/下采样块。
- **UpKern**：先训练小卷积核模型，再将核权重上采样以初始化大核模型。
- 对深度、宽度和卷积核大小进行复合缩放。

**问题—方案机制**

- 卷积归纳偏置 → 在小规模医学数据上更容易优化。
- 大核 depthwise convolution → 扩大有效感受野。
- 残差上下采样 → 缓解尺度转换时的语义损失。
- UpKern → 为大核训练提供较好的初始化，缓解直接扩大卷积核后的优化困难。

**我们的判断**

- **[推断]** 四个贡献并非四个互不相关的问题；它们都围绕“如何构造并稳定训练可扩展的 3D ConvNet”。
- 这比随意加入 ASPP、注意力、Strip Conv 更完整，因为设计共享一个中心假设。
- 对我们的项目：如果声称 MedNeXt 缺全局上下文，必须用感受野、困难病例或消融证明，而不能只因为“它是卷积”就默认成立。

来源：[MICCAI/arXiv 论文](https://arxiv.org/abs/2303.09975)；[官方代码](https://github.com/MIC-DKFZ/MedNeXt)；[本地 PDF](<../paper/外界参考论文/Mednext.pdf>)

### 3.4 UNETR++

**作者明确提出的问题 [原文]**

1. 3D 体数据 token 数量大，常规自注意力的二次复杂度造成计算瓶颈。
2. 高质量分割既需要空间依赖，也需要通道维度的判别信息。
3. 需要同时改善精度、参数量、计算量和推理效率。

**解决方案 [原文]**

- 提出 **Efficient Paired Attention（EPA）block**。
- 使用相互关联的空间注意力分支和通道注意力分支。
- 空间注意力被改写为相对输入规模呈线性复杂度的形式，并在多尺度编码/解码过程中使用。

**问题—方案机制**

`3D 全局关系昂贵 → 压缩/重排注意力计算 → 线性空间注意力`  
`空间定位与语义通道互补 → 成对双分支 → 联合形成判别特征`

**我们的判断**

- EPA 虽然有两个分支，但它们服务于同一个核心模块，不应机械写成两个创新点。
- **[质疑]** “空间分支负责空间、通道分支负责语义”只是设计意图；若没有分支级消融或可解释分析，不能当成已被严格证明的机制。
- 对我们的双分支想法：关键不是“并联了什么层”，而是每个分支接收什么信息、建立什么依赖，以及删除某一分支会在哪类病例上失败。

来源：[IEEE TMI 论文入口](https://ieeexplore.ieee.org/document/10526382)；[官方代码](https://github.com/Amshaker/unetr_plus_plus)

---

### 3.5 G-UNETR++ 与肝肿瘤扩展工作

**作者明确提出的问题 [原文/已核对摘要]**

1. CNN 的局部感受野限制长距离依赖建模。
2. CNN–Transformer 混合模型能建模全局信息，但模型复杂度较高。
3. 肝脏 CT 中器官/组织边界与几何特征难以学习。
4. 类别不平衡及困难边界会影响优化。

**解决方案**

- 以 UNETR++ 类主干学习原始 CT 特征。
- 两个 gradient-based encoders 接收 CT 的二阶偏导/Hessian 相关输入，强调 3D 几何和边界信息。
- 使用 Dice + Cross-Entropy + Hausdorff-distance 相关混合损失。
- 后续肝肿瘤工作采用两阶段思路：先获得肝区，再在肝 ROI 内分割肿瘤。**[需在肿瘤论文全文继续核对具体训练和信息流]**

**问题—方案机制**

- 二阶空间导数 → 对灰度曲率和结构变化敏感 → 为主干提供显式几何先验。
- ROI 约束 → 缩小搜索空间并减少肝外假阳性。
- Dice/CE/HD → 分别侧重重叠、体素分类和边界距离。

**我们的判断**

- 这是较典型的“多问题—多部件”叙事，但真正需要验证的是：梯度编码器是否确实改善边界病例，HD loss 是否确实改善距离指标，两阶段是否降低肝外假阳性。
- **[质疑]** “加入二阶梯度后 Dice 提高”不能单独证明网络学到了几何；还需要去掉各梯度分支、替换为普通卷积分支、比较边界指标和失败案例。
- 对我们的启发：问题可以借鉴，但机制必须由自己的 failure evidence 导出，不能只把 Hessian 换成另一个现成模块。

来源：[G-UNETR++ 原论文](https://doi.org/10.3390/app15020837)；[肝肿瘤扩展论文](https://doi.org/10.3390/diagnostics16030429)；[本地 PDF](<../paper/外界参考论文/diagnostics-16-00429.pdf>)

### 3.6 SALSA

**核心问题 [原文/此前已核对]**

1. 仅在单一 benchmark 上取得较高 Dice，不能证明跨中心、跨病种可靠性。
2. whole-mask Dice 会掩盖单个病灶的漏检、粘连与碎裂。
3. 分割指标高不自动等于临床可用，需要与医生和真实病例分布比较。

**解决方案 [原文/此前已核对]**

- 总计 1,598 个 CT：内部 885、外部 713。
- 外部数据覆盖 LiTS、HCC-TACE-Seg、TCIA-CRLM、MSD Task08 等异质来源。
- 同时报告 patient-wise 和 tumor-wise 指标，而不是只报整例 Dice。
- 对病灶检测、体积量化、不同病灶大小与医生表现进行分析。

**问题—方案机制**

`域偏移 → 多外部队列检验`  
`整体 Dice 掩盖漏检 → lesion-wise 检测与分层`  
`临床意义不明 → 医生比较与体积量化`

**我们的判断**

- SALSA 最值得学习的不是“又加了哪三个模块”，而是把可靠性问题拆成可以检验的实验终点。
- 它说明论文创新可以来自 **问题定义 + 数据设计 + 评价体系**，不一定来自复杂网络。
- **[质疑]** lesion-level 规则本身也可能带来阈值和匹配黑箱，因此必须记录匹配规则、最小病灶阈值和未检出定义。

来源：[Cell Reports Medicine 论文](https://doi.org/10.1016/j.xcrm.2025.102032)；[本地 PDF](<../paper/外界参考论文/SALSA.pdf>)

### 3.7 OF-TransUNet

**作者明确提出的问题 [原文]**

1. 2D nnU-Net 的局部卷积对长距离上下文建模有限。
2. 常见 Transformer 混合网络可能增加大量参数和计算。
3. 直接 full fine-tuning 在内部消融中表现出不稳定、难复现的优化行为。

**解决方案 [原文]**

- 在基本不改变 2D nnU-Net 的条件下，仅于 encoder stage 3（约 ×8 下采样）插入一个轻量 Conv-Transformer。
- 使用 **output-focused progressive unfreezing**：先解冻靠近输出端的部分，再逐步释放更深组件。
- 用公共 HCC-TACE 数据作开发，并在独立外部队列上进行主要检验。

**证据 [此前已核对]**

- 外部 per-patient tumor Dice：nnU-Net `0.2400`，OF-TransUNet `0.2788`，`p=0.0553`。
- 中等病灶（10–50 mm）：`0.190 → 0.286`，`p=0.021`。
- 结论应写成“总体 Dice 数值提高但主要终点未达到常用显著性阈值；预设的中等病灶分析显示统计支持”，不能笼统写成全面显著优于 nnU-Net。

**我们的判断**

- 方法创新本身不算很强，但实验设计、外部验证和统计表达提升了论文可信度。
- 渐进解冻解决的是优化稳定性，不应被写成直接解决小肿瘤或弱边界。
- Conv-Transformer 与中等病灶改善之间仍主要是关联；需要更直接的机制消融才能证明因果。

来源：[BMC Medical Imaging / PMC 全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC13374201/)；[本地 PDF](<../paper/外界参考论文/OF-TransUNet.pdf>)

> `Efficient-transformer.pdf` 与 `s12880-026-02406-z.pdf` 经 SHA-256 核对为同一篇 OF-TransUNet 论文的重复文件，不另建重复条目。

### 3.8 MedNeXt_MLA_MoE：当前方法与证据边界

**当前研究路线状态：外部可靠性问题已锁定，方法优势等待证据确认**

当前没有完成 Dataset003 与 HCC 的直接联合训练，因此不能把 source-only 外部验证下降解释为联合训练负迁移。MLA 和 MoE 也不预先作为论文结论。当前先验证：单域训练模型的外部可靠性是否不足、退化集中在哪些病例和错误类型，以及现有结构改动是否在多个未见数据域中稳定改善这些问题。

**新的中心问题**

> 在跨中心成像分布、患者构成和标注条件存在差异的情况下，如何提高三维肝肿瘤分割模型的外部可靠性，并减少其在未见数据域上的病灶漏检、假阳性与性能不稳定？

**第一阶段不做复杂模型，只做证据链**

1. 固定 Dataset003_Liver source-only 的模型、fold 和 `checkpoint_best.pth`，核对 LiTS、3D-IRCADb-01 与 HCC-TACE-Seg 的完整评价链。
2. 按数据域报告 Liver/Tumor/Overall、Recall、Precision、严重失败病例和适用时的无瘤病例 FP，不把不同数据域合并成一个平均分。
3. 比较多个可信 backbone/结构在三域的性能、排名和共同失败病例，确认问题是单模型偶发还是系统性外部困难。
4. 用多随机种子或多 fold 检验训练稳定性，再按病灶大小、对比度、边界、spacing 和病例属性寻找失效条件。
5. 只有失效条件与结构机制建立对应后，才把 MLA、MoE 或其他改动写成针对性方案。

**原有失败维度（暂作为证据终点，不再并列为三个核心问题）**

1. **外部可靠性**：内部验证提升能否迁移到 3D-IRCADb、HCC-TACE 等外部数据？
2. **困难病灶与视觉歧义**：低对比、无明显阴影、边界模糊病灶为何漏检？某些低密度非肿瘤区域为何被误检？
3. **无肿瘤病例安全性**：Dice 可能看不出无瘤病例假阳性，需要单独报告 case-level false positive。

**当前方法假设**

- `MedNeXt-L + MLABottleneck3D`：在最低分辨率瓶颈引入 MLA 风格低秩 K/V self-attention，补充全局肝—肿瘤上下文。
- `MoE-FFN`：让不同专家学习不同类型或尺度的困难模式。**[目前是方法假设，不是已证实机制]**
- 保持原有卷积 encoder–decoder、deep supervision 和基本训练设置，以便公平比较。

**现有证据与反证**

- 重训 Baseline 已完成三域完整验收，LiTS/IRCADb/HCC Overall 为 `0.8414/0.8429/0.6013`：IRCADb 没有统一下降，但 HCC 明显较低。
- 修复后 MLA+MoE 已完成三域完整验收，LiTS/IRCADb/HCC Overall 为 `0.8503/0.8174/0.6458`，Tumor Dice 为 `0.7509/0.6729/0.4511`。
- 修复后 MLA+MoE 相对 MedNeXt 的 Tumor Dice 平均差为 LiTS `-0.0091`、IRCADb `-0.0170`、HCC `+0.0337`，当前置信区间均跨 0 且 Holm 校正后均不显著，不能声称它已稳定提高外部可靠性。
- 现有结果说明“内部高分不能保证所有外部域可靠”，同时也反证了“所有外部域都会统一下降”以及“某个模块普遍改善三域”的过强说法。

**目前缺失的闭环**

1. 核心模型的多随机种子或多 fold 结果，证明域间差异不是单次训练波动。
2. 不同病灶大小、对比度、边界模糊度、spacing 和可获得病例属性的分层结果。
3. patient-wise、tumor-wise recall/precision、FPV/FNV、严重失败率与适用时的无瘤 false-positive rate。
4. 内部排名与两个外部域排名的一致性，以及修复后可信模型池的共同失败病例。
5. 模块声称的“全局上下文”或“专家分工”与具体失败类型之间的直接证据。
6. 标注差异、视觉歧义与模型不确定性的定量关联；未控制混杂前不作单一因果归因。

**当前最稳妥的论文主线**

> 不是“我们提出三个模块，所以性能提高”，而是：  
> **内部性能不能保证未见域可靠 → 用多域评价和共同失败病例确认问题 → 找出失效条件 → 提出具有明确机制的改动 → 用受控消融、多次训练和外部验证检验机制是否成立。**

### 3.9 Attention Is All You Need（Transformer）

**作者明确提出的问题 [原文]**

1. RNN/循环模型必须按时间步串行计算，难以充分并行。
2. 相距很远的 token 之间需要经过较长的信息传播路径，长程依赖难学。

**解决方案 [原文]**

- 完全去掉 recurrence 和 convolution，建立 Transformer encoder–decoder。
- scaled dot-product attention：`softmax(QK^T / sqrt(d_k))V`。
- multi-head attention、位置编码、逐位置 FFN，以及残差连接和 LayerNorm。

**机制**

- 每个 token 可直接与其他 token 计算关系，依赖路径缩短。
- 不再按时间步递归，因此训练阶段能并行处理序列。
- 多个 head 在不同投影子空间学习不同关系；位置编码补回注意力本身缺少的顺序信息。

**我们的判断**

- 论文真正的突破不是首次提出 attention，而是证明 **不用 RNN/CNN、只靠 attention 也能完成序列转换**。
- 多头、FFN、位置编码不是三个随意模块，而是纯 attention 架构成立所需的互补组件。
- 标准全局 self-attention 对序列长度为二次复杂度，这正是 Swin、线性 attention 和 Mamba 后续要处理的问题。

来源：[NeurIPS 论文](https://papers.nips.cc/paper/7181-attention-is-all-you-need)；[本地 PDF](<../paper/外界参考论文/Attention Is All You Need.pdf>)

### 3.10 BERT

**作者明确提出的问题 [原文]**

1. 当时的语言预训练表示通常是单向的，或只能较浅地拼接左右上下文。
2. 不同 NLP 下游任务常需要大量任务专用结构。

**解决方案 [原文]**

- 使用 Transformer **encoder** 预训练深层双向表示。
- Masked Language Modeling（MLM）：遮住部分 token，再根据左右上下文预测它们。
- Next Sentence Prediction（NSP）：在原始 BERT 中学习句子关系。
- 预训练完成后，为不同任务增加很小的输出层并整体 fine-tune。

**机制**

`遮住词 → 模型不能直接复制答案 → 必须同时利用左右上下文 → 获得可迁移的双向表示`

**我们的判断**

- BERT 的核心不是一种新的 attention，而是 **Transformer encoder + 自监督预训练目标 + 下游微调范式**。
- BERT 与 ViT/UNETR 不在同一个应用层级：BERT处理文本，ViT把视觉 patch 当 token，UNETR再把这套编码思想用于 3D 分割。
- BERT 的 MLM 是 MAE 的重要思想来源之一，但“遮词分类”和“遮图像 patch 后重建像素”并不是同一个任务。

来源：[ACL Anthology 论文](https://aclanthology.org/N19-1423/)

### 3.11 ViT

**作者明确提出的问题 [原文]**

> 计算机视觉是否必须依赖 CNN，还是可以把标准 Transformer 直接用于图像？

**解决方案 [原文]**

- 把图像切成固定大小 patch，并将每个 patch 线性映射为 token。
- 加入位置编码和用于分类的 `[CLS]` token。
- 将 token 序列送入标准 Transformer encoder，最后用 MLP head 分类。

**机制**

- patch embedding 把二维图像转换成 Transformer 可以处理的序列。
- self-attention 从第一层起就能建立远距离 patch 关系。
- 大规模预训练弥补纯 Transformer 相比 CNN 更弱的局部和平移归纳偏置。

**关键澄清**

- patch projection 在实现上可以写成 stride 等于 patch size 的卷积，但这不等于存在一个多阶段 CNN encoder。
- ViT 的主体 encoder 是 Transformer；U-Net encoder 则通常逐级卷积和降采样，二者的信息组织方式不同。
- 原论文的强结论依赖大规模预训练；不能从中推出小型医学数据上 ViT 一定优于 CNN。

来源：[原论文](https://arxiv.org/abs/2010.11929)

### 3.12 MAE

**作者明确提出的问题 [原文]**

1. 图像标签昂贵，希望从无标签图像学习通用表征。
2. 图像具有较强空间冗余，像 BERT 那样只遮少量输入，任务可能过于简单。
3. 若 encoder 同时处理大量 mask token，自监督训练仍然昂贵。

**解决方案 [原文]**

- 随机遮挡很高比例的 patch，典型设置约为 75%。
- 非对称 encoder–decoder：大型 encoder **只看可见 patch**，轻量 decoder 接收编码结果和 mask token 后重建原图像。
- 预训练结束后丢弃 decoder，用 encoder 完成下游 fine-tuning。

**机制**

`高遮挡率 → 不能依靠邻近像素轻易补全 → 被迫学习整体结构`  
`encoder 只算可见 patch → 大幅降低预训练计算量`

**关键澄清**

- MAE 首先是一种 **自监督预训练方法**，不是与 U-Net、MedNeXt 平级的分割网络。
- U-Net/MedNeXt encoder + masked reconstruction + segmentation fine-tuning 是可研究方向，但必须重新设计 3D masking、decoder 和预训练数据，不能把 MAE 当作即插即用模块。

来源：[CVPR/arXiv 论文](https://arxiv.org/abs/2111.06377)

### 3.13 GAN

**作者明确提出的问题 [原文]**

复杂数据分布难以显式建模，希望从噪声直接生成与真实数据分布相似的新样本。

**解决方案 [原文]**

- **Generator**：把随机噪声映射为生成样本。
- **Discriminator**：判断输入来自真实数据还是生成器。
- 两者构成 minimax 对抗博弈，判别器的可学习反馈替代固定的手工相似度。

**机制**

`D 学会寻找真假差异 → G 根据 D 的梯度修正生成分布 → 理想平衡时生成分布逼近真实分布`

**我们的判断**

- GAN 是“一种训练框架 + 两个对手网络”，不是固定的某个生成器结构。
- 它的经典困难包括训练不稳定、mode collapse 和评价困难；这些不是简单增加第三个模块就能解决。
- 医学图像中可用于合成、域适配或半监督，但“图像看起来真实”不等于病灶分布、标签关系和临床统计都真实。

来源：[NeurIPS 论文](https://papers.nips.cc/paper/5423-generative-adversarial-nets)

### 3.14 ResNet

**作者明确提出的问题 [原文]**

网络加深后出现 **degradation problem**：更深的 plain network 不仅测试误差高，连训练误差也更高。这不能仅用过拟合解释，而是优化困难。

**解决方案 [原文]**

- 不直接让若干层学习目标映射 `H(x)`，而是学习残差 `F(x)=H(x)-x`。
- 输出写为 `H(x)=F(x)+x`，其中 `x` 通过 identity shortcut 直接传递。

**机制**

- 若理想映射接近恒等映射，只需把残差学到接近 0。
- shortcut 为信息和梯度提供直接路径，使更深网络更容易优化。

**证据与启发**

- 原论文直接比较了同深度 plain net 与 residual net，并展示更深 plain net 训练误差反而升高，而残差网络可以从深度中获益。
- 这是非常标准的闭环：**先观察反常现象 → 提出最小结构改动 → 用对应对照实验验证**。
- MedNeXt 的残差块、残差上下采样都属于这条思想链，但不能因此把 MedNeXt 简化成“3D ResNet”。

来源：[CVPR 论文](https://arxiv.org/abs/1512.03385)；[本地 PDF](<../paper/外界参考论文/resent.pdf>)

### 3.15 ConvNeXt

**作者明确提出的问题 [原文]**

ViT/Swin 的成功通常被归因于 Transformer 本身，但性能差距中究竟有多少来自现代化的宏观结构、训练策略和微观设计，并不清楚。

**解决方案 [原文]**

- 从 ResNet 出发，按受控步骤向 Swin Transformer 的设计空间靠近。
- 采用更合适的 stage ratio、patchify stem 和独立下采样层。
- 使用大核 depthwise convolution、inverted bottleneck、GELU、LayerNorm，并减少不必要的激活和归一化。
- 最终得到仍由标准卷积组成的 ConvNeXt。

**机制**

- depthwise convolution 负责空间混合，`1×1`/线性层负责通道混合。
- inverted bottleneck 先扩张通道再压回，使通道变换更充分。
- 大核扩大单层局部感受野，但论文价值不只来自“大核”。

**我们的判断**

- ConvNeXt 回答的是一个科学问题：**Transformer 的强性能是否必须依赖 attention？**
- 它最值得学习的是逐项 modernize 的消融路线，而不是把最终 block 当成神秘配方。
- 我们此前实验更支持 DW + inverted bottleneck、深残差结构、通道混合与规范化的综合作用；不能把 MedNeXt 的表现只归因于大卷积核或参数量。

来源：[CVPR 论文](https://arxiv.org/abs/2201.03545)；[本地 PDF](<../paper/外界参考论文/ConvNet_for 2020s.pdf>)

### 3.16 ConvNeXt V2

**作者明确提出的问题 [原文]**

1. ConvNeXt 最初主要面向有监督训练，直接把普通 MAE 与卷积网络组合会出现次优表现。
2. 自监督特征学习中需要促进通道之间的有效竞争，减少冗余响应。

**解决方案 [原文]**

- **FCMAE**：fully convolutional masked autoencoder，使遮挡预训练与卷积结构匹配。
- **GRN**：Global Response Normalization，根据全局空间响应进行通道间归一化/竞争，并加入可学习缩放和偏置。
- 将预训练方法和网络结构共同设计，形成 ConvNeXt V2。

**关键澄清**

- GRN 是 **Global Response Normalization**，不是 GroupNorm。
- ConvNeXt V2 的中心不是“ConvNeXt 再加一个层”，而是发现 naive combination 失败后进行 architecture–pretraining co-design。
- 对 MedNeXt_MLA：如果采用 MAE 预训练，必须检验遮挡策略是否与 3D ConvNet 匹配，不能默认 2D ViT-MAE 的设置可直接迁移。

来源：[CVPR/arXiv 论文](https://arxiv.org/abs/2301.00808)

### 3.17 Mamba

**作者明确提出的问题 [原文]**

1. Transformer attention 随序列长度呈二次增长，长序列成本高。
2. 既有高效 State Space Models（SSM）在文本等离散内容上缺乏充分的 content-based reasoning/selection 能力。

**解决方案 [原文]**

- 让部分 SSM 参数随当前输入变化，使模型能够选择性保留或忘记信息。
- 设计 hardware-aware parallel algorithm，兼顾训练并行与递归推理。
- 构成不依赖 attention、原始设计中也不使用传统 MLP block 的 Mamba 主干。

**机制**

`输入相关状态更新 → 当前内容决定哪些历史信息通过 → 长序列选择性记忆`  
其序列计算随长度线性扩展，推理时无需保存完整 attention matrix。

**对医学分割的限制**

- 原始 Mamba 是通用序列模型，不是医学分割网络。
- 3D 图像必须先规定体素/patch 的扫描顺序；不同顺序会改变邻接与方向偏置。
- “线性复杂度”能证明效率优势，但不能自动证明比 attention 更懂 3D 空间关系。医学 Mamba 论文仍需与 CNN/Transformer 在同一 pipeline 下公平比较。

来源：[原论文](https://arxiv.org/abs/2312.00752)

### 3.18 TransUNet

**作者明确提出的问题 [原文]**

1. U-Net 的卷积具有局部性，难以显式建模长距离依赖。
2. 纯 Transformer 虽擅长全局关系，却缺少精确定位所需的低层局部细节。

**解决方案 [原文]**

- 先用 CNN 提取特征图，再把特征图 token 化送入 Transformer encoder 获取全局上下文。
- decoder 逐步上采样，并与高分辨率 CNN 特征通过 skip connection 融合以恢复定位细节。

**机制闭环**

`CNN → 局部纹理与高分辨率细节`  
`Transformer → token 间全局关系`  
`U 型 decoder/skip → 将两类信息恢复为像素级掩膜`

**关键澄清**

- 原始 TransUNet 主要是 **2D CNN–Transformer hybrid**。
- 它与 UNETR 不同：TransUNet 先有 CNN 特征提取；UNETR 直接把 3D 图像 patch 交给 Transformer encoder。
- 你写的 `rransunet` 暂按 TransUNet 记录。

来源：[原论文与官方代码](https://arxiv.org/abs/2102.04306)

### 3.19 UNETR

**作者明确提出的问题 [原文]**

3D CNN 的局部卷积与逐级下采样，难以直接捕获体数据中远距离位置之间的依赖。

**解决方案 [原文]**

- 将 3D volume 划分为不重叠的 3D patches，线性映射后加入位置编码。
- 用 Transformer 作为主要 encoder，在固定 token 表示上进行全局建模。
- 从不同 Transformer depth 取 hidden states，reshape 回空间特征，并通过不同尺度的卷积/反卷积路径接入 decoder。

**关键澄清：Transformer encoder 与 U-Net encoder 不同**

- 传统 U-Net encoder：卷积后逐级降低空间分辨率、增加通道，天然形成尺度金字塔。
- UNETR encoder：主体是 token 序列上的 Transformer；所谓 skip features 主要来自不同 **Transformer 深度**，再经投影形成不同空间尺度。
- 因此 UNETR 虽然外形是 U-shaped，但 encoder 的计算机制并不是卷积 U-Net encoder。

**我们的判断**

- UNETR 的核心创新是把纯 Transformer encoder 系统性接入 3D U-shaped decoder，而不是简单“在 U-Net 中间加 attention”。
- 全局 attention 的 3D token 成本很高，这为 Swin UNETR 和 UNETR++ 的效率改进提供了动机。

来源：[WACV 论文](https://openaccess.thecvf.com/content/WACV2022/html/Hatamizadeh_UNETR_Transformers_for_3D_Medical_Image_Segmentation_WACV_2022_paper.html)

### 3.20 Swin UNETR

**作者明确提出的问题 [原文]**

1. 3D FCNN 的有限卷积核不利于建模长距离信息，尤其影响大小变化明显的肿瘤。
2. 对全部 3D token 做全局 attention 计算和显存代价高。
3. 医学数据有限，需要更适合视觉结构的层次化表示。

**解决方案 [原文]**

- 以 3D Swin Transformer 作为 hierarchical encoder。
- 在局部窗口内计算 attention，并通过 shifted windows 让相邻窗口跨层交换信息。
- 提取多个分辨率的特征，经 skip connections 接入 FCNN decoder。

**机制**

- window attention 降低相对于全局 attention 的计算量。
- shifted window 避免窗口永远彼此隔离。
- patch merging 建立类似 CNN 金字塔的多尺度特征，方便与 U-shaped decoder 对接。

**我们的判断**

- Swin UNETR 不是“UNETR 换一种 attention”这么简单；它把 encoder 从固定分辨率全局 token 建模改为层次化局部窗口建模。
- 我们自己的内部实验中，SwinUNETR/nnFormer 没有稳定优于卷积 baseline，说明“全 Transformer 化”不是小规模 3D CT 的自动优势。

来源：[原论文](https://arxiv.org/abs/2201.01266)；[MONAI 实现](https://monai.io/research/swin-unetr)；[本地 PDF](<../paper/外界参考论文/Swin UNETR Swin Transformers for Semantic Segment.pdf>)

### 3.21 SegResNet

**名称说明**

SegResNet 通常指向 Myronenko 的 3D 残差 encoder–decoder 体系及其 MONAI 实现；对应的经典论文题目实际是 **3D MRI Brain Tumor Segmentation Using Autoencoder Regularization**，而不是题目中直接写 SegResNet。

**作者明确提出的问题 [原文]**

3D 脑肿瘤标注数据有限，纯分割监督容易过拟合，需要额外约束共享表征。

**解决方案 [原文]**

- 采用 3D residual encoder–decoder 完成肿瘤亚区分割。
- 训练时加入 variational autoencoder（VAE）分支重建输入，对共享 encoder 施加正则。
- 推理时移除 VAE 分支，只保留分割网络。

**关键澄清**

- VAE 是 **训练期辅助分支/正则策略**，并不是推理时必需的分割模块。
- MONAI 中 `SegResNet` 与带 VAE 的实现可能是不同类；看到模型名时必须检查实际代码，不能默认都使用 VAE loss。
- `smoothsegresnet` 暂未检索到公认同名模型。可能是名称记错，也可能是某个项目的自定义类；在看到原 PDF 或代码前不并入 SegResNet。

来源：[原论文](https://arxiv.org/abs/1810.11654)

### 3.22 EfficientMedNeXt

**作者明确提出的问题 [原文]**

1. MedNeXt 的高分辨率 decoder 存在较多冗余，参数量、FLOPs 和吞吐仍可显著优化。
2. 需要在不持续增大卷积核和通道扩张开销的情况下获取多尺度空间上下文。

**两阶段解决方案 [原文]**

1. **优化 decoder**：减少高分辨率冗余、统一各阶段 decoder channels，并精简最高分辨率恢复路径。
2. **DMRFB**：使用 dilated depthwise convolutions 建立多个感受野，较低成本地捕获多尺度上下文。

**报告结果 [原文]**

- EfficientMedNeXt-L 在 BTCV 报告 Dice `87.0%`，比 MedNeXt-L 高 `1.04%`，同时参数减少 `96.5%`、FLOPs 减少 `77.03%`。
- EfficientMedNeXt-S 报告相近 Dice、更好的 HD95、吞吐提高 `78.1%`，参数减少 `98.5%`、FLOPs 减少 `95%`。

**我们的判断与审稿证据**

- 这篇论文确实接近“两个工程问题—两个结构方案”，而且效率指标与问题直接对应。
- 但 MICCAI 公开评审曾质疑：部分测试集较小、无交叉验证、不同 baseline 的训练条件和 nnU-Net 自适应 pipeline 是否公平、最初缺少标准差/置信区间。
- 因此可学习其轻量化思路，但不能只凭单次 Dice 与参数下降就断言外部可靠性更强；它尤其适合作为我们论文的 **accuracy–efficiency baseline**，不是外部可靠性证据的替代品。

来源：[MICCAI 2025 论文与公开评审](https://papers.miccai.org/miccai-2025/0280-Paper4895.html)；[官方代码](https://github.com/SLDGroup/EfficientMedNeXt)；[本地 PDF](<../paper/外界参考论文/4895_paper.pdf>)

### 3.23 FCSU-Net

**中心问题 [我的判断]**

U 型网络怎样同时获得可靠的多尺度特征、缩小编码器与解码器的语义差距，并保留局部结构与长程关系？论文列了三个不足，但它们都属于“特征怎样提取和融合”这一个中心问题。

**方案与证据 [原文]**

- `CFMF` 用多尺度深度卷积协同提取特征；`FFF` 用全尺度语义融合替代普通跳连；`CS attention` 联合局部卷积上下文与跨维依赖。
- 在 BUSI、CVC-ClinicDB 和 DSB2018 三个公开 2D 数据集上与多种方法比较，并对组件做消融。
- **证据边界**：跨任务 2D 实验支持通用性，但不能直接证明其对 3D 肝肿瘤、跨中心偏移或无瘤假阳性有效；三个模块同时存在也不等于三个独立研究问题。

**对本项目的启发**：可以学习其“子缺口—模块—消融”写法，但我们的中心问题必须来自现有模型失败，而不能照搬这三个子缺口。

### 3.27 False Positive Reduction Network

**中心问题 [原文]**

全身 FDG-PET/CT 中，正常高摄取器官、炎症和感染容易被分成肿瘤，如何减少系统性假阳性而不丢失候选病灶？

**方案与证据**

- 自监督预训练编码器驱动全局模块，先生成粗候选肿瘤区域；局部精修模块再去除假阳性。
- AutoPET 训练集包含 1,014 次扫描、900 名患者，其中 513 次扫描无病灶；最终隐藏测试含 200 例，且有一半来自另一家医院。
- 论文报告预赛测试 Dice `0.9324`、当时榜单 Dice 第 1，最终测试进入前 7。
- **证据边界**：这是 PET/CT 高摄取混淆这一特定错误模式；Dice 排名不能替代逐例 FP、阴性病例特异性和“精修是否误删真病灶”的分析。

**对本项目的启发**：如果我们的无瘤病例存在假阳性，可以借鉴“先找候选、再针对 FP 精修”的问题定义，但不能直接复制 PET 强度先验。

### 3.28 Anatomy-Aware Coarse-to-Fine

**中心问题 [原文归纳]**

胸部肿瘤可能跨越肺壁：严格肺掩膜会漏检，完全放开又会产生大量肺外假阳性。核心是怎样使用解剖先验而不让先验裁掉真实边界病灶。

**方案与证据**

- 全体积粗分割后，依据候选与肺的重叠、到肺表面的距离及连通域大小做解剖感知筛选，再在 ROI 内结合不确定性进行精分割。
- 在私有数据和公开数据上验证；Orlando 数据中 Swin UNETR Dice 从 `0.4690` 提升到 `0.6447`。
- 假阳性连通域减少与 HD95 改善相关（论文报告 `ρ=-0.83, p<0.0001`）。
- **证据边界**：相关性不是因果证明；解剖距离和大小阈值可能依赖器官、中心与病例分布，迁移到肝脏前必须检查肝外侵犯和邻近病灶。

### 3.37 SegMoTE

**中心问题 [原文]**：SAM 迁移到不同医学模态和解剖任务时缺少自适应，直接混合异质数据微调又会造成噪声监督与负迁移。

- 在小规模 `MedSeg-HQ` 上仅训练约 17M 参数，并报告跨模态、域内外结果。
- **边界**：它的专家是 token 级且真正选择性激活；不能把它直接等同于当前项目中所有专家都计算的 MoE-FFN。

来源：[本地 PDF](<../paper/外界参考论文/Lu_SegMoTE_Token-Level_Mixture_of_Experts_for_Medical_Image_Segmentation_CVPR_2026_paper.pdf>)

---

### 3.38 MemSAM-2.5D

**中心问题 [原文]**：肝肿瘤尺度变化大、逐层预测不连续且边界含混，怎样在可接受显存下同时建模切内、Z 轴连续性和不确定边界？

- `HMA` 做切内多尺度表示，`ZSF` 建模层间依赖，`CGPM` 用置信度门控原型记忆细化边界。
- 在 MSD08、HCC-TACE-Seg 和 WAW-TACE 上报告重叠、边界、病灶级和连续性指标。
- **边界**：这是很典型的“多个子缺口围绕一个中心目标”；比较时必须逐项核对 HCC-TACE-Seg 的官方 105、QC 纳入 101、held-out test 21 口径是否一致。

来源：[本地 PDF](<../paper/外界参考论文/MemSAM-2.5D(1).pdf>)

### 3.39 Tyche

**中心问题 [原文]**：新分割任务通常需要重新训练，而且单一确定性掩膜无法表达标注歧义，怎样用上下文直接产生未见任务的多种合理预测？

- 用上下文集进行随机 in-context segmentation；设计让预测相互作用的卷积块，并加入上下文测试时增强。
- 这里确实有两个可独立测量的困难：是否需要重训、是否能覆盖合理的标注多样性；因此是“一套联合框架处理两个问题”的例子。
- **边界**：任务灵活性和预测多样性不能由单一 Dice 证明，需分别报告新任务迁移、校准和多样性质量。

来源：[本地 PDF](<../paper/外界参考论文/Rakic_Tyche_Stochastic_In-Context_Learning_for_Medical_Image_Segmentation_CVPR_2024_paper.pdf>)

### 3.40 Resource-Efficient Medical Report Generation

**中心问题 [原文]**：医疗报告生成若训练和部署大型 LLM，资源成本高，怎样保留医学语境能力并降低训练成本？

- 使用视觉编码器、LLM 和映射网络，仅训练映射网络，并用 prefix tuning 增强生成。
- 在 MIMIC-CXR 上评价报告生成质量。
- **边界**：这是胸片报告生成，不是医学分割；可作为“冻结大模型、只训练小适配器”的旁支参考，不能作为本项目 MoE 或 Dice 证据。

来源：[本地 PDF](<../paper/外界参考论文/Resource-Efficient.pdf>)

### 3.41 SAGE

**中心问题 [原文]**：病理全切片中细胞形态差异很大，静态 CNN–Transformer 对简单区域过度计算、对复杂区域建模不足，怎样按输入动态分配计算？

- 双路径保留主干稳定性，同时用分层路由和 top-k 专家做输入自适应；`SA-Hub` 对齐 CNN 与 Transformer 专家特征形状。
- 在 EBHI、GlaS 和 DigestPath 报告结果，并通过滑窗重建应用于 WSI。
- **边界**：它展示的是动态稀疏路由的设计逻辑；迁移到 3D CT 前必须测实际激活比例、显存和路由稳定性。

来源：[本地 PDF](<../paper/外界参考论文/Thai_SAGE_Shape-Adapting_Gated_Experts_for_Adaptive_Histopathology_Image_Segmentation_CVPRF_2026_paper.pdf>)

### 3.42 D-Persona

**中心问题 [原文]**：多标注者之间既有合理的形态分歧，也有个人偏好，怎样同时生成多样预测并对应到具体专家，而不是强行合成一个真值？

- 第一阶段用概率 U-Net 和有界损失建立多样潜空间；第二阶段用多个注意力投影头查询专家提示，生成个性化结果。
- 在鼻咽癌自建数据和 LIDC-IDRI 上评估多样化与个性化。
- **边界**：它关注标注者建模，不等于普通二值分割的边界增强；使用前需确认本项目是否拥有多标注者标签。

来源：[本地 PDF](<../paper/外界参考论文/Wu_Diversified_and_Personalized_Multi-rater_Medical_Image_Segmentation_CVPR_2024_paper.pdf>)

### 3.43 MAPSeg

**中心问题 [原文]**：目标域没有标签且存在跨模态、跨序列、跨中心或跨年龄偏移，怎样统一做无监督域适配？

- 结合 3D 多尺度 MAE 预训练和伪标签，覆盖集中式、联邦式和测试时 UDA。
- 在私有婴儿脑 MRI 和公开心脏 CT-MRI 数据上报告提升，并针对不同通信/隐私设定比较。
- **边界**：这与本项目的三域可靠性最相关，但前提是目标域无标签适配；若我们使用目标测试标签调参，就不再是同一 UDA 设定。

来源：[本地 PDF](<../paper/外界参考论文/Zhang_MAPSeg_Unified_Unsupervised_Domain_Adaptation_for_Heterogeneous_Medical_Image_Segmentation_CVPR_2024_paper.pdf>)

### 3.44 Prompt-Mamba-AF

**中心问题 [原文]**：HCC 形态和尺度差异、低肿瘤—肝脏对比及扫描域变化同时存在，怎样兼顾长程体积依赖、肝脏解剖约束和边界拓扑？

- 用 anatomy-aware prompt 限定肝脏语境，用 Mamba 状态空间建模长程体积依赖，用结构感知过滤保持边界拓扑。
- 在 LiTS、3D-IRCADb-01 和 CHAOS 上报告结果，模型参数约 `27.6M`。
- **边界**：它是本目录里与当前课题最接近的论文之一，但“三个困难”仍需逐模块消融、边界/小结节/跨域指标分别支撑；还要核对 CHAOS 是否与肿瘤标签任务严格可比。

## 4. “三个问题—三个模块”快速鉴别表

看到论文列出三个问题、三个模块时，逐项检查：

| 检查项 | 通过标准 | 常见伪闭环 |
| --- | --- | --- |
| 问题真实性 | 有数据、失败案例或已有研究支持 | 只说“小目标难、边界模糊、上下文不足” |
| 问题独立性 | 三个问题有不同可测量结果 | 同一个“特征不足”换三种说法 |
| 模块针对性 | 能解释输入、运算和输出为何改变目标现象 | “注意力能关注重要区域” |
| 一一对应消融 | 每个模块至少有独立加入/删除实验 | 只比较 baseline 与全部模块 |
| 指标对应 | 边界问题看 HD/ASSD；漏检看 recall；假阳性看 precision/FP | 所有问题都只用 Dice 证明 |
| 外部有效性 | 在未参与开发的数据上保持方向一致 | 只在同一 split 上反复调参 |
| 失败分析 | 指出哪些病例改善、哪些恶化 | 只展示最好看的可视化样例 |

## 6. 后续维护规则

1. 每读一篇先用一句话写出中心问题，再拆子缺口、方案和证据；不要按模块数量倒推问题数量。
2. 填完逐篇模板后，再决定是否进入总览矩阵。
3. “作者说解决了”与“实验真的证明了”必须分开写。
4. 对肝肿瘤论文至少记录：数据划分、ROI 是否使用真值、2D/3D、额外数据、patient-wise/tumor-wise、无瘤病例处理。
5. 所有数值都标明数据集和评价单位，禁止只写一个孤立 Dice。
6. 每累计 5 篇论文，回看一次：哪些问题反复出现，哪些只是换名字，哪些已有可靠证据但仍未解决。
