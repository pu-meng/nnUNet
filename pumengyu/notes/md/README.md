# 笔记入口

> 整理时间：2026-07-07
> 当前目录按主题拆成少量子文件夹；已删除重复旧稿和废弃资料。

## 当前入口

| 路径 | 用途 |
|---|---|
| `论文写作状态.md` | 当前论文写作推进、主线决策、补充实验队列 |
| `论文主线.md` | 当前论文叙事、核心证据和下一步优先级 |
| `../paper/论文母稿_MedNeXt_MLA_中文.md` | 中文母稿，集中存放正文草稿、材料、困惑、表格和路径 |
| `00_架构设计/` | 模型架构、Trainer、Loss、nnUNet 源码流程 |
| `01_实验方案/` | 实验计划、FP 抑制、数据划分、配置 |
| `02_实验结果/` | 当前结果排名、消融、外部验证、报告命令 |
| `03_数据集/` | 数据集、IRCADb、外部数据、分布度量 |
| `04_想法与规划/` | 论文计划、组会汇报、创新记录 |
| `05_工具与技术/` | GPU profiling、卷积机制、Tensor Core、工程工具 |
| `06_其他/` | 少量非主线笔记 |

## 使用建议

1. 写论文先看 `论文主线.md`。
2. 查某一类内容先进入对应子文件夹的 `README.md`。
3. 新增笔记优先追加到已有主题文件；只有形成新主题时再新增文件。
