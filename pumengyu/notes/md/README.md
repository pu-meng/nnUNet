# 从这里开始

这里只保留一条主阅读路径。日常推进论文时，不需要从知识库逐篇翻找。

## 必读顺序

1. [`我的论文问题.md`](我的论文问题.md)：当前锁定的现实问题、证据边界、下一步和反证条件。
2. [`论文主线.md`](论文主线.md)：先确定主方法、能说什么和暂时不能说什么。
3. [`03_知识库/论文问题_解法_说服链总表.md`](03_知识库/论文问题_解法_说服链总表.md)：逐篇对照已读论文如何定义问题、设计解法并建立说服链。
4. [`01_当前项目/当前方法与架构.md`](01_当前项目/当前方法与架构.md)：理解当前 MedNeXt_MLA_MoE 的真实结构。
5. [`01_当前项目/当前实验与重训.md`](01_当前项目/当前实验与重训.md)：查看正在训什么、命令、完成标准和决策门。
6. [`01_当前项目/当前结果与结论.md`](01_当前项目/当前结果与结论.md)：查看三域结果、消融和目前成立的结论。

## 三个目录

| 目录 | 什么时候看 |
|---|---|
| [`01_当前项目/`](01_当前项目/README.md) | 平时主要看这里，只保留研究问题、方法、实验和结果四份核心文档 |
| [`02_实验档案/`](02_实验档案/README.md) | 需要查原始实验、数据集、消融、失败病例或历史计划时 |
| [`03_知识库/`](03_知识库/README.md) | 需要理解 nnU-Net、MedNeXt、候选机制、GPU 或工程问题时 |

正式论文、汇报稿、图表和参考论文从 [`../paper/README.md`](../paper/README.md) 进入。
