## 4.5 CT 视觉歧义与临床失败模式

这部分必须写进论文，建议放在 Introduction 的问题动机、Results 的 case analysis、Discussion 的 limitation 中。

本文对“CT 视觉歧义”的工作定义：

```text
在 CT 图像上，看起来像肿瘤的区域不一定是真正肿瘤；
真正的肿瘤有时又没有明显低密度阴影或异常纹理。

模型对“有可见阴影的区域”判断能力相对更强：
  - 有阴影 + 有肿瘤：通常较容易识别；
  - 有阴影 + 无肿瘤：虽然仍可能产生假阳性，但相比“无阴影真肿瘤”更容易被模型学习和排除。

最困难的是“有肿瘤但肉眼/单张切片上几乎没有阴影”的区域：
  - 这类区域接近正常肝实质；
  - 模型几乎无法稳定识别；
  - 这是单期 CT 肝肿瘤分割的重要信息瓶颈。
```

3D 分割中的额外现象：

```text
模型不是独立判断每一张 2D 切片，而是在 3D patch 上联合判断。
因此某些 2D 切片本身没有明显阴影、也没有肿瘤，
但如果相邻切片存在明显阴影/肿瘤区域，模型可能把上下文延续到该切片，
导致局部过分割或假阳性。

这类错误不是简单的“单张切片看错”，而是 3D 上下文传播带来的边界/邻近切片误判。
```

因此本文的错误分析不只分 FP/FN，还要区分三种来源：

| 错误来源 | 表现 | 主要风险 |
|---|---|---|
| 可见阴影相似性 | 低密度阴影、术后切除灶、坏死/良性结构被预测为肿瘤 | 假阳性 |
| 隐匿/等密度肿瘤 | 肿瘤区域与正常肝实质接近，单切片无明显异常 | 漏检 |
| 3D 上下文牵连 | 当前切片无明显肿瘤，但邻近切片有肿瘤/阴影，模型把预测延续过来 | 边界过分割或邻近切片假阳性 |

要写进去的观察：

1. MSD/LiTS 中存在“无明显阴影但有肿瘤”的病例，模型很容易漏检。这说明单期 CT 的视觉证据不足，不能只靠换网络完全解决。
2. MSD/LiTS 中存在“有明显低密度阴影但 GT 无肿瘤”的病例，模型容易假阳性。
3. 3D 分割会带来邻近切片影响：当前 2D 切片本身无明显阴影或无肿瘤，也可能因为相邻切片存在肿瘤/阴影而被预测为肿瘤。
4. IRCADb 转换脚本明确排除了 `metastasectomi`，即术后切除灶/术后瘢痕不作为活体肿瘤；这类区域 CT 外观可能高度近似肿瘤，是临床假阳性的重要来源。
5. 这些发现可以提升论文深度：本文不是只报 Dice，而是解释模型为什么错、什么错误是临床上危险的、哪些错误可能来自 CT 模态本身和 3D patch 推理机制。
