今天用到的命令按类别整理：

**查看进程**
```bash

ps aux | grep clash          # 查看 clash 是否在运行
ps aux | grep clash | grep PuMengYu  # 只看自己的进程
pgrep -u PuMengYu clash      # 获取自己的 clash 进程号

```

**阅读命令:**

- ps是Process Status的缩写-查看进程状态的命令
-  pgrep=Process grep 按照名字搜索进程并且返回PID(进程号)
aux是什么的缩写?

- a是all users,显示所有用户的进程
- u是user-oriented,以用户友好格式显示
- x是include processes without a terminal,包含没有终端(后台守护进程)的进程


**查看端口**
```bash
ss -tlnp | grep 7891         # 查看端口是否在监听
ss -tlnp | grep clash        # 查看 clash 占用的端口
```
- ss是Socket Statistics的缩写，用于查看网络连接和端口状态的命令,是netstat的替代品

- tlnp是四个选项,t-TCP,只看TCP协议的内容,l-listening,只看正在"监听"的端口
- n-numeric用数字显示端口号
- p-process显示是哪个进程在占用端口

**网络测试**
```bash
curl -v https://api.anthropic.com          # 测试能否连上 Anthropic
curl -s -o /dev/null -w "%{http_code}" --max-time 10 https://www.google.com  # 测试返回状态码
curl http://127.0.0.1:9091/proxies         # 查看 clash 当前节点
```

**切换节点**
```bash
curl -X PUT http://127.0.0.1:9091/proxies/%E5%A4%A7%E5%93%A5%E4%BA%91 \
  -H "Content-Type: application/json" \
  -d '{"name": "节点名"}'
```

**下载文件**
```bash
curl -L "URL" -o 文件名      # 下载文件到指定路径
```

**文件操作**
```bash
cp 原文件 备份文件            # 备份
cat 文件 | grep 关键词        # 查找文件内容
head -20 文件                # 查看前20行
sed -i 's/旧内容/新内容/' 文件 # 原地替换文件内容
```

**环境变量**
```bash
export https_proxy=http://127.0.0.1:7891  # 设置代理
unset all_proxy                            # 清除某个变量
echo 'export ...' >> ~/.bashrc             # 永久写入
source ~/.bashrc                           # 立即生效
```

**进程管理**
```bash
kill 进程号                  # 杀掉进程
kill $(pgrep -u PuMengYu clash)  # 杀掉自己的 clash
nohup 命令 > 日志文件 2>&1 &  # 后台运行并记录日志
sleep 3                      # 等待3秒
```

**查看配置**
```bash
grep 'port' ~/.config/clash/config.yaml   # 查找配置文件中的端口
grep 'external-controller' ~/.config/clash/config.yaml
```
