# 镜像翻转（Mirroring）原理分析

## 1. 镜像翻转在 nnUNet 中的实现

### 训练时（Data Augmentation）

在 `nnUNetTrainer.py:834-839`，训练时对每个 patch 以 50% 概率随机翻转：

```python
if mirror_axes is not None and len(mirror_axes) > 0:
    transforms.append(MirrorTransform(allowed_axes=mirror_axes))
```

默认 3D 模式下 `mirror_axes = (0, 1, 2)`，即三个轴都可能翻转：
- **轴 0（前后）**：Z 轴翻转，上下颠倒
- **轴 1（左右）**：Y 轴翻转，左右镜像
- **轴 2（上下）**：X 轴翻转，冠状面翻转

每个 batch 的每个 sample 独立随机决定是否翻转、沿哪些轴翻转。

### 推理时（Test Time Augmentation, TTA）

在 `nnUNetTrainer.py:1275-1280`，推理时使用 `nnUNetPredictor` 并传入 `inference_allowed_mirroring_axes`：

```python
predictor = nnUNetPredictor(tile_step_size=0.5, use_gaussian=True, use_mirroring=True, ...)
predictor.manual_initialization(..., self.inference_allowed_mirroring_axes)
```

推理时对每个 case 做 **8 种镜像组合**（2³ = 8，每个轴翻转或不翻转），将 8 个预测结果取平均作为最终输出。这就是 TTA（Test Time Augmentation）。

## 2. 为什么镜像翻转能提高 Recall？

### 核心原因：肿瘤位置多样性

肝脏肿瘤在 CT 中的位置非常多变：
- 有的在肝左叶，有的在肝右叶
- 有的靠近膈顶（上方），有的靠近肝下缘（下方）
- 有的靠近前腹壁，有的靠近后腹膜

**镜像翻转相当于让模型"看到"肿瘤出现在不同解剖位置**：

```
原始图像（肿瘤在右侧）  →  左右镜像（肿瘤在左侧）
原始图像（肿瘤在上方）  →  上下镜像（肿瘤在下方）
```

### 具体机制

#### 机制 1：训练时 — 数据增强增加多样性

训练时随机翻转让模型学会**位置不变的特征提取**：

- 假设训练集中 70% 的肿瘤在肝右叶，30% 在肝左叶
- 如果不做镜像，模型可能学到"肿瘤通常在右侧"的偏置
- 做了左右镜像后，肝右叶的肿瘤也会出现在左侧，模型被迫学习"肿瘤就是肿瘤，不管在哪侧"
- 结果是模型对**不常见位置的肿瘤**也能检测到 → **Recall 提升**

#### 机制 2：推理时 — TTA 多视角平均

推理时 8 种镜像取平均，相当于**8 个不同视角的模型投票**：

```
原始方向预测：肿瘤概率图 A
左右镜像预测：肿瘤概率图 B（翻转回原始方向）
上下镜像预测：肿瘤概率图 C（翻转回原始方向）
...（共 8 种组合）

最终预测 = (A + B + C + ...) / 8
```

- 如果某个方向的预测漏掉了肿瘤边缘，另一个方向可能补上
- 如果某个方向的预测产生了误报，其他方向的平均会稀释它
- **TTA 相当于模型集成（ensemble），但只用一个模型**

#### 机制 3：梯度信号更丰富

反向传播时，镜像翻转改变了每个体素对应的梯度方向：

- 不镜像：梯度只从原始空间位置传播
- 镜像后：梯度从翻转后的位置传播，相当于**每个体素的感受野被重新排列**
- 这帮助模型在训练早期更快地建立稳定的特征检测器

## 3. 为什么 Baseline 的 Recall 是所有方法中最高的？

### 对比其他方法

| 方法 | Recall | 与 Baseline 差异 |
|------|--------|-----------------|
| **Baseline（默认镜像）** | **0.7853** | — |
| NoMirror（关闭镜像） | 0.6769 | ↓ -13.8% |
| SizeOversampleV2（过采样） | 预计 < 0.78 | 过采样增加 Precision 但可能降低 Recall |
| UFL（Focal Loss） | 预计 < 0.78 | 惩罚 FN 但同时也抑制 easy positive |

### 原因分析

#### 原因 1：镜像 = 免费的数据量翻倍

- 不做镜像：每个 epoch 看到 N 个不同的 patch
- 做镜像：每个 epoch 看到 N 个 patch，但每个 patch 有 50% 概率被翻转
- 相当于**有效训练数据量翻倍**，模型见过更多样化的肿瘤形态
- 更多数据 → 更好的泛化 → 更高的 Recall

#### 原因 2：TTA 对 Recall 的贡献

推理时 8 次预测取平均，对 Recall 的贡献：

```
假设某个肿瘤边缘体素：
  原始方向预测概率 = 0.45（漏检）
  左右镜像预测概率 = 0.55（检出）
  平均后概率 = 0.50（刚好过阈值，检出）
```

**TTA 相当于给每个体素多一次"被正确分类"的机会**。

#### 原因 3：其他方法都在"压制"模型

其他方法本质上都在**让模型变得更保守**：

| 方法 | 做了什么 | 对 Recall 的影响 |
|------|---------|-----------------|
| **NoMirror** | 减少数据多样性 | 模型没见过"肝脏在左侧"的假图像，但也失去了位置不变性 → Recall ↓ |
| **SizeOversample** | 重复无肿瘤 case | 模型更倾向于预测"无肿瘤" → Recall ↓ |
| **UFL** | 惩罚 FN 但 focal 压制 easy positive | 复杂 trade-off |
| **NoTumorFPPenalty** | 直接惩罚无肿瘤 case 的肿瘤预测 | 模型更不敢预测肿瘤 → Recall ↓ |

**Baseline 是唯一一个没有"压制"模型的方法**，它通过镜像让模型尽可能多地看到各种形态的肿瘤，所以 Recall 最高。

#### 原因 4：镜像对极小肿瘤的特别帮助

极小肿瘤（<5k 体素）在 CT 中本来就很难分辨：

- 不做镜像：模型只在原始位置看到这几十个体素
- 做镜像：模型在 8 个不同位置看到这几十个体素
- 相当于**极小肿瘤的梯度信号被放大了 8 倍**

这就是为什么 NoMirror 的极小肿瘤 Recall 从 66.9% 暴跌到 44.4%（下降 22.5%）。

## 4. 镜像翻转的代价

### 为什么 Precision 会下降？

镜像翻转虽然提高了 Recall，但也带来了误报：

```
原始图像：肝脏在右侧，模型学会"右侧高密度区域可能是肿瘤"
左右镜像后：肝脏出现在左侧，模型可能把"左侧高密度区域"也误判为肿瘤
```

具体来说：

1. **解剖位置混淆**：左右镜像让模型分不清"肝右叶"和"肝左叶"，可能把左叶的正常结构误判为肿瘤
2. **TTA 平均的副作用**：8 次预测中如果有 1-2 次误报，平均后虽然被稀释，但仍然可能超过阈值
3. **无肿瘤 case 的误报**：无肿瘤 case 本来就不该有肿瘤，但镜像让模型"看到"了不存在的肿瘤位置

这就是为什么 Baseline 的 Precision 只有 0.6451，而 NoMirror 提升到 0.7685。

## 5. 直观类比

```
Baseline（带镜像）：
  "我见过肿瘤在左边、右边、上边、下边，所以不管在哪我都能找到"
  → 找到很多（Recall 高），但也找错很多（Precision 低）

NoMirror（关闭镜像）：
  "我只在原始位置见过肿瘤，其他地方出现类似结构我不敢乱说"
  → 找到较少（Recall 低），但找得准（Precision 高）
```

---

## 6. 总结

| 方面 | 解释 |
|------|------|
| **镜像翻转是什么** | 训练时随机翻转 patch（数据增强）+ 推理时 8 种镜像取平均（TTA） |
| **为什么提高 Recall** | ① 数据多样性翻倍 ② TTA 多视角投票 ③ 梯度信号更丰富 ④ 极小肿瘤被放大 |
| **为什么 Baseline Recall 最高** | 其他方法都在"压制"模型（减少数据/惩罚预测），只有 Baseline 在"放开"模型 |
| **代价是什么** | Precision 下降（模型分不清左右解剖位置，产生误报） |
| **本质 trade-off** | Recall 和 Precision 不可兼得，镜像偏向 Recall，关闭镜像偏向 Precision |
